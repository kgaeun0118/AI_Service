# 0-4. 플라즈마와 RF — 상온에서 고온 화학을 일으키는 기술

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-3 가스](00-3-gas-and-fluids.md)

## 1. 왜 플라즈마인가 — 한 문장으로

> **플라즈마는 "웨이퍼를 뜨겁게 하지 않고도 고온 화학반응을 일으키는 장치"** 입니다.

CF₄ 분자를 열로 쪼개려면 수천 K가 필요합니다. 웨이퍼는 그 온도를 못 견딥니다(이미 만든 구조가 다 망가짐).
플라즈마는 전기장으로 **전자만** 가속합니다.

```
   전자 온도  Te ≈ 2 ~ 5 eV  (≈ 20,000 ~ 50,000 K 상당)   ← 분자를 쪼갤 수 있다
   이온 온도  Ti ≈ 0.05 eV   (≈ 실온 수준, 무거워서 전기장을 잘 못 따라감)
   중성 가스  Tg ≈ 300 ~ 600 K (웨이퍼가 견딜 수 있는 온도)
   → 이런 상태를 "저온 플라즈마(비평형 플라즈마)"라 한다.
```

전자의 질량이 이온의 1/1800 ~ 1/100,000 이기 때문에 가능한 일입니다. **전자만 뜨겁고 나머지는 차가운 상태** — 이것이 반도체 공정 플라즈마의 본질입니다.

### 플라즈마가 만들어 주는 3종 선수

| 종(species) | 역할 | 공정에서의 의미 |
|-------------|------|-----------------|
| **라디칼 (radical, 중성 활성종)** | 화학적으로 반응. 밀도가 이온보다 100 ~ 1000배 높음 | **화학적 식각·증착의 주역**. 등방성(isotropic) 경향 |
| **이온 (ion)** | 시스 전기장에서 가속되어 수직 입사, 운동량 전달 | **방향성(anisotropy)** 담당. 표면 결합 끊기, 스퍼터링 |
| **광자 (photon, UV)** | 발광 → 진단에 활용(OES), 소재에 손상도 유발 | 종점 검출, 플라즈마 유도 손상(VUV) |

> **식각의 핵심 원리(ion-enhanced etching)**: 라디칼 단독으로는 느리고, 이온 단독으로도 느립니다. **둘이 동시에 작용할 때 식각률이 급증**합니다.
> 이온이 표면 결합을 깨서 라디칼이 반응할 자리를 만들어 주기 때문입니다. 이온은 수직으로 오므로 **바닥만 빠르게 파이고 측벽은 남습니다 = 수직 프로파일**.

## 2. 시스(sheath) — 이온이 수직으로 꽂히는 이유

플라즈마와 표면(웨이퍼) 사이에는 얇은 전기적 경계층 **시스**가 생깁니다. 여기서 모든 방향성이 결정됩니다.

```
        플라즈마 본체 (준중성, 전위 ≈ Vp)
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
        │  전자가 가벼워 빨리 빠져나감
        │  → 표면은 음(–)으로 대전
        ▼
   ┌─────────────────────────────────────┐  ← 시스 (두께 ~0.1 ~ 수 mm)
   │  강한 전기장 (플라즈마→표면 방향)      │      · 이온이 여기서 가속
   │  이온이 수직으로 가속됨  ↓↓↓↓↓↓↓↓     │      · 전자는 반발됨
   └─────────────────────────────────────┘
   ███████████ 웨이퍼 (전위 ≈ Vdc, 음전위) ███████████
```

핵심 결론 4개:

1. **이온 에너지 ≈ (플라즈마 전위 − 웨이퍼 전위)** → 즉 **바이어스로 이온 에너지를 조절**한다.
2. 시스 두께 ≫ 이온의 평균자유행정이면 시스 안에서 충돌이 일어나 **방향성이 흐트러짐** → 그래서 저압이 유리(이유는 [0-2장](00-2-vacuum.md) λ 이야기와 동일).
3. 절연막 위에서는 전하가 쌓여 이온 궤적이 휨 → **차징(charging) 유발 결함**(notching, twisting). 그래서 **펄스 플라즈마**로 주기적으로 중성화합니다.
4. 웨이퍼가 절연체(SiO₂ 등)로 덮여 있어도 RF는 커패시터를 통해 전류를 흘릴 수 있으므로, **RF 바이어스**를 씁니다(DC로는 절연막에 전류를 못 흘림).

## 3. 플라즈마 소스 도감 — 구조와 선택 이유

### 3-1. CCP (Capacitively Coupled Plasma, 용량결합)

```
            RF (13.56 MHz 등)
                  │
        ┌─────────┴──────────┐
        │  상부 전극(샤워헤드) │  ← 가스도 여기서 나옴
        └────────────────────┘
        ░░░░░░ 플라즈마 ░░░░░░       갭: 보통 수 mm ~ 수 cm
        ┌────────────────────┐
        │ 웨이퍼 + ESC(하부전극)│  ← 여기에 바이어스 RF (2 MHz, 400 kHz 등)
        └─────────┬──────────┘
                  │
              RF or 접지
```

| 항목 | 내용 |
|------|------|
| 원리 | 두 전극 사이에 RF → 전자가 진동하며 기체를 이온화 |
| 압력 | 수 mTorr ~ 수백 mTorr |
| 플라즈마 밀도 | 중간 (10⁹ ~ 10¹¹ /cm³) |
| 특징 | **이온 에너지가 높다**(시스 전압이 큼) → 물리적 타격이 필요한 공정에 유리 |
| 약점 | 밀도와 이온 에너지가 **함께 움직임**(하나만 조절하기 어려움) → 해결책이 아래의 다중 주파수 |
| 주 용도 | 유전막 식각(옥사이드/나이트라이드), HAR 식각, PECVD |

**다중 주파수(dual/triple frequency) CCP — 왜 필요한가**
```
  고주파(예: 60 ~ 100 MHz) → 주로 플라즈마 밀도(=라디칼/이온 생성량) 지배
  저주파(예: 2 MHz, 400 kHz) → 주로 이온 에너지(시스 전압) 지배
  → 두 개를 독립적으로 돌리면 "얼마나 많이" 와 "얼마나 세게" 를 분리 제어 가능
```
이것이 현대 유전막 식각 장비가 2 ~ 3개의 RF 제너레이터를 가진 이유입니다.

### 3-2. ICP / TCP (Inductively Coupled Plasma, 유도결합)

```
        ┌─── 평면 코일 (안테나) ───┐   ← RF 13.56 MHz
        ╞══════════════════════════╡   유전체 윈도우(석영/알루미나)
        ░░░░░░ 고밀도 플라즈마 ░░░░░░
        ┌──────────────────────────┐
        │  웨이퍼 + ESC            │  ← 독립 바이어스 RF
        └──────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| 원리 | 코일의 교류 자기장이 유도 전기장을 만들어 전자를 가속(변압기 2차측처럼) |
| 압력 | 1 ~ 수십 mTorr (저압에서 잘 동작) |
| 밀도 | **고밀도** (10¹¹ ~ 10¹² /cm³) |
| 특징 | **밀도(소스 파워)와 이온 에너지(바이어스 파워)를 구조적으로 분리** → 제어성 최고 |
| 약점 | 유전체 윈도우에 증착물 퇴적 → 결합 효율 변화(드리프트), 윈도우 PM 필요 |
| 주 용도 | 실리콘/폴리/금속 식각, 컨덕터 식각, ALE, 다운스트림 소스 |

### 3-3. 기타 소스

| 소스 | 원리 | 특징 | 용도 |
|------|------|------|------|
| **마이크로웨이브 / ECR** | 2.45 GHz + 자기장 공명 | 초고밀도, 저이온에너지 | 다운스트림 애싱, 원격 플라즈마 클린, 일부 식각 |
| **원격 플라즈마 (RPS)** | 챔버 밖에서 플라즈마 생성, 라디칼만 챔버로 | **이온 손상 없음**, NF₃ 해리 효율 높음 | 챔버 클린(in-situ 대비 손상↓), 표면 처리, 선택적 제거 |
| **HDP (Helicon/ICP 변형)** | 고밀도 + 웨이퍼 바이어스 동시 | 증착과 스퍼터가 동시에 → **갭필** | HDP-CVD (STI/IMD 갭필) |
| **마그네트론 (PVD)** | DC/펄스DC + 영구자석으로 전자 포획 | 타겟 근처 밀도↑ → 스퍼터율↑ | 스퍼터 증착 ([06장](06-metallization-pvd-ecp.md)) |
| **Bernas / IHC 이온 소스** | 열전자 + 자기장, 아크 방전 | 대전류 이온 생성 | 임플란터 ([07장](07-ion-implantation.md)) |
| **LPP (Laser Produced Plasma)** | CO₂ 레이저로 Sn 액적을 플라즈마화 | 13.5 nm EUV 발광 | EUV 광원 ([03장](03-photolithography.md)) |
| **CCP+ICP 하이브리드** | 두 소스 동시 | 극단적 제어성 | 첨단 식각 |

## 4. RF 전달 계통 — 매처, 케이블, 접지

플라즈마에 파워를 넣는 것은 "전선을 연결한다"로 끝나지 않습니다. RF는 **임피던스 정합** 문제입니다.

```
 ┌──────────────┐   50 Ω    ┌─────────┐   가변 임피던스   ┌────────────┐
 │ RF 제너레이터 │══════════▶│ 매처     │═════════════════▶│ 챔버(플라즈마)│
 │ (13.56 MHz…) │  동축케이블 │ (Match)  │  스트랩/피드     │  전극        │
 └──────────────┘            └─────────┘                  └────────────┘
      ▲                          │
      │ 반사파(reflected power)   │ 가변 커패시터 2개(C1, C2)를 모터로 움직여
      └──────────────────────────┘ 부하 임피던스를 50 Ω로 변환
```

| 구성 | 역할 | 실무 포인트 |
|------|------|-------------|
| **RF 제너레이터** | 정해진 주파수·파워 공급 | 출력은 "순방향 파워". 실제 플라즈마에 들어간 것은 순방향 − 반사 |
| **매칭 네트워크(매처)** | 플라즈마 임피던스(수 Ω ~ 수십 Ω, 복소수)를 50 Ω으로 변환 | **자동 매처**는 모터로 C1/C2를 움직임. **포지션 값이 중요한 진단 데이터** |
| **반사 파워 (Pr)** | 정합 실패분 | 지속적 반사 = 파워 부족 + 제너레이터 손상 + 결과 드리프트 |
| **RF 동축 케이블/스트랩** | 전달 | **길이·경로가 임피던스를 바꿈** → PM 후 케이블 경로를 원래대로! (자주 간과되는 매칭 문제 원인) |
| **접지(RF return path)** | 전류 귀환 경로 | 접지 불량 = 플라즈마 비대칭, 아킹, 이상 발광. 가스켓/스크린의 접촉 저항 관리 |
| **필터/블로킹 커패시터** | 히터·센서선으로 RF 누설 방지 | 필터 열화 시 온도 센서 오독, 히터 손상 |
| **VI 프로브** | 전극에서 전압·전류·위상 실측 | 제너레이터 표시값보다 실제에 가까움 → 고급 FDC 지표 |

### 매처 포지션이 왜 중요한 데이터인가

같은 레시피에서 **매처 C1/C2 포지션이 평소와 다르다** = 챔버 내부 상태(증착물 두께, 부품 마모, 접지 상태)가 변했다는 뜻입니다.
공정 결과가 아직 스펙 안이어도 매처 포지션은 이미 이동해 있습니다. → **강력한 선행지표**([0-7장](00-7-sensors-and-control.md)).

## 5. 자주 쓰는 플라즈마 노브 → 결과

| 노브 | 물리적으로 바뀌는 것 | 공정 결과 | 부작용 |
|------|---------------------|-----------|--------|
| **소스 파워 ↑** | 전자 밀도·라디칼 생성 ↑ | 식각/증착률 ↑ | 챔버 부품 소모↑, 발열↑, 선택비 변화 |
| **바이어스 파워 ↑** | 이온 에너지 ↑ | 방향성 ↑, 하드마스크 뚫기 쉬움, 식각률 ↑ | **선택비 ↓**, 마스크 소모 ↑, 웨이퍼 손상(플라즈마 유도 손상), 부품 스퍼터 |
| **압력 ↑** | 충돌 ↑, 라디칼 밀도 ↑, 시스 얇아짐 | 화학적 식각 성분 ↑, 식각률 ↑(보통) | 등방성 ↑(프로파일 나빠짐), 파티클/폴리머 ↑ |
| **갭(전극 간격) ↓** | 전력 밀도 ↑, 체류시간 ↓ | 균일도·프로파일 변화, 라디칼 조성 변화 | 아킹 위험, 균일도 재튜닝 필요 |
| **가스 비율 변경** (예: C₄F₈/O₂) | 폴리머 생성 vs 제거 균형 | **선택비와 프로파일의 주 노브** | 폴리머 과다 → 식각 정지, 과소 → 측벽 손실 |
| **펄싱(듀티/주파수)** | 라디칼/이온 비율, 차징 완화 | HAR 프로파일 개선, ARDE 완화, 선택비 향상 | 실효 식각률 ↓, 제어 복잡 |
| **웨이퍼 온도 ↑** | 라디칼 흡착·탈착, 폴리머 두께 | 선택비·프로파일 변화, 부산물 휘발 | 레지스트 변형, 소재 손상 |
| **He 백사이드 압력 ↑** | 웨이퍼-척 열전달 ↑ | 웨이퍼 온도 ↓·균일 | 너무 높으면 웨이퍼가 떠서 파손/척킹 실패 |

> **입문자에게 가장 중요한 한 줄**: 플라즈마에서 노브 하나는 결코 하나만 바꾸지 않습니다. 반드시 **"무엇이 같이 나빠지는가"** 를 함께 기억하세요.

## 6. 플라즈마와 관련된 문제들

| 문제 | 원인 | 결과 | 대책 |
|------|------|------|------|
| **아킹 (arcing)** | 국부 전계 집중(날카로운 부위, 파티클, 증착물 박리, 오염) | 웨이퍼 킬 결함, 부품 손상, 파워 트립 | 부품 형상(라운딩), 청소, 아크 검출(제너레이터 기능), 펄스DC, 압력/갭 조정 |
| **차징 손상 (charging)** | 절연막 위 전하 축적, 전자/이온 플럭스 불균형 | 게이트 산화막 파괴(안테나 효과), 노칭, HAR 프로파일 왜곡 | 펄스 플라즈마, 플라즈마 플러드 건(임플란트), 안테나 룰 설계 |
| **플라즈마 유도 손상 (PID) / VUV** | 고에너지 광자·이온 | 계면 트랩, 저유전막 손상(k값 상승) | 원격 플라즈마, 저바이어스, 보호막 |
| **비대칭/비균일 플라즈마** | 접지 불량, 부품 편마모, 배기 비대칭 | 웨이퍼 내 편차(한쪽 방향) | 접지 점검, 부품 교체, 배기 대칭화 |
| **파우더/폴리머 박리** | 챔버 내벽 퇴적물 응력 | 파티클 급증 | 주기적 클린, seasoning, 코팅, 라이너 온도 제어 |
| **점화 실패 (no strike)** | 압력·전압·가스 조건, 오염, 매처 초기 포지션 | 레시피 중단 | 점화용 스텝(높은 압력/Ar), 매처 프리셋, RF 케이블/접지 확인 |
| **제너레이터 반사 파워 상승** | 매처 고장, 부품 변화, 케이블 | 파워 부족·트립 | 매처 튜닝 범위 확인, 케이블 점검 |

## 7. 챔버 클린과 seasoning — 플라즈마 장비의 숙명

플라즈마 장비는 **공정을 돌릴수록 챔버 내부가 변합니다**(증착물 퇴적, 부품 마모). 그래서 두 가지 루틴이 붙습니다.

| 루틴 | 내용 | 목적 |
|------|------|------|
| **In-situ 챔버 클린** | NF₃/원격 플라즈마로 챔버 내부 증착물을 휘발 제거 (웨이퍼 없음, 또는 매 웨이퍼 사이) | 퇴적물 축적 방지, 파티클 억제 |
| **Wafer-less Auto Clean (WAC)** | 웨이퍼 없이 자동 클린 시퀀스 | 웨이퍼 간 재현성 유지 |
| **Seasoning / Conditioning** | PM 직후 더미 웨이퍼로 공정을 여러 장 돌려 **내벽 상태를 양산 상태로 복원** | "첫 장 효과(first wafer effect)" 제거 |
| **챔버 매칭** | 여러 챔버의 결과를 동일화 | 같은 레시피로 같은 결과 |

> **왜 seasoning이 필요한가**: 갓 청소한 금속 벽면은 라디칼을 잘 흡수(recombination)해서 라디칼 밀도가 낮습니다. 공정을 몇 장 돌려 벽에 얇은 막이 생기면 흡수율이 안정화됩니다.
> 즉 **챔버 벽도 공정 변수**입니다. 자세히는 [0-8 부품과 소모품](00-8-parts-and-consumables.md).

## 8. 진단(OES) — 플라즈마를 읽는 법

**OES(Optical Emission Spectroscopy)**: 플라즈마 발광 스펙트럼을 보고 어떤 종이 얼마나 있는지 추정합니다.

| 활용 | 방법 |
|------|------|
| **종점 검출 (EPD)** | 식각이 다른 층에 도달하면 부산물 발광이 급변 → 그 순간을 검출. 예: 폴리 식각 중 SiF 발광(440 nm 대) 감소, CO/CN 변화 |
| **챔버 상태 감시** | 특정 라인 강도 비율을 지표로 트렌드 감시(FDC) |
| **누설/오염 검출** | N₂(391 nm 대), OH, H 라인의 이상 출현 |
| **챔버 매칭** | 챔버 간 스펙트럼 비교 |

한계와 실무: 윈도우가 증착물로 흐려지면 신호가 약해집니다(윈도우 PM 필요). 개구율이 작은(열린 면적이 작은) 패턴은 부산물 신호가 약해 종점 검출이 어렵습니다 → 간섭계(IEP) 병용.
