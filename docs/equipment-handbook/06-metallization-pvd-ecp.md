# 06. 금속배선 장비 — PVD · 도금 · CVD/ALD 금속 · 실리사이드

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-3 가스(전구체 전달)](00-3-gas-and-fluids.md), [0-4 플라즈마](00-4-plasma-and-rf.md), [05 증착](05-deposition-cvd-ald.md)
> 다루는 장비: 이베이퍼레이터 · **스퍼터(마그네트론 PVD) 클러스터** · 디개스/프리클린 챔버 · **W-CVD/ALD** · **Cu 전기도금(ECP)** · 무전해 도금 · 실리사이드(RTA) · Mo/Ru/Co 증착
>
> **이 장의 중심 질문**: "금속은 재료마다 융점·증기압·반응성이 전부 다른데, 장비는 이것을 어떻게 다루는가?"

---

## 1. 먼저 결론 — 재료 물성이 장비 선택을 결정한다

금속 박막을 만드는 방법은 크게 4가지이고, **어느 것을 쓸지는 재료의 물성이 거의 결정합니다.**

```
 재료를 주면, 장비는 이렇게 정해진다:

 ┌─ 증기압이 충분히 높고(낮은 온도에서 증발), 조성이 단순한가? ── Yes ──▶ [증발(evaporation)]
 │                                                                    (Al, Au, Ag … 연구/후공정/광학)
 │  No
 ├─ 고융점/저증기압이거나, 합금 조성을 지켜야 하는가? ───────── Yes ──▶ [스퍼터(PVD)]
 │                                                                    (Ti, TiN, Ta, TaN, W, Cu seed, AlCu, Ru …)
 │  또는 컨포멀리티가 더 중요
 ├─ 휘발성 전구체가 존재하고 홀 측벽까지 균일해야 하는가? ──── Yes ──▶ [CVD / ALD]
 │                                                                    (W: WF₆, Mo: MoO₂Cl₂/MoCl₅, TiN: TiCl₄, Ru, Co)
 │  또는 두꺼운 매립이 필요
 └─ 깊은 트렌치/비아를 보이드 없이 "채워야" 하는가? ────────── Yes ──▶ [전기도금(ECP)]
                                                                      (Cu 배선, TSV, 범프, RDL)
```

> **핵심 통찰**: "금속마다 기화 특성이 다르다"는 문제는 **증발법에서만 치명적**입니다.
> 스퍼터는 애초에 "기화"를 쓰지 않고 **운동량 전달로 원자를 때려서 떼어내기** 때문에 융점·증기압의 제약을 대부분 우회합니다.
> 그것이 반도체 금속 공정이 증발 → 스퍼터로 넘어간 근본 이유입니다. 아래에서 정량적으로 봅니다.

---

## 2. 증발(evaporation) — 왜 반도체 배선에서 퇴출되었나

### 2-1. 증발의 물리

```
   가열된 소스에서 나오는 원자 플럭스는 그 물질의 "증기압"에 비례한다(헤르츠-크누센).

      Flux ∝ P_vapor(T) / √(M·T)

   그리고 증기압은 온도에 대해 지수적으로 변한다(클라우지우스-클라페이롱):

      P_vapor ∝ exp( − ΔH_vap / RT )

   → 온도 몇십 ℃ 차이로 증착률이 몇 배 변한다 (제어가 예민)
```

### 2-2. 금속별 "증발 가능성" 비교 (대략적인 감각용)

| 금속 | 융점 (℃, 대략) | **증기압 10⁻⁴ Torr가 되는 온도 (℃, 대략)** | 증발로 다루기 |
|------|----------------|-------------------------------------------|---------------|
| Al | 660 | ~1,010 | 쉬움 (고전적 배선 재료였던 이유) |
| Ag | 962 | ~850 (고체에서도 증발) | 쉬움 |
| Au | 1,064 | ~1,130 | 쉬움 |
| Cu | 1,085 | ~1,020 | 가능하나 반도체 배선용으로는 부적합(확산 문제) |
| Cr | 1,857 | ~1,160 (승화) | 가능 |
| Ni | 1,455 | ~1,260 | 가능(전자빔) |
| Ti | 1,668 | ~1,530 | 어려움(전자빔 필요, 반응성 큼) |
| Co | 1,495 | ~1,250 | 가능하나 실용성 낮음 |
| Pt | 1,768 | ~1,750 | 매우 어려움 |
| **Mo** | 2,623 | ~2,120 | 실질적으로 불가 |
| **Ta** | 3,017 | ~2,820 | 실질적으로 불가 |
| **W** | 3,422 | ~2,760 | 실질적으로 불가 |

> 값은 **자릿수 감각용 근사치**입니다(문헌·자료마다 차이가 있습니다). 요점은 다음입니다:
> **배리어/배선에 꼭 필요한 Ti, Ta, W, Mo, Ru 같은 고융점 금속은 증발로는 사실상 만들 수 없습니다.**
> 도가니·히터가 먼저 녹거나, 필요한 온도에서 주변 부품이 다 오염됩니다.

### 2-3. 합금 문제 — 증발의 결정적 약점 (사용자 질문의 핵심)

```
   Al-Si 합금(1 % Si) 을 증발시키면 어떻게 될까?

   같은 온도(예 1,100 ℃)에서
     Al 의 증기압 ≫ Si 의 증기압
   → 거의 Al 만 날아가고 Si 는 소스에 남는다
   → 웨이퍼에 증착된 막의 조성이 소스 조성과 완전히 다름 (= 분별증발, fractionation)
   → 게다가 시간이 갈수록 소스 조성이 변하므로 막 조성도 시간에 따라 변함(재현 불가)

   Al-Cu(0.5 %) 도 동일한 문제. 그런데 배선에는 Cu 나 Si 를 소량 넣어야 한다
   (EM 수명 향상, 접합 스파이킹 방지). → 증발로는 불가능.
```

증발 시대에 쓰던 대응책과 그 한계:

| 대응책 | 방법 | 한계 |
|--------|------|------|
| **플래시 증발** | 소량을 순간적으로 전량 증발 | 재현성·대면적 어려움 |
| **다중 소스 공증발** | 각 원소 소스를 따로 두고 속도 개별 제어 | 소스마다 온도 제어 필요, 균일도·재현성 확보 난이도 급증 |
| **소스 조성 보정** | 소스에 Si/Cu를 과다 투입 | 시간에 따라 조성 드리프트 |
| **결론** | — | **스퍼터로 전환** |

### 2-4. 증발 장비의 형태 (참고 — 현재는 특수 용도)

| 방식 | 구조 | 특징 | 현재 용도 |
|------|------|------|-----------|
| **저항 가열(thermal)** | 텅스텐 보트/바스켓에 재료를 올려 통전 가열 | 단순·저렴 | 연구, 리프트오프, 일부 후공정/광학 |
| **전자빔(e-beam)** | 전자빔을 도가니 재료에 집속 → 국부 용융 | 고융점 대응, 도가니 오염 적음 | 광학 코팅, MEMS, 연구, 일부 패키징 |
| **MBE** | UHV + 정밀 셀(Knudsen cell) | 원자층 제어, 초고순도 | 화합물 반도체 연구/특수 소자 |
| **공통 장점** | 지향성 강함(소스가 점 → 직진) → **리프트오프 패터닝에 유리** | | |
| **공통 단점** | 스텝 커버리지 매우 나쁨, 합금/고융점 불가, 밀착력 낮음 | | |

## 3. 스퍼터(마그네트론 PVD) — 반도체 금속 증착의 주력

### 3-1. 원리 — "기화"가 아니라 "당구공"

```
   ① Ar 플라즈마를 만들고
   ② 타겟(증착할 금속)에 음전압을 걸어 Ar⁺ 이온을 가속해 충돌시킨다
   ③ 충돌 운동량이 표면 원자에 전달되어 원자가 튀어나온다(스퍼터링)
   ④ 튀어나온 중성 금속 원자가 웨이퍼에 도달해 막을 만든다

   → 재료를 "녹이거나 끓이지 않는다". 따라서 융점·증기압 제약이 사라진다.
      W(융점 3,422 ℃)도 상온의 타겟에서 스퍼터된다.
```

```
   [마그네트론 스퍼터 챔버 단면]

        ┌─────── 회전 마그넷 어셈블리 ───────┐  ← 자석을 회전시켜 타겟을 균일하게 소모
        │        (영구자석 + 요크)            │
        ╞════════════════════════════════════╡
        │  ███████ 타겟 (금속 원판) ███████   │ ← DC/펄스DC/RF 인가(음극), 배킹 플레이트에 본딩
        │  ▒▒▒ 배킹 플레이트 + 수냉 채널 ▒▒▒  │ ← 냉각이 필수(열로 타겟이 깨짐/녹음)
        ╞════════════════════════════════════╡
        │   다크 스페이스 실드 / 접지 실드      │ ← 이상 방전 방지, 퇴적물 포집(소모성)
        │      ░░░░ Ar 플라즈마 ░░░░           │  1 ~ 5 mTorr
        │   (선택) 콜리메이터 / 코일            │ ← 지향성·이온화 향상
        │   ███ 웨이퍼 ███                     │
        │   ESC 또는 히터/쿨링 척 + RF 바이어스 │ ← 바이어스로 재스퍼터·충진 제어
        │   엣지 클램프/실드                    │
        └────────────────┬───────────────────┘
               크라이오 펌프(H₂O 배기) + 터보/드라이
```

### 3-2. 모듈·부품 사전

| 부품 | 역할 | 문제 시 | 관리 |
|------|------|---------|------|
| **타겟** | 증착 재료 공급원(최대 소모품) | 소모에 따라 에로전 프로파일 변화 → **증착률·균일도 드리프트**. 노듈 생성 → 아킹·파티클 | kWh 카운트, 번인(burn-in), 교체 후 매칭 재확인 |
| **배킹 플레이트 + 본딩** | 타겟 지지·열 전달·전기 접촉 | 본딩 열화 → 국부 과열 → 타겟 크랙(치명적) | 본딩 품질(벤더 관리), 냉각수 유량 |
| **회전 마그넷** | 플라즈마를 타겟 면에 고르게 이동 | 정지/편심 → 국부 소모, 균일도 붕괴 | 회전 감시 |
| **다크스페이스/접지 실드** | 이상 방전 억제, 퇴적물 포집 | 퇴적막 박리 → 파티클, 절연 단락 | 누적 두께 기준 교체·재생 |
| **콜리메이터** | 비스듬한 원자를 걸러 **수직 성분만 통과** | 막힘 → 증착률 급감 | 소모성, 정기 교체 |
| **RF 코일 (IMP/ICP형)** | 금속 원자를 이온화 → 바이어스로 방향 제어 | 소모·코팅 | 교체 |
| **웨이퍼 척 (+ RF 바이어스)** | 온도 제어 + 이온 충격 제어 | 온도/바이어스 오차 → 충진·저항 변화 | He/척 상태 |
| **셔터(일부 장비)** | 초기 불안정 증착을 웨이퍼에 안 맞게 차단 | — | — |
| **크라이오 펌프** | H₂O 배기 (금속막 산화 방지의 핵심) | 재생 필요, 포화 | 재생 주기 |

### 3-3. 전원 방식 — 왜 DC만으로 안 되는가

| 방식 | 적용 | 이유 |
|------|------|------|
| **DC 마그네트론** | 금속 타겟(Al, Cu, Ti, Ta, W) | 도전성 타겟이므로 전류가 흐름. 단순·고속 |
| **RF 마그네트론** | 절연/저도전 타겟(산화물 타겟 등) | DC로는 절연 타겟에 전류를 못 흘림 → 표면 대전 → 방전 정지 |
| **펄스 DC** | 반응성 스퍼터(TiN, AlN, ITO 등) | 타겟 표면에 절연 화합물이 생겨 대전 → 아킹. 주기적으로 극성을 반전해 전하를 중화 |
| **HiPIMS (고출력 펄스)** | 고이온화가 필요한 경우 | 순간 고파워로 금속 이온화율↑ → 지향성·밀착력·충진 개선. 평균 파워 낮아 발열 제어 |
| **AC 듀얼 마그네트론** | 대면적(디스플레이 등) | 두 타겟이 교대로 음극/양극 |

### 3-4. 반응성 스퍼터 — TiN을 만드는 방법

```
   Ti 타겟 + Ar + N₂ → 웨이퍼에 TiN 증착
   문제: N₂가 많으면 타겟 표면에도 TiN이 생김 = "타겟 피독(poisoning)"
        → 스퍼터 수율이 떨어지고 증착률이 급감, 아킹 증가
   특성: 유량-특성 곡선에 히스테리시스가 존재(같은 N₂ 유량에서 두 상태가 가능)

   해결(장비):
    · 폐루프 제어: 플라즈마 발광(OES)이나 타겟 전압을 피드백해 N₂ 유량을 실시간 제어
    · 펄스 DC 로 대전 완화
    · 고속 제어 밸브
```

### 3-5. **합금·조성 문제를 스퍼터가 어떻게 해결하는가** (사용자 질문 정면 답변)

```
   [핵심 원리: 정상상태 표면 농축(steady-state surface enrichment)]

   Al-0.5%Cu 합금 타겟을 스퍼터한다고 하자.
   Cu 의 스퍼터 수율이 Al 보다 크다 → 처음에는 Cu 가 더 많이 빠져나간다
   → 타겟 표면의 Cu 농도가 감소(=상대적으로 Al 농축)
   → 그러면 Cu 가 빠져나가는 양이 줄어든다
   → 어느 시점에서 "빠져나가는 조성 = 타겟 벌크 조성" 이 되는 평형에 도달

   결론: 정상상태에서는 **막 조성 ≈ 타겟 조성** 이 된다.
         (증발과 정반대 — 증발은 증기압 차이가 계속 누적되어 조성이 어긋난다)
```

이것이 **합금 배선(AlCu, AlSiCu)과 화합물(TiN, TaN, TiAlN, ITO)을 스퍼터로 만드는 이유**입니다. 다만 실무에서는 조건이 붙습니다.

| 조건 | 내용 |
|------|------|
| **번인(burn-in) 필수** | 신품 타겟은 아직 정상상태 표면이 아님 → 정해진 kWh만큼 더미 방전으로 길들인 뒤 양산 투입 |
| **타겟 냉각 필수** | 타겟이 뜨거워지면 **확산과 국부 증발**이 일어나 정상상태가 깨짐 → 조성 변동 |
| **타겟 제조 품질** | 결정립 크기·집합조직(texture)·밀도·순도(5N ~ 6N)가 균일해야 조성·증착률이 균일 |
| **에로전 프로파일 변화 보정** | 타겟이 파이면서 방출 각도 분포가 변함 → 두께 프로파일 드리프트 → 수명 구간별 보정 |
| **다중 캐소드/공스퍼터** | 조성을 자유롭게 바꾸고 싶으면 타겟을 여러 개 두고 각각 파워 제어(예: TiAlN, 자성막) |

| 조성 구현 방법 | 장점 | 단점 |
|----------------|------|------|
| **합금 타겟 1개** | 조성 안정·간단, 양산 표준 | 조성을 바꾸려면 타겟을 새로 만들어야 함 |
| **다중 타겟 공스퍼터** | 조성을 파워로 튜닝 | 균일도·재현성 확보 난이도, 장비 복잡 |
| **반응성 스퍼터** | 질화물/산화물 생성 | 피독·히스테리시스 관리 필요 |

### 3-6. 스퍼터 수율 감각 (Ar⁺ 약 500 eV, 대략적인 값)

| 재료 | 스퍼터 수율 (원자/이온, 대략) |
|------|------------------------------|
| Cu | ~2.0 ~ 2.5 |
| Au | ~2.4 |
| Ni | ~1.5 |
| Al | ~1.0 |
| Cr | ~1.2 |
| Mo | ~0.8 |
| W | ~0.6 |
| Ta | ~0.6 |
| Ti | ~0.5 |
| Si | ~0.5 |

> 요점: 수율 차이는 있지만 **증기압처럼 자릿수로 벌어지지 않습니다**(증기압은 10⁶배 이상 차이가 흔함).
> 그래서 스퍼터는 조성을 지킬 수 있고, 증발은 못 지킵니다. **이것이 두 방법의 결정적 차이입니다.**

### 3-7. 고종횡비 홀에 금속을 넣는 기술 (지향성 확보)

```
   문제: 스퍼터 원자는 넓은 각도로 날아온다 → 좁은 홀 바닥에 잘 안 들어감
        (입구가 먼저 막혀 오버행 → 보이드)

   해결책 계보:
    ① 저압화 (충돌 감소 → 직진성 향상)
    ② 롱 스로우(long throw): 타겟-웨이퍼 거리를 늘려 비스듬한 성분이 챔버 벽으로 빠지게
    ③ 콜리메이터: 벌집 구조로 비스듬한 성분을 물리적으로 차단 (증착률 손실이 큼)
    ④ IMP (Ionized Metal Plasma): RF 코일로 금속 원자를 이온화 → 웨이퍼 바이어스로 수직 가속
    ⑤ SIP / 자기 이온화 스퍼터: 고파워에서 금속 이온이 스스로 플라즈마를 유지
    ⑥ HiPIMS: 순간 고출력 펄스로 이온화율 극대화
    ⑦ 재스퍼터(re-sputter): 웨이퍼 바이어스로 바닥/오버행을 다시 깎아 재분포
       → 바닥 커버리지와 시드 연속성 개선 (Cu 시드에서 필수 기법)
```

| 기법 | 얻는 것 | 대가 |
|------|---------|------|
| 콜리메이터 | 지향성 | 증착률 급감, 소모품 |
| IMP/SIP/HiPIMS | 지향성 + 밀착력 + 충진 | 장비 복잡, 열부하 |
| 재스퍼터 | 시드 연속성, 바닥 보강 | 시간, 측벽 손상 가능 |

## 4. PVD 클러스터 — 디개스와 프리클린이 왜 별도 챔버인가

```
   [Cu 배선용 PVD 클러스터 예]

     FOUP → EFEM → 로드락 →┬─▶ [디개스 챔버] 200~350 ℃ 가열, 진공
                            │      : 저유전막/포토 잔류 수분·용매를 미리 빼낸다
                            │        (이걸 안 하면 이후 챔버에서 가스가 나와 막질·진공 오염)
                            ├─▶ [프리클린 챔버] Ar 플라즈마 스퍼터 에치 or 원격 H₂/He 플라즈마
                            │      : 컨택 바닥의 자연산화막·잔류물 제거 → 접촉저항 확보
                            ├─▶ [배리어 챔버] TaN/Ta 또는 TiN 스퍼터(또는 ALD)
                            ├─▶ [시드 챔버] Cu 시드 스퍼터 (+ 재스퍼터)
                            └─▶ 냉각 → 로드락 → FOUP → (도금으로 이동)

   ★ 전부 "진공을 깨지 않고" 연속 수행한다.
     이유: 중간에 대기 노출되면 1초 안에 산화·수분 흡착이 일어나
           접촉저항↑, 배리어 특성↓, 밀착력↓ ([0-2장](00-2-vacuum.md) 참조)
```

| 챔버 | 역할 | 빠뜨리면 |
|------|------|----------|
| 디개스 | 아웃개싱 제거 | 막질 저하, 진공 회복 지연, 파티클 |
| 프리클린 | 자연산화막·폴리머 제거 | **컨택 저항 폭증**(수율 직결), 밀착 불량 |
| 배리어 | Cu 확산 차단 + 밀착 | Cu가 절연막·Si로 확산 → 소자 파괴 |
| 시드 | 도금 전류 경로 제공 | 도금 보이드, 미도금 |
| 냉각 | 반출 전 온도 하강 | FOUP 변형, 산화 |

## 5. 왜 Cu는 식각하지 않고 "채우는가" — 다마신 공정

```
   Al 배선 시대:  Al 전면 증착 → 포토 → 식각(Cl₂/BCl₃)으로 배선 모양 만들기 → 절연막 채움

   Cu 시대:       Cu 는 저온에서 휘발성 화합물을 만들지 않는다
                 (CuClx 는 증기압이 너무 낮아 플라즈마 식각이 실용적이지 않다)
                 → 식각 불가 → 방식을 완전히 뒤집는다

   [다마신 / 듀얼 다마신]
     ① 절연막에 트렌치(배선)와 비아(층간 연결)를 식각으로 먼저 만든다
     ② 배리어(TaN/Ta) + 시드(Cu) 를 PVD/ALD 로 입힌다
     ③ 전기도금(ECP)으로 Cu 를 과충전(overburden)한다
     ④ CMP 로 표면의 여분 Cu 와 배리어를 갈아내 배선만 남긴다 ([08장](08-cmp.md))
```

> **장비 관점의 의미**: Cu 도입은 **CMP 장비를 필수 설비로 만들었고, ECP 장비라는 새 카테고리를 낳았습니다.**
> "재료 물성(식각 불가)이 장비 구성을 바꾼" 가장 대표적 사례입니다.

## 6. Cu 전기도금(ECP) 장비 — 화학이 형상을 만든다

### 6-1. 구조

```
   [ECP 셀 (fountain 방식)]

        ┌──────── 웨이퍼 (아래를 향함, 회전) ────────┐
        │  ▓▓▓ 시드 Cu 면이 전해액에 접촉 ▓▓▓        │
        │  엣지 컨택 링 (전류 공급, 밀봉)             │ ← 음극(cathode). 접촉 저항 균일성이 핵심
        └──────────────┬──────────────────────────┘
                       │  ↑ 전해액 상향 분출(fountain), 패들/교반
        ┌──────────────┴──────────────────────────┐
        │   확산기(diffuser) / 이온 저항판(HRVA)     │ ← 전류 분포 균일화
        │   양극(anode): Cu 가용성 or 불용성 + 멤브레인│
        │   전해액: CuSO₄ + H₂SO₄ + Cl⁻ + 첨가제 3종  │
        └──────────────────────────────────────────┘
   주변 모듈: 프리웨트(진공 함침) · 도금 셀 ×N · 베벨/엣지 린스 · 세정/건조 · (인라인) 어닐
```

### 6-2. 부품·모듈 사전

| 모듈/부품 | 역할 | 문제 시 |
|-----------|------|---------|
| **프리웨트 (pre-wet)** | 진공 상태에서 웨이퍼를 적셔 홀 안 공기를 제거 | 기포 잔류 → **미도금 보이드** |
| **엣지 컨택 링** | 전류 공급 + 전해액 침입 차단 | 접촉 불균일 → 두께 편차, 링 열화 → 누액·오염 |
| **양극(anode)** | Cu 이온 공급 | 가용성 양극은 슬라임 발생 → 멤브레인 필요 |
| **이온 저항판/확산기** | 전류 분포 제어 | 엣지 과도 도금(terminal effect) |
| **패들/교반** | 물질 전달 촉진 | 교반 부족 → 고전류밀도에서 버닝(거친 도금) |
| **전해액 관리 유닛** | 조성·첨가제 농도 유지, 필터 | 첨가제 소모/분해 → **충진 실패**(보이드/심) |
| **정류기(파형 제어)** | DC/펄스/역펄스 | 결정립·충진·균일도 변화 |
| **베벨/엣지 린스** | 웨이퍼 외곽 Cu 제거 | Cu 오염 확산(팹 전체 리스크) |
| **어닐 모듈** | 결정립 성장(저항↓, 신뢰성↑) | 자기 어닐(self-anneal) 편차 |

### 6-3. 첨가제 3종 — "바닥부터 채우기(bottom-up superfill)"의 비밀

```
   전기도금을 그냥 하면 홀 입구가 먼저 자라 막혀 보이드/심(seam)이 생긴다.
   첨가제 3종이 이것을 뒤집는다:

   ① 억제제(Suppressor, 예: 폴리에틸렌글리콜 + Cl⁻)
      : 표면 전체에 흡착해 도금을 억제. 특히 "가스 교환이 활발한 입구·평지"에 잘 붙는다
   ② 촉진제(Accelerator, 예: 황화물 계열 SPS/MPSA)
      : 도금을 가속. 표면적이 줄어드는 홀 바닥에서 농도가 상대적으로 "농축"된다
        (CEAC: Curvature Enhanced Accelerator Coverage)
   ③ 평탄제(Leveler)
      : 돌출부의 성장을 선택적으로 억제해 표면을 평탄하게

   결과: 바닥이 가장 빨리 자라고 → 위로 밀려 올라오며 채워짐 = "슈퍼필"
        보이드도 심도 없는 완전 충진
```

| 첨가제 이상 시 | 증상 |
|----------------|------|
| 촉진제 부족 | 바닥 성장 느림 → 심(seam)/보이드 |
| 억제제 부족 | 입구 과성장 → 조기 폐색, 보이드 |
| 평탄제 부족 | 표면 거칠음, 오버버든 과다 → CMP 부담 |
| 분해 생성물 축적 | 도금 이상, 결함 | 

> **여기가 "화학이 장비 성능"인 대표 지점**입니다. ECP 장비의 진짜 실력은 **전해액 분석·보충 제어(CVS 등 분석법)** 에 있습니다.

### 6-4. 도금 후 처리

| 단계 | 이유 |
|------|------|
| **어닐(100 ~ 400 ℃)** | 도금된 Cu는 결정립이 작음 → 어닐로 성장시켜 비저항↓, EM 수명↑. 하지 않으면 상온에서 천천히 변하는 **자기 어닐**로 특성이 흔들림 |
| **베벨/백사이드 Cu 제거** | Cu는 강력한 오염원(Si 내 깊은 준위 트랩) → 웨이퍼 외곽·뒷면 Cu는 반드시 제거 |
| **CMP** | 오버버든과 배리어 제거 ([08장](08-cmp.md)) |
| **캡 형성** | SiCN 유전 캡 또는 CoWP 금속 캡 → Cu 표면 확산·EM 억제 |

### 6-5. 무전해 도금(electroless) — 전류 없이

| 특징 | 내용 |
|------|------|
| 원리 | 환원제를 포함한 용액에서 촉매 표면에서만 자발 환원 → 선택적 성장 |
| 장점 | 전류 경로(시드) 불필요, 선택적 캡(CoWP) 형성 가능 |
| 단점 | 용액 안정성, 선택성 관리, 오염 |
| 용도 | Cu 캡, 패키징 UBM(Ni/Au), 선택적 금속화 |

## 7. 텅스텐(W) — CVD로만 가능한 이유와 장비 이슈

```
   W 는 융점 3,422 ℃ → 증발 불가. 스퍼터는 가능하나 깊은 컨택 홀을 "채우기"는 불가.
   → 휘발성 전구체 WF₆ 를 이용한 CVD 가 정답

   반응:
    ① 핵생성(nucleation):  WF₆ + SiH₄  → W + SiF₄ + ...   (저온, 얇게, 매끄러운 초기층)
    ② 벌크 성장:           WF₆ + 3H₂   → W + 6HF          (400 ~ 450 ℃, 컨포멀·고속)
```

| 장비/공정 이슈 | 내용 | 대책 |
|----------------|------|------|
| **F가 Si를 공격** | WF₆/HF가 하부 Si·산화막을 침식 | **TiN 배리어 필수**(WF₆ 차단), 배리어 연속성 확보 |
| **볼케이노(volcano) 결함** | 배리어 결함부로 WF₆가 침투해 하부와 반응 → 화산 모양 융기 | 배리어 품질(ALD TiN), 프리클린 |
| **F 잔류** | 막 내 F가 신뢰성·접촉저항 악화 | **ALD W / 저F 핵생성(B₂H₆ 기반)**, 어닐 |
| **심(seam)/보이드** | 컨포멀 성장은 중앙에서 만남 → 심 발생 | **순환 증착-식각**, 저항 낮은 ALD W, 아래부터 채우는 화학 |
| **응력·비저항** | 두께 얇을 때 저항 급증(표면·입계 산란) | 결정립 제어, Mo 등 대체재 검토 |
| **배기 부식** | HF/WF₆ | 히팅 라인, 내식 배관, 스크러버 |

### 왜 W → Mo 전환이 논의되는가

```
   금속이 얇아질수록 비저항이 급격히 증가한다(전자의 표면/입계 산란).
   또한 W 는 반드시 배리어(TiN 등)를 필요로 하는데,
   배선 폭이 좁아지면 "배리어가 단면의 상당 부분"을 차지해 실효 저항이 커진다.

   Mo 는 ① 배리어 없이(또는 매우 얇게) 쓸 수 있고
        ② 얇은 두께에서 저항 증가가 상대적으로 작다
   → 3D NAND 워드라인, 일부 컨택에서 Mo 도입이 진행 중.
   전구체: MoCl₅, MoO₂Cl₂ 등 → **고체/저증기압 전구체 전달이 장비 과제**
   ( [0-3장](00-3-gas-and-fluids.md) 의 고체 앰플 승화·히팅 라인 문제가 그대로 등장 )
```

> **"재료마다 물성이 다르면 어떻게 하나"** 의 최신 버전이 바로 이 문제입니다.
> Mo 전구체는 상온에서 고체이고 증기압이 낮습니다. 그래서 장비는 **가열 앰플 + 승화 + 전 경로 히팅 + 압력 기반 전달 제어**로 대응합니다.
> 그리고 앰플 표면적이 줄며 공급량이 떨어지는 문제(depletion)까지 관리해야 합니다.

## 8. 배리어·라이너 — 왜 필요하고 왜 어려운가

| 재료 | 역할 | 만드는 방법 | 이슈 |
|------|------|-------------|------|
| **TaN / Ta** | Cu 확산 배리어(TaN) + Cu 밀착·젖음(Ta) | PVD(이온화), ALD | 두께 스케일링 한계 |
| **TiN** | W 컨택 배리어, 전극 | PVD, CVD(TiCl₄+NH₃), **ALD** | Cl 잔류, 스텝 커버리지 |
| **Co 라이너** | Cu 젖음성·EM 개선, 컨택 금속 | CVD/ALD/PVD | 비용, 계면 |
| **Ru 라이너** | Cu 직접 도금 가능(시드리스), 배리어리스 후보 | ALD/CVD (Ru 전구체) | 전구체 비용·산화 관리 |
| **왜 어려운가** | 배리어는 **얇아야**(저항 때문) 하지만 **완벽해야**(1 nm 결함도 Cu 확산 경로) 함 | — | ALD 가 사실상 유일한 해 |

> **Cu 확산이 왜 치명적인가**: Cu는 Si 내에서 확산이 빠르고 깊은 준위 트랩을 만들어 소수캐리어 수명을 파괴합니다.
> 한 번 오염되면 장비·팹 전체로 퍼집니다. 그래서 팹은 **Cu 사용 구역을 물리적으로 분리**하고, 베벨/백사이드 Cu 제거를 엄격히 관리합니다.

## 9. 실리사이드 — 금속과 Si를 반응시켜 만드는 층

```
   목적: 소스/드레인·게이트의 접촉 저항을 낮춘다

   [SALICIDE (Self-Aligned Silicide) 공정 — 장비 시퀀스]
    ① 프리클린 (자연산화막 제거) ── 없으면 반응 불균일
    ② Ni(Pt) 스퍼터 증착 + 캡(TiN) 증착   ← PVD 클러스터에서 연속
    ③ RTA 1 (저온): 금속-rich 상 형성 (예: Ni₂Si)
    ④ 선택적 습식 제거: 반응하지 않은 금속(산화막 위의 금속)만 제거 → **자기정렬**
    ⑤ RTA 2: 저저항 상으로 변환 (예: NiSi)
```

| 재료 | 특징 | 장비 관점 |
|------|------|-----------|
| **TiSi₂** | 과거 표준. C49 → C54 상변태 필요, 좁은 선폭에서 변태 어려움 | 두 번의 RTA, 상 제어 |
| **CoSi₂** | 중간 세대 | 얇은 접합에서 Si 소모 문제 |
| **NiSi (+Pt)** | 현재 주류. 저온 형성, Si 소모 적음 | **온도창이 좁다** → 과열 시 NiSi₂ 생성(고저항), 파이핑 결함. Pt 첨가로 열안정성 개선 |
| 장비 핵심 | 프리클린 청정도, 금속 두께 균일도, **RTA 온도 정밀도(±수 ℃)** | 방사율 보정·스파이크 프로파일 ([02장](02-oxidation-diffusion-thermal.md)) |

## 10. Al 배선 시대의 장비 기술 (여전히 쓰임)

| 기술 | 내용 | 이유 |
|------|------|------|
| **AlCu(0.5 %) 합금 타겟** | EM 수명 향상 | 순수 Al은 EM으로 단선 |
| **Ti/TiN 하부·상부층** | 젖음성·EM·반사 제어 | Al 응집 방지, 포토 반사 억제 |
| **핫 Al / 리플로우 스퍼터** | 고온(400 ~ 500 ℃)에서 Al이 표면 확산으로 흘러 홀을 채움 | 비아 충진 |
| **포스필/고압 리플로우** | 고압 Ar로 밀어 채움 | 보이드 제거 |
| **Al 스파이킹 방지** | Al이 Si로 확산해 접합을 관통 → Si 1 % 첨가 또는 배리어 | 접합 파괴 방지 |
| 현재 용도 | 파워/아날로그/레거시, 패드·재배선, 일부 이미지센서 | 저비용·단순 |

## 11. 장비 노브 ↔ 공정 결과

| 장비 | 노브 | 물리 | 결과 | 부작용 |
|------|------|------|------|--------|
| PVD | 파워(kW) | 스퍼터 플럭스 | 증착률 ↑ | 타겟 수명↓, 발열, 파티클 |
| PVD | 압력(Ar) ↓ | 충돌 감소 | 지향성 ↑, 바닥 커버리지 ↑ | 플라즈마 유지 한계, 증착률 ↓ |
| PVD | 타겟-웨이퍼 거리 ↑ | 각도 선별 | 지향성 ↑ | 증착률 ↓ |
| PVD | 웨이퍼 RF 바이어스 ↑ | 이온 충격 | 재스퍼터·충진 ↑, 밀착·밀도 ↑ | 측벽 손상, 하부 손상, 두께 감소 |
| PVD | 척 온도 | 표면 확산 | 리플로우·충진, 결정립 | 열버짓, 응집 |
| PVD | 반응성 가스(N₂) 유량 | 화합물 형성 | 조성·저항·응력 | 타겟 피독, 히스테리시스 |
| W-CVD | 핵생성 조건(SiH₄ vs B₂H₆) | 초기층 | F 잔류·저항·심 | 두께 손실 |
| W-CVD | 온도/압력 | 반응 속도 | 컨포멀리티·저항 | 심/보이드 |
| ECP | 전류 밀도·파형 | 도금 속도·결정립 | 충진·두께·거칠기 | 버닝, 보이드 |
| ECP | 첨가제 농도 | 흡착 경쟁 | **슈퍼필 성립 여부** | 보이드, 오버버든 |
| ECP | 교반/패들 | 물질 전달 | 고속 도금 가능 | 기포 |
| 실리사이드 | RTA 온도/시간 | 상 형성 | 시트 저항 | 상 이상(고저항), 파이핑 |

## 12. 불량과 장비 원인

| 파티클 급증(PVD) | 실드 퇴적물 박리, 타겟 노듈, 아킹 | 누적 두께, 아크 카운트, 타겟 표면 |

| 도금 두께 엣지 편중 | 컨택 링 접촉, 이온저항판, terminal effect | 링 상태, 전류 분포 설정 |

| W 볼케이노 결함 | 배리어 결함 | ALD TiN 품질, 프리클린, 단면 분석 |
| 실리사이드 시트 저항 이상 | RTA 온도, 프리클린, 금속 두께 | thermal wafer 검증, 두께 측정, 상 분석(XRD) |
| 전구체 공급 불안정(Mo/Ru) | 앰플 온도·잔량, cold spot | 히팅 프로파일, 앰플 교체 주기, 압력 기반 전달 |
| EM/신뢰성 불량 | 결정립(어닐 부족), 캡 품질, 배리어 | 어닐 조건, 캡 공정, 단면 TEM |

## 13. 최근 동향

| 동향 | 내용 |
|------|------|
| **배선 금속 다변화** | Cu 한계(배리어 비중, 비저항 상승) → **Ru, Mo, Co** 도입. 각 금속마다 전구체·전달 장비 과제 |
| **배리어리스/시드리스** | Ru 위에 직접 Cu 도금, Mo 배리어리스 → 실효 단면 확보 |
| **ALD 금속 확대** | 초박막·컨포멀 요구 → ALD W/TiN/Ru/Mo |
| **선택적 금속 증착** | 특정 표면에만 성장 → 자기정렬, 리소 부담 완화 |
| **하이브리드 본딩용 Cu** | 나노미터급 리세스 제어와 어닐 팽창 정밀 제어 ([11장](11-packaging.md)) |
| **패키징 도금 확대** | 마이크로범프, RDL, TSV 도금 → ECP 장비 수요 증가 |
| **저온화** | 3D 적층에서 금속 공정 온도 제한(400 ℃ 이하) |
