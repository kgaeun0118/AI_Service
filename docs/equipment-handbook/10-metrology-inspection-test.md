# 10. 계측·검사·테스트 장비 — 보이지 않는 것을 보는 기술

> 선행 학습: [0-7 센서·제어·데이터](00-7-sensors-and-control.md)
> 다루는 장비: 엘립소미터/반사계 · **OCD(스캐터로메트리)** · **CD-SEM** · 오버레이 계측기 · **결함 검사기(광학 BF/DF, e-beam)** · XRF/XRD · 4점 탐침 · AFM · 웨이퍼 지오메트리 · **프로버 + ATE(EDS)** · 전기 특성 평가(PCM/WAT)

---

## 1. 계측과 검사는 다른 일이다

| 구분 | **계측 (Metrology)** | **검사 (Inspection)** |
|------|----------------------|----------------------|
| 질문 | "얼마인가?" (두께 12.3 nm, CD 18.5 nm) | "이상한 게 있나?" (결함 위치·개수·종류) |
| 대상 | 정해진 위치의 정량 값 | 웨이퍼 전면의 예외 사건 |
| 결과 활용 | 공정 제어(R2R), SPC | 수율 문제 원인 추적, 장비 상태 판정 |
| 대표 장비 | 엘립소미터, OCD, CD-SEM, 오버레이 | 광학 결함 검사기, e-beam 검사, 파티클 카운터 |
| 샘플링 | 웨이퍼 수 점 ~ 수십 점 | 전면(또는 넓은 영역) 스캔 |

그리고 세 번째 축이 있습니다.

| **테스트 (Test)** | 완성된 소자가 전기적으로 동작하는가? |
|-------------------|--------------------------------------|
| 장비 | 프로버 + ATE(웨이퍼 테스트/EDS), PCM/WAT 측정 |
| 결과 | 굿/배드 다이 맵, 파라미터 분포 → 수율과 직결 |

## 2. 왜 이렇게 많은 계측이 필요한가

```
   공정 하나가 끝나면 우리는 "웨이퍼 속을 볼 수 없다".
   깨서 단면을 보면(SEM/TEM) 정확하지만 그 웨이퍼는 버려진다(파괴 검사).

   → 양산에서는 **비파괴 + 인라인 + 빠른** 측정이 필요하다.
   → 그래서 대부분의 계측은 "간접 측정 + 모델 피팅"이다.
      (빛의 반사·산란·회절을 재고, 모델로 역산해서 두께·CD를 얻는다)

   이 사실이 실무에서 아주 중요하다:
    · 모델이 틀리면 값도 틀린다 (실제와 다른 값을 자신 있게 보고한다)
    · 그래서 TEM/AFM 같은 기준 측정(reference)으로 주기적 교정이 필요하다
```

## 3. 막 두께·조성 계측

| 장비 | 원리 | 측정 대상 | 한계 |
|------|------|-----------|------|
| **엘립소미터** | 편광된 빛의 반사 시 위상·진폭 변화(Δ, Ψ) 측정 → 광학 모델 피팅 | 투명막 두께·굴절률(n, k) | 금속·불투명막 불가, 모델 의존, 다층은 상관성 문제 |
| **반사계(reflectometer)** | 파장별 반사율 스펙트럼 피팅 | 투명막 두께 | 상동 |
| **XRF (형광 X선)** | 원소 고유 형광 X선 강도 | **금속막 두께·조성**(Cu, W, Ti, Ta 등) | 박막 하한, 조성 분리 |
| **XRD (X선 회절)** | 결정 회절 | 결정상·배향·응력 | 시간, 결정성 필요 |
| **XRR (X선 반사)** | 저각 반사 | 초박막 두께·밀도·거칠기 | 느림, 주로 참조용 |
| **4점 탐침 / 비접촉 시트저항** | 전류-전압 | 시트 저항(도핑·금속) | 접촉 손상(4PP), 패턴 제약 |
| **FTIR** | 적외 흡수 | Si 중 산소·탄소, 막 조성(Si-H 등) | 감도 |
| **SIMS (오프라인)** | 이온 스퍼터 + 질량분석 | 도핑 깊이 프로파일 | 파괴, 느림 |
| **TEM/STEM (오프라인)** | 투과전자 | 원자 수준 단면 구조 | 파괴, 시료 준비 오래 |

## 4. CD와 형상 계측 — 가장 치열한 영역

### 4-1. CD-SEM

```
   전자빔을 웨이퍼 표면에 주사하고 2차 전자를 검출해 이미지를 만든 뒤,
   신호 프로파일에서 에지를 정의해 선폭(CD)을 산출한다.

   장점: 직접 보인다(이미지), 다양한 형상 대응, 표준적
   단점/주의:
    · 전자빔이 레지스트를 수축시킴(shrinkage) → 반복 측정 시 값이 변함
      → 저가속·저도즈 조건, 1회 측정 원칙
    · 차징(절연막) → 이미지 왜곡
    · 에지 정의 알고리즘에 따라 값이 달라짐 → "측정 레시피"가 곧 정의
    · 단면 정보 없음(측벽 각도·높이는 간접)
```

### 4-2. OCD / 스캐터로메트리

```
   주기적 패턴(격자)에 빛을 쏘고, 회절·산란 스펙트럼을 측정한 뒤
   광학 모델(RCWA 등)로 "CD, 높이, 측벽각, SWA, 층 두께"를 동시에 역산한다.

   장점: 비파괴, 빠름, **3D 형상 파라미터를 동시에** 얻음, 측정 반복성 우수
   단점: 전용 측정 패턴(타깃) 필요, 모델 개발 부담, 상관성(파라미터 간 혼동) 문제
   실무: OCD로 대량 측정 + CD-SEM/TEM으로 주기 검증하는 **하이브리드 메트롤로지**가 표준
```

### 4-3. AFM / 기타

| 장비 | 용도 |
|------|------|
| **AFM** | 표면 거칠기, 단차, 나노토폴로지, CMP 후 표면. 느리지만 기준 측정 |
| **SEM 단면(오프라인)/FIB** | 실제 프로파일 확인. 파괴 |
| **TEM** | 최종 기준. 원자 수준 |
| **전기적 CD(전기저항 기반)** | 실효 CD 추정 |

## 5. 오버레이 계측

| 방식 | 원리 | 특징 |
|------|------|------|
| **IBO (Image Based Overlay)** | 두 층의 마크 이미지를 광학으로 찍어 중심 간 거리 측정 | 직관적, 프로세스 영향 받기 쉬움 |
| **DBO (Diffraction Based Overlay)** | 두 층에 겹친 격자의 회절 비대칭에서 오버레이 산출 | 정밀·반복성 우수, 타깃 설계 필요 |
| **SEM 기반 오버레이** | 실제 소자 패턴에서 직접 | 느림, 검증용 |
| 실무 이슈 | **계측 편향(bias)**: 프로세스에 의해 마크가 변형되면 측정값이 실제와 다름 → 여러 파장·타깃으로 교차 검증 |

결과는 [03장](03-photolithography.md)의 스캐너 보정(R2R)으로 되돌아갑니다.

## 6. 결함 검사 — 웨이퍼 전면을 훑는 장비

| 장비 | 원리 | 잡는 것 | 특징 |
|------|------|---------|------|
| **비패턴(bare) 표면 검사기** | 레이저 산란 | 파티클, 스크래치, COP | **장비 파티클 qual의 표준 도구**. 빠름 |
| **패턴 웨이퍼 광학 검사기 (BF/DF)** | 명시야/암시야 이미지 비교(다이 대 다이, 셀 대 셀) | 파티클, 브릿지, 미싱, 잔류 | 빠름. 해상 한계(광학) |
| **e-beam 검사(EBI)** | 전자빔 이미지 + 전압 콘트라스트 | **미세 결함, 전기적 결함(오픈/쇼트)** — 광학이 못 보는 것 | 느림 → 다중빔으로 개선 중 |
| **매크로 검사** | 저배율 전면 | 코팅 불량, 엣지, 대면적 이상 | 빠름 |
| **엣지/베벨 검사** | 전용 광학 | 엣지 결함·박리 | 파티클 근원 관리 |
| **리뷰 SEM** | 검사에서 나온 좌표를 고배율로 재촬영 | 결함 분류(ADC) | 원인 규명에 필수 |
| **EDX/EDS(리뷰 SEM 부착)** | 특성 X선 | **결함의 원소 조성** → 발생 부품 지목 | [0-8장](00-8-parts-and-consumables.md) |

### 결함 원인 추적의 실전 논리

```
 ① 검사로 결함 좌표 맵을 얻는다
 ② 맵의 "패턴"을 본다
      · 동일 다이 내 동일 좌표 반복      → 마스크/레티클 기인
      · 웨이퍼 전면 랜덤                → 파티클/케미컬/환경
      · 링/방사형/특정 방향             → 장비 시그니처(회전/스캔/가스 흐름)
      · 엣지 편중                      → 엣지 링/척/베벨/반송
      · 특정 슬롯/특정 웨이퍼만          → FOUP/반송/특정 스테이션
 ③ 리뷰 SEM으로 형태 분류 + EDX로 조성 분석
 ④ 조성 → 부품/재료 지목 (예: Y → 이트리아 코팅, Al+F → 아노다이징, C → 폴리머/O링, Cu → 오염)
 ⑤ 장비 이력(PM·부품 교체·레시피 변경)과 시간 상관 분석 → 원인 확정
```

> 이 5단계가 팹 수율 엔지니어링의 핵심 루프입니다. **"맵 패턴 + 조성"이 원인을 지목합니다.**

## 8. 웨이퍼 테스트(EDS) — 프로버와 테스터

```
 ┌──────────────── 웨이퍼 테스트 셀 ────────────────┐
 │                                                 │
 │   [ATE (테스터)]  ── 테스트 헤드 ── [프로브 카드] │
 │    · 패턴 생성·전압/전류 인가·응답 판정             │
 │                                 │ (수천 개 핀)   │
 │                                 ▼               │
 │   [프로버]                   웨이퍼 패드/범프에 접촉│
 │    · 웨이퍼 척(온도 제어: -40 ~ +150 ℃ 급)        │
 │    · XYZθ 정밀 스테이지 + 광학 정렬                │
 │    · 인덱싱(다이 단위 이동) + 터치다운              │
 │    · 웨이퍼 로더(FOUP), 니들 클리닝 유닛            │
 └─────────────────────────────────────────────────┘
   결과: 다이별 굿/배드 맵 → 잉크리스 맵(전자 기록) → 조립 단계로 전달
```

| 부품 | 역할 | 이슈 |
|------|------|------|
| **프로브 카드** | 테스터와 다이를 전기적으로 연결 | 종류: 캔틸레버 / **버티컬** / **MEMS**. 미세 피치·다핀·고주파로 갈수록 MEMS 필수. 고가·소모성 |
| **프로브 니들/팁** | 패드에 접촉 | 마모·오염 → 접촉 저항 상승(오판정). **니들 클리닝** 주기 관리 |
| **웨이퍼 척(온도)** | 고온/저온 테스트 | 온도 정확도, 결로 방지(저온) |
| **정렬 광학** | 패드와 니들 정렬 | 미스얼라인 → 패드 손상(probe mark) |
| **터치다운 제어** | 접촉 압력·오버드라이브 | 과도하면 패드 손상/크랙, 부족하면 접촉 불량 |
| **테스터(ATE)** | 전기 시험 | 채널 수·속도가 비용 지배. 병렬 테스트(멀티사이트)로 원가 절감 |

### 무엇을 테스트하는가

| 단계 | 내용 |
|------|------|
| **PCM / WAT (Wafer Acceptance Test)** | 스크라이브 라인의 테스트 소자로 공정 파라미터 측정(문턱전압, 저항, 커패시턴스, 누설) → **공정 건전성 판정** |
| **웨이퍼 테스트(EDS/Sort)** | 실제 칩 기능·속도·누설 테스트 → 굿/배드, 등급(빈) 분류 |
| **리페어** | 메모리는 여분 셀로 결함 셀을 대체(레이저/전기적 퓨즈) → **수율 회복 공정** |
| **KGD (Known Good Die)** | HBM/칩렛처럼 다이를 적층할 때는 **적층 전에 양품임을 보장**해야 함 → 웨이퍼 테스트의 중요성이 급상승 ([11장](11-packaging.md)) |

> **HBM 시대의 변화**: 12단 적층에서 1개 다이가 불량이면 전체가 폐기됩니다.
> 그래서 웨이퍼 테스트(KGD 확보)와 적층 중간 테스트가 원가를 지배합니다. 테스트 장비가 "부가 공정"에서 **핵심 공정**으로 올라간 이유입니다.

## 9. 계측 전략 — 무엇을 어디서 얼마나 재는가

| 개념 | 내용 |
|------|------|
| **샘플링 계획** | 전수 측정은 불가능(시간·비용) → 로트당 1 ~ 3장, 웨이퍼당 5 ~ 49점 등으로 설계 |
| **측정 지점 선정** | 센터/엣지/중간, 특정 다이 위치. 장비 시그니처가 나타나는 위치를 포함해야 의미 있음 |
| **게이지 R&R** | 측정계 자체의 산포 검증. **공정 산포보다 측정 산포가 크면 관리 불가** |
| **하이브리드 메트롤로지** | OCD(대량) + CD-SEM/TEM(검증) 조합 |
| **가상 계측(VM)** | 장비 트레이스로 결과 예측 → 계측 부하 절감 ([0-7장](00-7-sensors-and-control.md)) |
| **결함 샘플링** | 검사 전수 스캔은 느림 → 핫스팟 위치 위주 스캔, 주기적 전면 스캔 |
| **매칭** | 같은 모델 계측기 간 값 일치(툴 매칭). 다르면 SPC가 엉킨다 |

## 10. 불량과 장비 원인 (계측/검사 관점)

| 증상 | 의심 | 확인 |
|------|------|------|
| 측정값 산포 급증 | **계측기 문제 우선** | 동일 웨이퍼 반복 측정(R&R), 표준 시료 |
| 두께값이 실제와 다름 | 광학 모델(n,k), 하부막 변경 | 모델 재구축, TEM/XRR 대조 |
| CD-SEM 값이 반복 측정마다 감소 | 레지스트 수축 | 저도즈 조건, 1회 측정 |
| 오버레이 측정과 실제 불일치 | 마크 변형(프로세스 유발 bias) | 파장·타깃 교차 검증 |
| 결함 수가 갑자기 0에 가까움 | 검사 감도 설정·레시피 오류 | 표준 결함 웨이퍼로 감도 확인 |
| 노이즈 결함(false count) 폭증 | 표면 거칠기·막 변경, 감도 | 레시피 재조정 |
| 프로버 접촉 불량 | 니들 오염/마모, 오버드라이브 | 클리닝, 카드 점검, 접촉 저항 |
| 프로브 마크 과대 | 정렬·압력 | 정렬 확인, 오버드라이브 하향 |
| 테스트 수율이 특정 위치에서 낮음 | 공정 시그니처 or 테스트 하드웨어 | 맵 패턴 비교, 카드 채널 점검 |

## 11. 최근 동향

| 동향 | 내용 |
|------|------|
