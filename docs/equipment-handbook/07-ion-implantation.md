# 07. 이온주입 장비 — 이온 하나하나를 세는 기계

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-4 플라즈마](00-4-plasma-and-rf.md), [02 열처리](02-oxidation-diffusion-thermal.md)
> 다루는 장비: **중전류 임플란터 · 고전류 임플란터 · 고에너지 임플란터 · PLAD(플라즈마 도핑) · 크라이오/분자 임플란트**

## 1. 공정이 장비에 요구하는 것

이온주입은 **원자를 이온화해 전기장으로 가속하고, 웨이퍼에 박아 넣어 도핑하는 공정**입니다. 요구는 5개입니다.

| 요구 | 의미 | 정량 감각 |
|------|------|-----------|
| **도즈 정확도** | 단위 면적당 주입된 이온 수 | 목표의 ±0.5 % 이내 재현. 도즈는 시트 저항 → 트랜지스터 특성 직결 |
| **에너지 정확도/순도** | 주입 깊이를 결정 | 수백 eV ~ MeV. **에너지 오염(원하지 않는 에너지 이온)** 이 접합을 망친다 |
| **종(species) 순도** | 원하는 이온만 | 질량 분석으로 분리. 오염 이온 하나가 특성 변화 |
| **균일도** | 웨이퍼 내 ±0.5 % 급 | 빔 스캔·웨이퍼 스캔 정밀도 |
| **무손상/무오염** | 금속 오염, 차징 손상, 파티클 | 빔라인 부품에서 스퍼터된 금속이 함께 박히면 치명적 |

```
   도즈 계산의 기본:

      Dose [ions/cm²] = ∫ I dt / (q · n · A)

      I : 빔 전류, q : 전자 전하, n : 이온의 전하 상태(1+, 2+ …), A : 면적
   → 즉 **"전류를 시간으로 적분해 이온 수를 센다"** 는 것이 임플란터의 본질.
     그래서 임플란터는 근본적으로 "정밀 전류계 + 가속기"다.
```

## 2. 변천사

| 시기 | 기술 | 이유 |
|------|------|------|
| 1960 ~ 70s | 확산(diffusion) 도핑이 주류, 임플란트는 보조 | 장비 가격·처리량 |
| 1970s | 임플란트 상용화 | **도즈와 깊이를 독립적으로 정확히 제어** 가능(확산은 불가) |
| 1980s | 중전류/고전류 구분, 배치(디스크) 방식 | 처리량 |
| 1990s | **단일 웨이퍼 + 정전 스캔**, 질량분석 고도화 | 300 mm 전환, 균일도, 오염 관리 |
| 2000s | **저에너지 고전류**(USJ, 초얕은 접합), 디셀 모드 | 미세화 → 접합이 극도로 얇아짐 |
| 2000s ~ | **PLAD/PIII(플라즈마 도핑)** | 초저에너지 고도즈, 3D 구조 컨포멀 도핑 |
| 2010s ~ | **크라이오 임플란트, 분자(클러스터) 이온, 탄소 공주입** | 결함/확산 제어, 비정질화 제어 |
| 현재 | 3D 구조 도핑(FinFET/GAA), 고에너지(이미지센서/파워), SiC 임플란트 | 구조·응용 다양화 |

> **왜 확산 대신 임플란트인가**:
> 확산은 "표면에 도펀트를 붙이고 열로 밀어넣는" 방식이라 **농도와 깊이를 따로 조절할 수 없습니다**(둘 다 온도·시간에 묶임).
> 임플란트는 **에너지 = 깊이**, **전류×시간 = 농도** 로 **완전히 분리 제어**됩니다. 이것이 결정적 이점입니다.

## 3. 장비 전체 구조 — 빔라인이라는 이름의 가속기

```
 ┌── ① 이온 소스 ──┐   ② 추출/집속      ③ 질량 분석         ④ 가속/감속
 │  가스: BF₃, PH₃,│   ┌──────────┐   ┌──────────────┐   ┌──────────────┐
 │  AsH₃, GeF₄ 등  │   │ 추출 전극 │   │  분석 마그넷   │   │  가속 컬럼    │
 │  아크 챔버       │──▶│ (수 ~ 수십│──▶│  (90° 정도로  │──▶│ (다단 전극,   │
 │  필라멘트/RF     │   │  kV)     │   │   빔을 휨)    │   │  수 kV~MV)   │
 │  자기장          │   │ 서프레션  │   │  + 분해 슬릿   │   │  또는 감속(디셀)│
 └─────────────────┘   └──────────┘   └──────────────┘   └──────────────┘
                                             │                    │
                                             ▼                    ▼
                        ⑤ 빔 정형/스캔                ⑥ 프로세스 챔버
                    ┌────────────────────┐      ┌──────────────────────────┐
                    │ 사중극 렌즈(집속)     │      │ 웨이퍼 (틸트/트위스트 가능) │
                    │ 정전 스캐너(빔을 부채 │─────▶│ 플라즈마 플러드 건(중화)    │
                    │ 꼴로 흔듦) + 평행화   │      │ 패러데이 컵(도즈 측정)      │
                    │ 에너지 필터(중성 제거)│      │ 웨이퍼 스캔(기계적 상하)    │
                    └────────────────────┘      └──────────────────────────┘

  전 구간 진공: 10⁻⁶ ~ 10⁻⁷ Torr  (이유는 4절)
  전 구간에 X선 차폐, 고전압 안전 인터락
```

### 3-1. 모듈·부품 사전

| 모듈 | 부품 | 역할 | 문제/소모 |
|------|------|------|-----------|
| **이온 소스** | 아크 챔버, 필라멘트(또는 IHC 캐소드/RF 안테나), 리펠러, 소스 자석, 가스/증기 공급 | 도펀트 가스를 플라즈마화 → 이온 생성 | **최대 소모품**. 필라멘트 소모, 아크 챔버 내부 증착·스퍼터, 수명 후 빔 전류 저하 → 정기 교체(수일~수주) |
| **고체 증기 소스(베이퍼라이저)** | 가열 오븐(예: 고체 B, Sb, In, C 소스) | 고체를 승화시켜 공급 | 온도 제어, 응축(cold spot) |
| **추출(extraction) 전극** | 추출·서프레션 전극, 아퍼처 | 플라즈마에서 이온을 뽑아 가속 | 스퍼터 마모 → 빔 형상 변화, 파티클 |
| **분석 마그넷** | 대형 전자석, 자기장 제어 | **질량/전하 선별**(m/q에 따라 곡률 반경 다름) | 자장 안정성, 냉각 |
| **분해 슬릿(resolving slit)** | 슬릿 | 원하는 종만 통과 | 마모, 오염 → 종 순도 저하 |
| **가속/감속 컬럼** | 다단 전극, 절연체, 고전압 전원 | 에너지 부여(또는 감속) | 절연체 오염 → 방전, 고전압 안정성 |
| **사중극/아인젤 렌즈** | 정전·자기 렌즈 | 빔 집속·정형 | 정렬 |
| **정전 스캐너** | 편향 전극 | 빔을 부채꼴로 고속 주사 | 파형 정확도 = 균일도 |
| **평행화 렌즈(collimator/P-lens)** | 정전/자기 | 부채꼴 빔을 평행 빔으로 | 각도 오차 = 틸트 오차 |
| **에너지 필터 (EF/AEF)** | 굽힘 + 슬릿 | 중성 입자·잘못된 에너지 이온 제거 → **에너지 오염 차단** | 필수 부품 |
| **패러데이 컵** | 전류 측정기(여러 위치) | 실시간 도즈 측정·폐루프 | 오염·2차전자 보정 |
| **플라즈마 플러드 건(PFG)** | 저에너지 전자·플라즈마 공급 | **차징 중화** | 없으면 게이트 파괴 |
| **웨이퍼 플래튼/스캔** | 척, 틸트/트위스트 구동, 기계 스캔 | 위치·각도 제어 | 파티클, 각도 정확도 |
| **그래파이트 부품(라이너/아퍼처)** | 빔이 닿는 부위를 저오염 재료로 | **금속 오염 차단** | 소모, 파티클 |
| **진공 펌프군(크라이오+터보)** | 고진공 유지 | 광재 아웃개싱 대응 | 재생 주기 |
| **X선 차폐** | 납/차폐 구조 | 고에너지 전자 제동방사 차폐 | 정기 점검, 법적 관리 |

## 4. 왜 임플란터는 고진공(10⁻⁶ ~ 10⁻⁷ Torr)이 필요한가

```
  ① 빔 손실 방지
     이온이 수 m 빔라인을 지나는 동안 잔류 가스와 충돌하면 산란·손실 → 전류 저하

  ② ★ 전하 교환(charge exchange) 방지 — 가장 중요
     B⁺ + 잔류가스 → B⁰ (중성) 또는 B²⁺ 로 전하 상태가 바뀐다
     · 중성이 되면 자기장·전기장에 반응하지 않아 그대로 직진 → 원치 않는 에너지로 웨이퍼 도달
     · 특히 "감속(decel) 모드"에서 심각: 감속 전에 중성화된 입자는 감속되지 않고
       높은 에너지를 그대로 유지한 채 박힘 = **에너지 오염(energy contamination)**
     · 결과: 의도보다 깊은 꼬리 프로파일 → 접합 깊이·누설 특성 이상
     → 대책: 압력을 극도로 낮추고, **에너지 필터(굽힘+슬릿)로 중성 입자를 물리적으로 제거**

  ③ 도즈 측정 정확도
     잔류 가스가 이온화되면 패러데이 컵이 읽는 전류에 오차가 생긴다

  ④ 오염 억제
     잔류 탄화수소·수분이 웨이퍼 표면에 들어가면 도핑·계면 특성 악화

  덧붙여: 포토레지스트를 마스크로 쓰기 때문에 **레지스트 아웃개싱(H₂, 탄화수소)** 이 대량 발생한다
  → 임플란터는 "웨이퍼가 가스를 뿜는 장비"이며, 이 때문에 강력한 배기(크라이오)가 필요하다
```

## 5. 임플란터의 3종 분류 — 왜 나뉘는가

| 종류 | 에너지 | 빔 전류 | 용도 | 특징 |
|------|--------|---------|------|------|
| **중전류 (Medium Current)** | 수 keV ~ 수백 keV | µA ~ 수 mA | 웰, 채널, 임계전압 조정, 할로 | 정밀 각도 제어, 저오염, 정전 스캔 |
| **고전류 (High Current)** | 수백 eV ~ 수십 keV | 수 mA ~ 수십 mA | 소스/드레인, 폴리 도핑(고도즈) | **공간 전하 반발(space charge)** 때문에 저에너지 대전류 수송이 어렵다 → 빔라인 설계가 핵심 |
| **고에너지 (High Energy)** | 수백 keV ~ MeV | 낮음 | 딥 웰, 이미지센서, 파워소자, 리트로그레이드 웰 | RF 선형가속기(LINAC) 또는 탠덤 방식, 강한 X선 차폐 |

### 저에너지 고전류가 어려운 이유 (공간 전하 문제)

```
   같은 극성 이온끼리는 서로 밀어낸다(쿨롱 반발).
   에너지가 낮으면 이온 속도가 느려 빔 안에 이온이 오래 머문다 → 밀도 ↑ → 반발 ↑
   → 빔이 퍼져(blow-up) 전류 손실, 각도 흐트러짐

   대책:
    · 플라즈마 전자로 빔을 중화(빔 플라즈마 형성) → 반발 억제
    · 감속(decel) 방식: 높은 에너지로 수송하고 웨이퍼 직전에 감속
      → 대신 전하교환에 의한 에너지 오염 위험 (그래서 에너지 필터 필수)
    · 분자/클러스터 이온 사용: 예를 들어 B 대신 B₁₈Hₓ 같은 큰 분자를 주입
      → 같은 에너지에서 원자당 에너지가 작아져 "저에너지 효과"를 얻고 전류는 크게 유지
```

## 6. 각도가 중요한 이유 — 채널링, 섀도잉, 틸트/트위스트

```
  [채널링(channeling)]
   결정 격자에는 원자가 비어 보이는 "복도(channel)"가 있다.
   이온이 그 방향으로 들어가면 충돌이 적어 훨씬 깊이 박힌다
   → 깊이 프로파일에 긴 꼬리 → 접합 깊이 제어 실패

   대책:
    · 틸트(tilt, 기울임) 7° 정도 + 트위스트(twist, 회전) 조합으로 채널 방향을 피한다
    · 사전 비정질화(PAI: Ge/Si 주입으로 표면을 비정질화) → 격자 규칙성 제거
    · 스크린 산화막

  [섀도잉(shadowing)]
   틸트를 주면 마스크(레지스트/게이트)의 그림자가 생겨 한쪽만 덜 주입된다
   → 트랜지스터 좌우 비대칭
   대책: 트위스트를 나눠 여러 방향에서 주입(예: 4회전 쿼드 주입)

  [3D 구조(FinFET/GAA)]
   핀 측벽에 도핑하려면 비스듬히 넣어야 하지만, 이웃 핀이 그림자를 만든다
   → 각도 창이 매우 좁다 → PLAD(컨포멀 플라즈마 도핑)나 고체 소스 확산 대안 검토
```

## 7. 차징(charging)과 플라즈마 플러드 건

```
   이온 빔은 전하를 나른다. 웨이퍼 표면이 절연막으로 덮여 있으면 전하가 쌓인다.
   → 표면 전위 상승
     ① 이후 들어오는 이온을 반발·편향 → 도즈·균일도 오차
     ② 게이트 산화막에 과도 전압 → **절연막 파괴(안테나 효과)**

   해결: 플라즈마 플러드 건(PFG) / 전자 샤워
     · 저에너지 전자를 대량 공급해 표면을 중화
     · 전자 에너지가 너무 높으면 오히려 음전하 축적/손상 → 정밀 튜닝 필요

   또한 설계 규칙(안테나 룰)로 회로 측에서도 방어한다.
```

## 8. 도즈 제어와 균일도 — 어떻게 ±0.5 %를 맞추나

| 방법 | 원리 |
|------|------|
| **패러데이 컵 폐루프** | 웨이퍼 주변/후방 컵으로 빔 전류를 실시간 측정 → 스캔 속도 또는 스캔 횟수를 조절해 적분 도즈를 목표에 맞춤 |
| **정전 스캔 + 기계 스캔** | 빔을 수평으로 고속 정전 주사 + 웨이퍼를 수직으로 기계 이동 → 전면 커버 |
| **빔 프로파일 측정** | 스캔 전에 빔 형상·각도를 측정해 보정 |
| **2차 전자 보정** | 이온 충돌로 튀는 2차 전자가 전류 측정을 왜곡 → 서프레션 전극/전자 억제 |
| **각도 측정/보정** | 빔 평행도(각도 산포)가 프로파일을 바꿈 → 정기 측정 |
| **후 계측** | 시트 저항(4점 탐침) 맵 또는 광학적 도즈 측정(TW: thermal wave) 으로 검증 |

> 실무: **시트 저항 맵의 패턴**이 원인을 지목합니다. 스트라이프 = 스캔 문제, 좌우 비대칭 = 각도/섀도잉, 링 = 회전/플래튼, 전체 오프셋 = 도즈/캘.

## 9. PLAD (플라즈마 도핑) — 빔라인이 없는 임플란터

```
   웨이퍼를 플라즈마에 노출하고, 웨이퍼에 고전압 음펄스를 인가
   → 시스 전기장으로 이온이 웨이퍼로 수직 가속되어 주입

   장점: · 초저에너지 + 초고도즈를 매우 빠르게 (처리량 압도적)
        · 3D 구조 측벽에도 비교적 컨포멀하게 도핑 가능
   단점: · 질량 분석이 없어 **종 순도가 낮다**(원하지 않는 이온도 들어감)
        · 에너지 분포가 넓다, 도즈 정확도가 빔라인 방식보다 떨어짐
        · 표면 손상·오염 관리 필요
   용도: 고도즈 S/D, 3D 구조, 태양전지/파워 일부
```

## 10. 크라이오/분자 임플란트 등 최신 기법

| 기법 | 원리 | 얻는 것 |
|------|------|---------|
| **크라이오 임플란트** | 웨이퍼를 저온(예 −60 ~ −100 ℃)으로 유지하며 주입 | 비정질층이 안정적으로 형성되고 결함 재배열이 억제 → 어닐 후 결함·확산 감소 |
| **분자/클러스터 이온** | B₁₈Hₓ, C₇Hₓ 등 큰 분자 주입 | 원자당 저에너지 + 대전류 → 초얕은 접합 고생산성 |
| **탄소 공주입(C co-implant)** | C를 함께 주입 | 격자 간극(interstitial)을 포획해 **도펀트 과도 확산(TED) 억제** |
| **Ge PAI(사전 비정질화)** | Ge 주입으로 표면 비정질화 | 채널링 억제, 활성화 향상 |
| **고온 임플란트** | 고온에서 주입 | SiC 등 결함 제어(화합물 반도체) |

> 이 기법들의 공통점: **"임플란트 자체"가 아니라 "임플란트 + 어닐의 조합 결과"를 최적화**한다는 것입니다.
> 임플란트는 항상 [02장](02-oxidation-diffusion-thermal.md)의 어닐 장비와 한 세트로 생각해야 합니다.

## 11. 장비 노브 ↔ 공정 결과

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| **에너지 ↑** | 이온 관통력 | 주입 깊이(Rp) ↑ | 결함 깊이 ↑, 마스크 관통 위험 |
| **도즈 ↑** | 이온 수 | 농도 ↑, 시트 저항 ↓ | 비정질화·결함 ↑, 시간 ↑(처리량 ↓) |
| **빔 전류 ↑** | 시간당 이온 수 | 처리량 ↑ | 차징·발열(레지스트 손상), 공간전하 |
| **틸트 각도** | 채널링·섀도잉 | 깊이 프로파일, 좌우 대칭 | 섀도잉 발생 |
| **트위스트** | 방위각 | 섀도잉 평균화 | 시간 ↑ |
| **전하 상태(1+/2+)** | 실효 에너지 = qV | 같은 전압에서 더 깊게 | 빔 전류 ↓ |
| **감속(decel) 모드** | 저에너지 구현 | 초얕은 접합 | **에너지 오염** 위험 |
| **PFG 설정** | 표면 전위 | 차징 손상 ↓ | 과도 시 음전하·오염 |
| **웨이퍼 온도** | 결함 거동 | 비정질화·확산 제어 | 레지스트 거동 변화 |

## 12. 불량과 장비 원인

| 증상 | 의심 | 확인 |
|------|------|------|
| 시트 저항 전체 오프셋 | 도즈 캘, 패러데이 컵 오염, 빔 전류 측정 | 캘 이력, 컵 청소, 표준 웨이퍼 비교 |
| 시트 저항 스트라이프 패턴 | 스캔 파형/속도, 빔 프로파일 | 스캔 파라미터, 빔 측정 |
| 좌우 비대칭 특성 | 틸트/트위스트, 섀도잉, 플래튼 각도 | 각도 실측, 쿼드 주입 적용 |
| 접합이 예상보다 깊음(꼬리) | **채널링** 또는 **에너지 오염** | 틸트/PAI 확인, 에너지 필터 상태, 진공도 |
| 게이트 산화막 파괴/수율 저하 | 차징 | PFG 조건, 빔 전류 하향, 안테나 룰 |
| 금속 오염 검출 | 빔라인 부품 스퍼터(아퍼처/슬릿), 척 | 그래파이트 부품 상태, TXRF 원소 확인 |
| 파티클 증가 | 소스/아퍼처 마모, 레지스트 박리, 반송 | 소스 수명, 챔버 청소, 웨이퍼 취급 |
| 빔 전류 저하(점진적) | **소스 수명**(필라멘트/아크 챔버) | 소스 시간, 교체 후 회복 |
| 빔 불안정/방전 | 절연체 오염, 고전압 계통, 진공도 | 컬럼 청소, HV 로그, 리크 체크 |
| 진공 회복 지연 | 레지스트 아웃개싱, 크라이오 포화 | 재생 주기, 웨이퍼 전처리(디개스) |
| 종 순도 이상 | 분해 슬릿 오염, 마그넷 캘 | 질량 스펙트럼 스캔 |

## 13. 실무 — PM/안전

| 항목 | 내용 |
|------|------|
| **소스 교체(PM 최다 항목)** | 필라멘트/아크 챔버 교체, 소스 영역 청소. 도펀트 잔류물(As/P/B) 취급 → **독성 분진 주의, 전용 PPE·전용 청소기** |
| **빔라인 청소** | 아퍼처·슬릿·라이너의 증착물 제거. As/P 잔류물은 유해 폐기물로 처리 |
| **고전압 안전** | 수십 ~ 수백 kV. 방전·잔류 전하. LOTO + 접지봉 절차 필수 |
| **X선 관리** | 고에너지 장비는 방사선 관리구역. 차폐 점검, 인원 피폭 관리, 법적 신고 |
| **독성 가스** | AsH₃/PH₃/BF₃/GeF₄. 실린더 캐비닛·검지기·스크러버 인터락 |
| **Qual** | 빔 전류/각도 캘 → 도즈 재현성 → 시트 저항 균일도 → 파티클 → 금속 오염 |

> **임플란터가 안전 측면에서 특별한 이유**: 반도체 장비 중 **고전압 + 방사선 + 독성 물질**이 동시에 있는 거의 유일한 장비입니다.
> 신입이 절대 혼자 PM에 들어가지 않는 장비입니다.

## 14. 최근 동향

| 동향 | 내용 |
|------|------|
| **3D 구조 도핑** | FinFET/GAA에서 각도 창이 좁아 PLAD·고체소스 확산·컨포멀 도핑 기술 병용 |

| **도즈 계측 고도화** | 비파괴 광학 계측, 가상 계측(VM) |
| **생산성** | 단일 웨이퍼 고전류화, 소스 수명 연장 |
