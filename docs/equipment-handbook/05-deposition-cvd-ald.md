# 05. 증착 장비 — CVD·ALD·에피 (막을 쌓는 기술)

> 선행 학습: [0-3 가스와 유체](00-3-gas-and-fluids.md), [0-4 플라즈마](00-4-plasma-and-rf.md), [0-5 척](00-5-thermal-and-chuck.md)
> 다루는 장비: APCVD · **LPCVD(배치)** · **PECVD** · HDP-CVD · SACVD · FCVD · **ALD / PEALD / 배치·공간분리 ALD** · 에피(RP-CVD) · SOD/스핀온
> 금속막 증착(PVD/도금/W-CVD)은 [06장 Metallization](06-metallization-pvd-ecp.md)에서 별도로 다룹니다.

## 1. 공정이 장비에 요구하는 것

증착은 "원하는 재료를, 원하는 두께로, 원하는 형상 위에" 쌓는 일입니다. 요구는 6개입니다.

| 요구 | 의미 | 장비에서 어떻게 푸는가 |
|------|------|----------------------|
| **두께 제어/균일도** | Å 단위 정밀, 웨이퍼 내 1 % 이내 | 온도·유량·압력 정밀 제어, 자기제한 반응(ALD) |
| **스텝 커버리지 / 컨포멀리티** | 요철·홀 측벽까지 균일하게 | 표면반응 지배 영역 운용(저압·저온), ALD |
| **갭필 (gap fill)** | 좁은 틈을 빈 공간(void) 없이 채움 | HDP(증착+스퍼터 동시), 흐르는 막(FCVD), 순환 증착-식각 |
| **막질** | 밀도, 응력, 유전율, 불순물(H, C, Cl), 결정성 | 플라즈마 에너지, 온도, 후처리(어닐/UV 큐어) |
| **응력 제어** | 인장/압축을 목표값으로 | 플라즈마 조건, 주파수, 온도 — 웨이퍼 휨과 소자 성능(스트레인)에 직결 |
| **저온화** | 하부 구조 보호(BEOL 400 ℃ 이하) | PECVD/PEALD, 촉매 화학 |

### 반응 지배 vs 확산(수송) 지배 — 컨포멀리티의 뿌리

```
   증착 속도를 무엇이 결정하는가?

  ① 수송(확산) 지배 (mass-transport limited)
     - 표면 반응이 매우 빨라, 가스가 도달하는 즉시 소모됨
     - 결과: 가스가 잘 닿는 곳(입구·상부)만 두껍게 → 컨포멀리티 나쁨, 오버행 → 보이드
     - 조건: 고온, 고압

  ② 표면반응 지배 (surface-reaction limited)
     - 가스는 충분히 있고, 표면 반응이 느려 속도를 결정
     - 결과: 어디든 반응 속도가 같음 → 컨포멀 (단, 온도 균일도가 곧 두께 균일도)
     - 조건: 저온, 저압  ← LPCVD가 저압·저온을 쓰는 이유

  ③ 자기제한(self-limiting) : ALD
     - 표면이 포화되면 더 이상 반응하지 않음 → 사이클 수만으로 두께 결정
     - 결과: 컨포멀리티 거의 100 %, 초박막 정밀
```

## 2. 변천사 — 요구가 장비를 만든 순서

| 시기 | 장비 | 해결한 문제 | 한계 → 다음 |
|------|------|-------------|-------------|
| 1960 ~ 70s | **APCVD** (대기압, 연속 컨베이어) | 빠른 후막 증착(PSG/BPSG) | 기상 반응·파티클, 균일도, 컨포멀리티 |
| 1970 ~ 80s | **LPCVD 배치 퍼니스** | 저압으로 컨포멀·배치 균일도 확보 | 고온(열버짓), 금속 위에 못 씀 |
| 1980s | **PECVD** | **플라즈마로 저온화** → 금속 배선 위 절연막 가능 | 컨포멀리티 제한, 수소/응력, 손상 |
| 1990s | **HDP-CVD** | 증착과 스퍼터 동시 → STI/IMD **갭필** | 종횡비 더 커지면 한계, 손상 |
| 1990 ~ 2000s | **SACVD (O₃-TEOS)** | 저온·컨포멀·고종횡비 갭필 | 막질, 습기 흡수 |
| 2000s | **ALD 양산 도입** | 고유전막(HfO₂), 배리어, 초박막 정밀 | 느림 → 처리량 |
| 2000s ~ | **FCVD(흐름성 막)**, 순환 증착-식각 | 극단적 종횡비 갭필 | 후처리(큐어) 필요 |
| 2010s ~ | **PEALD, 배치 ALD, 공간분리 ALD** | ALD의 처리량·저온화 | 균일도/조성 관리 |
| 2010s ~ | **선택적 증착 (ASD)** | 특정 표면에만 증착 → 자기정렬 | 선택성 유지(결함) |
| 현재 | **초저온·고선택·3D 대응** | 3D NAND 다층 스택, GAA, 하이브리드 본딩 | 응력·결함·처리량 |

> **패턴**: 리소가 미세해질수록 증착에 요구되는 것은 "두께"가 아니라 **"형상 제어(컨포멀/갭필)와 저온"** 으로 이동했습니다.
> 그리고 SADP/SAQP 시대에는 **스페이서 두께 자체가 패턴 피치를 결정**하므로, ALD가 리소의 일부가 되었습니다([03장](03-photolithography.md)).

## 3. 장비별 구조와 원리

### 3-1. LPCVD 배치 퍼니스

구조는 [02장 수직 퍼니스](02-oxidation-diffusion-thermal.md)와 동일합니다. 차이는 가스와 압력입니다.

| 막 | 화학 | 온도(전형) | 특징 |
|----|------|-----------|------|
| 폴리실리콘 | SiH₄ → Si + 2H₂ | 600 ~ 650 ℃ | 게이트/전극. 도핑 in-situ(PH₃) 가능 |
| Si₃N₄ | 3SiH₂Cl₂ + 4NH₃ | 700 ~ 800 ℃ | 하드마스크/스페이서. 강한 인장 응력, NH₄Cl 부산물(배기 막힘) |
| SiO₂(LTO/HTO) | SiH₄+O₂ / TEOS | 400 ~ 750 ℃ | 다목적 |
| 도핑 유리(BPSG/PSG) | TEOS+B/P 소스 | — | 리플로우 평탄화(과거) |

**LPCVD 배치의 특징적 이슈**
- **가스 소모(depletion)**: 하류로 가면서 반응물이 소모 → T/C/B 두께 차. 온도 램프(존 오프셋)와 다중 노즐로 보상.
- **부산물 고화**: SiN 공정의 NH₄Cl이 배기 라인에서 고화 → 트랩·히팅 필수.
- **석영 튜브 코팅 축적** → 박리 파티클 → 정기 튜브 교체/재생.

### 3-2. PECVD (싱글 웨이퍼 또는 멀티스테이션)

```
              RF (13.56 MHz + 저주파 옵션)
                        │
         ┌──────────────┴──────────────┐
         │ 샤워헤드(=상부 전극, 온도 제어) │ ← 듀얼 채널(전구체 분리) 가능
         ├───── 갭(수 mm ~ cm, 가변) ───┤
         │      ░░░ 플라즈마 ░░░         │
         ├─────────────────────────────┤
         │  ███ 웨이퍼 ███               │
         │  히터 내장 서셉터(200 ~ 650 ℃) │ ← 진공척/포켓, 퍼지 링
         └──────────────┬──────────────┘
                        │ 접지 or 저주파 바이어스
   [멀티스테이션 구조]: 하나의 큰 챔버 안에 스테이션 4 ~ 6개 + 인덱서
         → 웨이퍼가 스테이션을 한 칸씩 돌며 나눠 증착 → 처리량↑ + 평균화로 균일도↑
```

| 막 | 화학 | 용도 | 포인트 |
|----|------|------|--------|
| SiO₂ | SiH₄+N₂O, TEOS+O₂ | IMD, 패시베이션 | 저온, 수분 흡수 주의 |
| SiN | SiH₄+NH₃(+N₂) | 패시베이션, CESL(스트레스), 하드마스크 | **응력을 인장↔압축으로 조절**(주파수/파워) → 트랜지스터 성능 튜닝 |
| SiON | 혼합 | ARC, 절연 | 굴절률 튜닝 |
| SiC/SiCN | 유기실리콘+NH₃ | Cu 확산 배리어/에치스톱 | 저유전 요구 |
| **저유전막(SiCOH, k<3)** | 유기실리콘 + 포로젠 | BEOL 배선 간 커패시턴스 감소 | **UV 큐어**로 포로젠 제거 → 다공성. 플라즈마/습식 손상에 매우 취약 |
| a-C (비정질 카본) | 탄화수소 | 초후막 하드마스크(HAR 식각용) | 투명도/응력 |

> **응력 제어가 왜 중요한가**: ① 웨이퍼가 휘면 노광 오버레이·척킹이 망가짐, ② 막이 갈라지거나 박리됨,
> ③ 의도적으로 채널에 응력을 주면 캐리어 이동도가 올라감(strained silicon) → **PECVD 응력은 성능 노브**입니다.

### 3-3. HDP-CVD — 갭필의 고전적 해법

```
   고밀도 플라즈마(ICP형) + 웨이퍼 바이어스 동시 인가

   증착(SiH₄/O₂) 과 스퍼터(Ar 이온) 를 동시에 진행
   → 입구에 생기는 오버행을 이온이 깎아내면서 아래로 채움
   → D/S 비(Deposition/Sputter ratio)가 갭필 능력을 결정

      ┌──┐ ┌──┐        오버행 형성 → 이온이 제거
      │▓▓│ │▓▓│           ↓
      │  │ │  │  →     아래부터 채워짐(bottom-up 경향)
```
| 장점 | 단점 |
|------|------|
| 보이드 없는 갭필(중간 종횡비), 치밀한 막 | 이온 충격 손상, 코너 클리핑, 종횡비 한계, 열 부하 |

### 3-4. SACVD / FCVD — 더 어려운 갭필

| 장비/공정 | 원리 | 특징 |
|-----------|------|------|
| **SACVD (Sub-Atmospheric, O₃+TEOS)** | 준대기압에서 표면 유동성 있는 산화막 성장 | 컨포멀·고종횡비 갭필. 습기 흡수 → 후 어닐 필요 |
| **FCVD (Flowable CVD)** | 증착 시 흐르는(액체 유사) 막이 틈으로 흘러 들어감 → 이후 큐어(어닐/UV/O₃)로 SiO₂화 | 극단적 종횡비 갭필. 수축(shrinkage)·응력 관리 필요 |
| **순환 증착-식각 (dep-etch cycling)** | 조금 쌓고 입구를 살짝 식각해 열어주기를 반복 | 시간 비용 |
| **스핀온 (SOD/SOG)** | 도포 후 큐어 | 장비는 트랙류. 막질 한계 |

### 3-5. ALD — 자기제한 반응의 장비화

```
   [ALD 1 사이클]  예: Al₂O₃ (TMA + H₂O)

   ① 전구체 A 펄스 (TMA)  → 표면 -OH와 반응, 표면이 포화되면 반응 정지 (자기제한)
   ② 퍼지 (N₂/Ar)         → 기상 잔류 A 제거 ★ 여기서 부족하면 CVD식 반응(파티클/두께 이상)
   ③ 반응물 B 펄스 (H₂O)  → 표면 리간드를 제거하며 -OH 재생
   ④ 퍼지                 → 반복

   두께 = (사이클당 증착량 GPC, 보통 0.5 ~ 1.5 Å) × 사이클 수
   → 시간이 아니라 "횟수"로 두께를 정한다  ← 재현성의 근본 이유
```

| ALD 장비 형태 | 구조 | 장단점 |
|---------------|------|--------|
| **싱글 웨이퍼 시간분리 ALD** | 한 챔버에서 펄스/퍼지를 시간으로 분리 | 정밀·유연. 퍼지 시간 때문에 느림 |
| **PEALD (플라즈마 강화)** | 반응물 단계에 플라즈마(O₂/N₂/NH₃/H₂) 사용 | **저온에서 고품질**(400 ℃ 이하), 반응 활성↑. 플라즈마 손상·컨포멀리티 약간 저하 |
| **배치 ALD (퍼니스형)** | 수십~100장 동시 | 처리량 우수, 사이클 시간 김 | 균일도·퍼지 설계 난이도 |
| **공간분리 ALD (spatial/rotary)** | 회전 플래튼 위 웨이퍼가 A영역 → 퍼지커튼 → B영역을 지나감 | 퍼지 시간 절약 → 매우 빠름 | 기계적 복잡, 가스 커튼 격리 품질 |
| **선택적 ALD (ASD)** | SAM(자기조립단분자막) 등으로 특정 표면 억제 | 자기정렬 패터닝, 리소 부담 완화 | 선택성 유지·결함 관리 |

**ALD 장비의 하드웨어 급소**

| 항목 | 왜 중요한가 |
|------|-------------|
| **빠른 밸브(ALD 밸브)** | 수십 ms 펄스. 응답·반복성이 GPC를 결정 |
| **압력식 MFC / 빠른 유량 제어** | 짧은 펄스에서 열식 MFC는 응답이 느림 ([0-3장](00-3-gas-and-fluids.md)) |
| **전구체 전달(버블러/DLI/고체 앰플)** | 증기압이 낮은 전구체가 많음. 온도·잔량 관리가 두께 재현성 직결 |
| **히팅 라인/cold spot 관리** | 응축 = 파티클 + 두께 드리프트. "흐름 방향으로 계속 더 뜨겁게" 원칙 |
| **퍼지 효율(챔버 체적/컨덕턴스)** | 챔버 체적이 작고 배기가 빨라야 퍼지가 짧아짐 → **작은 챔버**가 ALD에 유리 |
| **샤워헤드 설계** | A/B 전구체가 챔버 전에 만나지 않게(듀얼 채널) |
| **챔버 벽 온도** | 벽에도 ALD가 일어남 → 퇴적·파티클. 벽 온도로 제어 + 주기적 클린 |

| 주요 ALD 막과 전구체 예 | 용도 |
|------------------------|------|
| Al₂O₃ (TMA + H₂O/O₃/플라즈마 O) | 패시베이션, 절연, 하드마스크 |
| HfO₂ / ZrO₂ (HfCl₄·TEMAH / ZrCl₄ 등) | 게이트 고유전막, DRAM 커패시터 |
| TiN (TiCl₄ + NH₃) | 배리어/전극 |
| SiO₂ / SiN (아미노실란 + O/N 플라즈마) | **스페이서(SADP 피치 결정)**, 라이너 |
| W / Mo / Ru / Co | 금속 배선·컨택 ([06장](06-metallization-pvd-ecp.md)) |

## 4. 에피택시 장비 (Epitaxy)

```
   [단일 웨이퍼 RP-CVD 에피 반응기]

   램프(상/하) 복사 가열 → 웨이퍼 1장, 서셉터 회전
   석영 챔버(콜드월) → 벽 증착 억제
   가스: SiH₂Cl₂ / SiH₄ / Si₂H₆ + H₂ (캐리어) + GeH₄(SiGe) + B₂H₆/PH₃(도핑) + HCl
   압력: 수 Torr ~ 대기압,  온도: 600 ~ 1150 ℃
```

| 적용 | 내용 | 장비 요구 |
|------|------|-----------|
| **블랭킷 에피** | 고품질 Si 층 | 결정성, 결함 0, 도핑 프로파일 급격도 |
| **선택적 에피 (SEG)** | 산화막 위에는 안 자라고 Si 위에만 | HCl 첨가로 핵생성 억제, 또는 **순환 증착-식각(CDE)** |
| **소스/드레인 SiGe:B, Si:P** | 채널에 응력 인가 + 저저항 | 조성·도핑 정밀, 패싯(facet) 제어 |
| **GAA 나노시트용 Si/SiGe 다층** | 교대 적층 → 나중에 SiGe만 제거 | 층별 두께·조성 균일도가 소자 성능 직결 |
| **SiC/GaN 에피** | 전력/RF | 전용 반응기(MOCVD/HVPE), 고온 |

**에피 장비의 관리 포인트**
- **표면 준비가 절반**: 자연산화막·탄소 오염이 있으면 결정이 이어지지 않음 → 인시투 H₂ 베이크 / 프리클린(원격 플라즈마, HF vapor) 필수.
- **서셉터·석영 부품 증착물**: 파티클·두께 드리프트 → HCl 인시투 클린, 정기 교체.
- **오토도핑**: 웨이퍼 뒷면/서셉터의 도펀트가 기상으로 재분포 → 백사이드 실링, 저압 운용.
- **고온 + H₂** → 수소 안전 설계.

## 5. 장비 노브 ↔ 공정 결과

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| **온도 ↑** | 반응 속도(지수) | 증착률 ↑, 막질·밀도 ↑, 결정성 ↑ | 열버짓 ↑, 컨포멀리티 저하(수송 지배로 이동) |
| **압력 ↓** | 확산 ↑, 평균자유행정 ↑ | 컨포멀리티 ↑, 균일도 ↑ | 증착률 ↓ |
| **전구체 유량 ↑** | 공급량 | 증착률 ↑ | 기상 반응(파티클), 재료비 |
| **플라즈마 파워 ↑ (PECVD)** | 해리·이온 에너지 | 막 밀도 ↑, 저온 가능, 응력 변화 | 손상, 응력 과다, 파티클 |
| **저주파 비율 ↑ (PECVD)** | 이온 충격 ↑ | 압축 응력 방향, 치밀화 | 손상 |
| **갭 (샤워헤드-웨이퍼)** | 전력 밀도·체류시간 | 균일도·막질 | 재튜닝 |
| **ALD 펄스 시간** | 표면 포화 여부 | 포화되면 두께 안정(자기제한) | 부족 시 두께 부족·불균일, 과다 시 시간 낭비 |
| **ALD 퍼지 시간** | 기상 잔류 제거 | 부족하면 CVD식 성장(파티클·GPC 상승) | 길면 처리량 ↓ |
| **ALD 사이클 수** | 두께 | 선형적으로 두께 결정 | — |
| **D/S 비 (HDP)** | 증착 vs 스퍼터 | 갭필 능력 | 손상, 코너 클리핑 |
| **UV 큐어 조건(저유전막)** | 포로젠 제거·가교 | k값 ↓, 기계 강도 ↑ | 수축·응력 |
| **후 어닐** | 치밀화·탈수 | 막질 ↑, 응력 변화 | 열버짓 |

## 6. 불량과 장비 원인

| 증상 | 의심 | 확인 |
|------|------|------|
| 두께가 서서히 감소 | 전구체 앰플 depletion, MFC 드리프트, 샤워헤드 막힘 | 앰플 잔량/온도, ROR, 샤워헤드 육안 |
| 두께 균일도 악화(센터-엣지) | 갭, 유량 배분, 히터 존, 배기 대칭 | C/E 스윕, 존 파워, APC 개도 |
| 파티클 급증 | 챔버 퇴적물 박리, 기상 반응, cold spot 응축 | 누적 두께 카운트, 듀얼채널 확인, 라인 온도 맵 |
| ALD GPC 상승/변동 | 퍼지 부족, 전구체 과공급, 벽 온도 | 퍼지 시간 스윕, 포화 곡선 재측정 |
| 막 내 H/C 불순물 과다 | 온도 낮음, 플라즈마 부족, 퍼지 부족 | FTIR/SIMS, 조건 재검토 |
| 갭필 보이드 | 오버행(수송 지배), D/S 비, 종횡비 | 단면 SEM, 압력·온도 하향, dep-etch 도입 |
| 막 박리/크랙 | 응력 과다, 밀착력, 두께 | 응력 측정, 밀착 처리(플라즈마 전처리), 두께 분할 |
| 웨이퍼 휨 증가 | 응력 | 응력 튜닝(주파수/파워/온도) |
| 저유전막 k값 상승 | 플라즈마/습식 손상, 흡습 | 손상 완화(원격 플라즈마), 큐어/실링 |
| 에피 결함(적층결함/힐록) | 표면 전처리 불량, 오염, 온도 | 프리클린 이력, H₂ 베이크, 챔버 클린 |
| 선택적 에피에서 산화막 위 핵생성 | HCl 부족, 온도/압력 | CDE 조건, 표면 상태 |
| 웨이퍼 간 첫 장 차이 | 챔버 idle 상태, pre-coat | 더미 선행, pre-coat 표준화 |
