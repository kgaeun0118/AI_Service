# 0-8. 부품과 소모품 — 장비의 실체는 부품이다

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-4 플라즈마](00-4-plasma-and-rf.md), [0-5 척](00-5-thermal-and-chuck.md)
> 요지: 장비는 사지만, 운영은 **부품으로** 한다. 현장 엔지니어의 시간 대부분은 "어떤 부품이 얼마나 닳았고 언제 갈 것인가"에 쓰인다.

---

## 1. 부품을 3종류로 나누면 장비 운영이 보인다

| 분류 | 정의 | 교체 주기 | 예 |
|------|------|-----------|-----|
| **소모성 부품 (consumable)** | 공정 중 물리·화학적으로 **소모되도록 설계된** 부품 | 수일 ~ 수개월 | 포커스/엣지 링, 샤워헤드, 스퍼터 타겟, CMP 패드, 코일, 라이너, O링, 필터, 슬러리 |
| **유지보수 부품 (maintenance / wear part)** | 마모·열화되어 주기적 교체 | 수개월 ~ 수년 | 로봇 블레이드/패드, 밸브 씰, 베어링, 램프, 펌프 소모품 |
| **영구 부품 (durable)** | 원칙적으로 장비 수명 동안 사용 | 수년 ~ | 챔버 바디, 척 본체, RF 제너레이터, 스테이지, 프레임 |

> **핵심 사실**: 소모성 부품은 **"닳으면서 공정 결과를 바꿉니다."**
> 즉 어제와 오늘의 공정이 달라지는 가장 흔한 이유가 소모품의 마모 상태입니다. 이것이 seasoning·매칭·PM 주기가 존재하는 근본 이유입니다.

---

## 2. 공정별 주요 소모성 부품 지도

| 공정 | 소모성 부품 | 소모되는 이유 | 마모 시 공정에 나타나는 증상 |
|------|-------------|---------------|------------------------------|
| **플라즈마 식각** | 포커스 링 / 엣지 링 | 이온 충격으로 스퍼터·식각 | 엣지 CD 드리프트, 엣지 식각률 변화, 엣지 프로파일 기울어짐 |
| | 상부 전극 / 샤워헤드 | 이온 충격, 홀 확장, 증착물 | 균일도 변화, 파티클, 홀 시그니처 |
| | 챔버 라이너 / 실드 | 퇴적물 축적, 코팅 마모 | 파티클, 라디칼 재결합률 변화(식각률 드리프트) |
| | ESC 유전체 | 이온 충격·아킹 | He 누설률 상승, 척킹 불량, 국부 온도 이상 |
| | 석영/세라믹 윈도우(ICP) | 증착물, 식각 | RF 결합 효율 변화, OES 신호 저하 |
| **PECVD/ALD** | 샤워헤드, 히터 서셉터 | 막 퇴적, 열사이클 | 파티클(박리), 두께 균일도 |
| | 챔버 키트(라이너/펌핑 링) | 퇴적물 | 파티클, 컨덕턴스 변화 |
| **PVD (스퍼터)** | **타겟** | 스퍼터로 직접 소모(주 소모품) | 증착률 변화(에로전 프로파일), 노듈에 의한 아킹·파티클 |
| | 실드/클램프/콜리메이터 | 퇴적물 축적 → 박리 | 파티클(치명적), 증착 프로파일 |
| **CMP** | **패드**, 컨디셔너 디스크, 리테이닝 링, 슬러리 | 마찰 마모 | 제거율(MRR) 감소, 균일도 악화, 스크래치, 디싱 |
| **CVD/식각 공통** | O링, 필터, 트랩, 펌프 소모품 | 화학·열 열화 | 누설, 파티클, 펌프 고장 |
| **임플란트** | 소스 필라멘트/아크 챔버, 그래파이트 부품, 아퍼처 | 스퍼터·증착·열 | 빔 전류 저하, 금속 오염, 도즈 불안정 |
| **RTP/에피** | 램프, 서셉터, 석영 부품 | 열사이클, 증착물 | 온도 프로파일 이상, 파티클 |
| **퍼니스** | 석영 튜브, 보트, 히터 엘리먼트 | 열사이클, 실투, 금속 확산 | 파티클, 오염, 균일도 |
| **노광(트랙/스캐너)** | 노즐, 필터, 척(백사이드), 펠리클, 광원 부품 | 오염, 사용 | 코팅 결함, 디포커스, 광량 저하 |
| **패키징** | 다이싱 블레이드, 본딩 캐필러리/툴, 몰드 체이스, 필터 | 마모 | 칩핑, 본딩 불량, 몰드 플래시 |

## 3. 내플라즈마 재질과 코팅 — 왜 이트리아(Y₂O₃)인가

플라즈마 식각 챔버는 **불소·염소 라디칼과 이온 충격**에 동시에 노출됩니다. 재질 선택 기준은 "얼마나 덜 깎이고, 깎여도 얼마나 덜 해로운가"입니다.

| 재질 | 내플라즈마성 | 특징 / 문제 |
|------|--------------|-------------|
| 알루미늄 + 아노다이징(Al₂O₃) | 보통 | 저렴, 가공 용이. 불소 플라즈마에 AlF₃ 생성 → 파티클, 두께 감소 |
| 석영(SiO₂) | 낮음~보통 | 불소에 식각됨(SiF₄로 휘발). 소모가 크지만 **오염물이 Si계라 상대적으로 무해** |
| 알루미나 세라믹(Al₂O₃) | 보통 | 벌크 세라믹. AlF₃ 생성 |
| **이트리아 (Y₂O₃) 용사 코팅** | 높음 | 불소와 반응해 YF₃ 생성하지만 **매우 안정하고 휘발 안 함** → 침식 속도가 낮음. 현대 식각 챔버 표준 |
| **YAG / YOF / 복합 산화물** | 매우 높음 | 이트리아의 개량형. 균열·기공 저감, 파티클 저감 |
| SiC | 높음 | 강도·저오염. 고가 |
| 폴리이미드/PTFE | 낮음 | 플라즈마 직접 노출 금지 → 리세스·실드로 가려야 함 |

**코팅의 함정**
- 코팅은 "닳지 않는다"가 아니라 **"천천히 닳는다"** 입니다. 수명이 끝난 코팅은 기공·균열을 통해 **오히려 파티클을 대량 방출**합니다. 그래서 코팅 부품에도 수명 카운트가 붙습니다.
- 용사 코팅은 기공률·표면조도·두께 관리가 품질의 전부입니다. **재생(refurbish) 품질이 부품 성능을 좌우**합니다.
- PM 시 코팅면을 긁으면 그 부위가 파티클 원이 됩니다. 취급 규칙(도구·장갑·보관)이 중요합니다.

## 4. Seasoning / Conditioning — 챔버를 "길들인다"는 것

### 왜 필요한가 (물리)

```
   [PM 직후: 맨 금속/세라믹 벽]
     라디칼이 벽에 부딪히면 재결합(recombination)되어 사라짐 → 라디칼 밀도 낮음
     → 식각률 낮음 / 증착률 다름 / 프로파일 다름

   [공정 수십 장 후: 벽에 얇은 반응층/폴리머]
     벽의 재결합 계수가 안정화 → 라디칼 밀도 안정
     → 결과가 반복 가능해짐  ← 이 상태가 "양산 상태"
```

즉 **챔버 벽 자체가 공정 변수**입니다. 이것이 seasoning의 본질입니다.

| 루틴 | 목적 | 형태 |
|------|------|------|
| **Seasoning (PM 후)** | 벽 상태를 양산 상태로 복원 | 더미 웨이퍼 수 장 ~ 수십 장에 공정 레시피 수행 |
| **Pre-coat** | 챔버 내벽에 의도적으로 얇은 막 코팅 | 증착 장비에서 흔함(파티클 억제, 금속 오염 방지) |
| **Wafer-less Auto Clean (WAC)** | 웨이퍼 사이 퇴적물 제거 | 플라즈마만 수 초 ~ 수십 초 |
| **In-situ / Remote clean** | 누적 퇴적물 제거(NF₃ 등) | 일정 웨이퍼 수마다 |
| **Idle 보정 (idle time effect)** | 챔버가 쉬면 벽 상태가 변함 | idle 후 첫 웨이퍼 전에 더미/클린 시퀀스 |

> **First Wafer Effect**: 로트의 첫 웨이퍼만 결과가 다른 현상. 원인은 대개 **챔버 벽 온도/퇴적 상태/가스 잔류의 초기 과도 상태**입니다.
> 대책: 더미 웨이퍼 선행 투입, idle 시 퍼지/가열 유지, 첫 장 전용 보정 레시피.

## 5. 부품 수명 관리 — 무엇을 카운트하는가

| 카운터 | 적용 부품 | 이유 |
|--------|-----------|------|
| **웨이퍼 카운트** | 라이너, 링, 샤워헤드 | 퇴적·소모가 처리량에 비례 |
| **RF 시간 (RF hour)** | 플라즈마 노출 부품 | 실제 플라즈마 노출 시간이 소모를 결정 |
| **kWh (타겟)** | 스퍼터 타겟 | 투입 에너지 ∝ 스퍼터된 양 |
| **누적 두께 (µm)** | 증착 챔버 키트 | 퇴적막 응력이 한계 넘으면 박리 |
| **연마 시간 / 웨이퍼 수 (패드)** | CMP 패드/디스크 | 마모 |
| **컷 길이 (블레이드)** | 다이싱 블레이드 | 마모 |
| **점등 시간 (램프)** | RTP/노광 램프 | 광량 저하 |
| **사이클 수** | 밸브, 도어, 로봇 | 기계적 피로 |

**수명 관리의 3가지 방식**

| 방식 | 내용 | 장단점 |
|------|------|--------|
| 고정 주기 (TBM, time-based) | 정해진 카운트에서 무조건 교체 | 단순·안전. 낭비 발생(아직 쓸 수 있는 부품 폐기) |
| 상태 기반 (CBM, condition-based) | 실측(두께, 파티클, 지표)으로 판단 | 효율적. 측정 체계 필요 |
| 예지 (PdM) | 트렌드로 잔여 수명 예측 | 최적. 데이터·모델 필요 ([0-7장](00-7-sensors-and-control.md)) |

> 현실: 대부분 TBM 기본 + 핵심 지표에 CBM/PdM을 덧붙이는 하이브리드입니다.

## 6. 부품 재생(refurbishment)과 관리 체계

| 항목 | 내용 |
|------|------|
| **왜 재생하나** | 세라믹/코팅 부품은 매우 비쌈. 코팅 벗기고 재코팅해 반복 사용(수 회) |
| **재생 공정** | 탈코팅(블라스팅/화학) → 기재 검사(치수·크랙) → 재코팅(용사) → 표면 처리 → 세정 → 검사 → 포장 |
| **품질 리스크** | 기재 두께 감소, 코팅 기공률/밀착 불량, 세정 잔류물 → **파티클·금속 오염의 숨은 원인** |
| **세정 등급 관리** | 초순수 세정, 초음파, 건조, 진공 포장. "세정 이력이 없는 부품은 챔버에 못 들어간다"가 원칙 |
| **부품 이력 추적** | 부품별 시리얼/재생 횟수/사용 이력 관리. 문제 발생 시 동일 로트 부품 전수 점검 |
| **신품 vs 재생품 혼용** | 챔버 매칭을 깨뜨리는 원인. 챔버별로 **같은 조건(재생 횟수/리비전)** 을 유지하는 것이 좋음 |

## 7. PM (Preventive Maintenance) — 실제로 무슨 일을 하는가

### 규모별 분류

| 구분 | 주기(전형) | 작업 내용 | 소요 |
|------|-----------|-----------|------|
| **일상 점검 (daily/weekly)** | 매일~매주 | 게이지 확인, 파티클 체크, 소모품 잔량, 알람 이력 확인 | 분 단위 |
| **Minor PM** | 수주 | 링/샤워헤드 교체, 윈도우 청소, O링 일부 교체 | 수 시간 |
| **Major PM (Full kit)** | 수개월 | 챔버 전면 분해, 키트 전량 교체, 척 점검, 리크 체크 | 1 ~ 3일 |
| **Overhaul** | 수년 | 펌프/스테이지/구동계 오버홀 | 수일 ~ 주 |

### PM 표준 절차 (식각/CVD 챔버 기준 예시)

```
 1. 공정 정지 · 레시피 종료 · 챔버 클린 수행
 2. 벤트(N₂) → 대기압 복귀 → 안전 인터락 확인(LOTO: 전원/가스/RF 차단·잠금)
 3. 잔류 유해가스 퍼지 확인 (가스 검지, 필요 시 SCBA/보호구)
 4. 챔버 개방 → 부품 탈거 (순서·토크·방향 기록)
 5. 오염부 청소 (승인된 방법만: 지정 와이퍼/알코올/블라스팅 금지 부위 확인)
 6. 신품/재생품 장착 (청정 장갑, 지정 토크, O링 홈 무결점 확인)
 7. 챔버 폐쇄 → 펌프다운 → **리크 체크(He 또는 rate-of-rise)**
 8. 베이킹/퍼지 → 베이스 압력 도달 확인
 9. 캘리브레이션 (게이지, 갭, 온도, RF 매칭 확인)
10. **Seasoning** (더미 웨이퍼)
11. **Qual**: 파티클 → 두께/식각률/균일도 → CD → 필요 시 전기 특성
12. 챔버 매칭 확인 → 양산 해제(release)
```

> **입문자가 자주 놀라는 점**: PM에서 **분해보다 "재조립 + 검증"이 훨씬 오래 걸립니다.**
> 리크 체크, 베이스 압력 회복, seasoning, qual이 시간의 대부분입니다. 그래서 PM 시간 단축 기술(빠른 키트 교체, 사전 세정 부품 준비, 자동 qual)이 곧 생산성입니다.

### PM 후 흔한 실패 유형

| 실패 | 원인 |
|------|------|
| 리크 발생 | O링 홈 이물, O링 꼬임/손상, 토크 불균일, 볼트 순서 오류 |
| 파티클 폭증 | 부품 세정 불량, 코팅 손상, 잔여 파편, seasoning 부족 |
| 결과 시프트 | 갭/링 두께 변경, 부품 리비전 차이, 센서 캘 미실시 |
| RF 이상 | 접지 가스켓 미장착, 케이블 경로 변경, 매처 범위 이탈 |
| 온도 이상 | 히터 커넥터 미체결, 열전대 위치 변경, 칠러 라인 기포 |
| 반송 에러 | 티칭 미수행/오류 |

## 8. 파티클 — 부품과 파티클의 관계

파티클은 "어디서 오는가"로 분류하면 대책이 명확해집니다.

| 발생원 | 메커니즘 | 웨이퍼상 패턴(단서) | 대책 |
|--------|----------|--------------------|------|
| **퇴적막 박리(flaking)** | 응력 축적 → 박리 | 랜덤 + 군집, 크기 큼 | 클린/코팅 주기 단축, 라이너 온도 관리, pre-coat |
| **기상 반응(gas phase nucleation)** | 전구체 조기 반응 | 전면 랜덤, 미세 | 듀얼채널, 압력/온도 조정, 퍼지 시간 |
| **부품 마모/스퍼터** | 이온 충격 | 엣지 편중(링 관련), 금속 오염 동반 | 부품 교체, 내플라즈마 부품 |
| **아킹** | 전계 집중 | 국부 대형 결함, 손상 흔적 | 부품 형상·청소, 펄스DC |
| **기계적 마찰(반송)** | 블레이드/핀/밸브 | 특정 위치 반복, 백사이드 | 패드/핀 교체, 티칭, 슬릿 밸브 PM |
| **웨이퍼 파편** | 파손 후 잔류 | 무작위, 장기간 지속 | 완전 수색·청소, 전수 점검 |
| **외부 유입** | FOUP/환경 | 특정 FOUP/슬롯 | FOUP 세정, 환경 점검 |

**파티클 진단의 실전 순서**
1. **비패턴 웨이퍼(bare wafer)** 로 장비 파티클 테스트 — 웨이퍼 통과만(반송 only) vs 공정 수행(process) 을 분리해 측정
   → 반송만으로 증가하면 반송계, 공정 시 증가하면 챔버.
2. **맵 패턴**을 본다(엣지/센터/방향성/군집).
3. **스텝 분리 테스트**: 레시피를 스텝별로 나눠 어느 스텝에서 발생하는지 특정.
4. 필요 시 **SEM/EDX 로 파티클 조성 분석** → 조성이 부품을 지목합니다(예: Y 검출 → 이트리아 코팅, Al+F → 아노다이징, C → 폴리머/O링).

> 조성 분석은 결정적입니다. "Al과 F가 같이 나왔다" = 아노다이징 침식. "Y" = 이트리아 코팅 열화. **부품을 지목하는 지문**입니다.

## 9. 트러블슈팅 — 부품 관련

| 증상 | 의심 부품 | 확인 |
|------|-----------|------|
| 엣지 CD/식각률이 서서히 변함 | 포커스/엣지 링 마모 | 링 두께 실측, RF hour, 교체 후 회복 여부 |
| 파티클이 PM 주기 말에 급증 | 라이너/실드 퇴적막 박리 | 누적 두께 카운트, 클린 주기 단축 |
| 증착률이 서서히 감소 | 타겟 소모/에로전, 샤워헤드 막힘 | kWh 카운트, 육안, 교체 테스트 |
| 아킹 알람 증가 | 타겟 노듈, 실드 퇴적, 절연체 오염 | 타겟 표면, 실드 상태, 절연 저항 |
| He 누설률 상승 | ESC 유전체 마모 | 척 표면 검사, 누설률 트렌드 |
| 챔버 간 결과 차 | 소모품 수명 위치/리비전 차 | 카운터 비교, 실측 치수 비교 |
| 재생품 장착 후 파티클 | 재생 품질, 세정 불량 | 부품 이력, 동일 재생 로트 전수 점검 |
| PM 후 첫 로트 결과 이상 | seasoning 부족 | 더미 수 증가, 매칭 재확인 |
