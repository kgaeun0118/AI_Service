# 0-6. 반송과 정렬 — 웨이퍼를 깨지 않고, 더럽히지 않고, 정확히 옮기기

> 선행 학습: [0-1 장비를 보는 눈](00-1-equipment-literacy.md), [0-2 진공](00-2-vacuum.md)
> 요지: 공정 챔버가 아무리 좋아도, 웨이퍼를 옮기는 과정에서 파티클이 붙거나 0.1 mm 틀어지면 전부 무의미하다. 그리고 실제 장비 알람의 1위는 대부분 **반송 에러**다.

---

## 1. 반송은 왜 별도의 기술 영역인가

| 요구 | 구체적 수치 감각 |
|------|------------------|
| **깨지지 않게** | 300 mm 웨이퍼 두께 775 µm. 무게 약 130 g. 엣지 충격 하나로 크랙 → 후속 공정에서 폭발적 파손 |
| **더럽히지 않게** | 20 nm 파티클 한 개가 킬러 결함. 반송 경로는 **파티클 발생의 주요 근원지**(기계적 마찰 부위) |
| **정확하게** | 챔버 내 웨이퍼 중심 위치 오차는 수백 µm 이내. 노광 스테이지는 **nm 단위** |
| **빠르게** | 반송 시간이 곧 처리량(WPH). 로봇 궤적 최적화가 장비 스펙의 일부 |
| **추적 가능하게** | 어느 FOUP 몇 번 슬롯 웨이퍼가 어느 챔버에 언제 들어갔는지 전부 기록(불량 추적) |

## 2. 웨이퍼가 팹에서 이동하는 전체 체계

```
 [팹 자동화]
   스토커(Stocker) ──▶ OHT(천장 주행 반송차) ──▶ 장비 로드포트
       │  FOUP 보관        레일 주행                 │
       │                                            ▼
       │                               ┌──────────────────────────┐
       │                               │ ① 로드포트 + FOUP 오프너   │
       │                               │ ② 대기(ATM) 로봇          │
       │                               │ ③ 얼라이너(노치/각도 정렬)  │
       │                               │ ④ 로드락(대기↔진공)        │
       │                               │ ⑤ 진공(VAC) 로봇           │
       │                               │ ⑥ 프로세스 챔버            │
       │                               └──────────────────────────┘
       └── MES/호스트 ── SECS/GEM 통신으로 로트·레시피 지시
```

| 요소 | 설명 |
|------|------|
| **FOUP** (Front Opening Unified Pod) | 300 mm 웨이퍼 25장을 담는 밀폐 캐리어. 내부는 N₂ 퍼지 가능(퍼지 FOUP). 웨이퍼가 팹 공기에 직접 노출되지 않게 하는 핵심 |
| **FOSB** | 출하/보관용 캐리어(공정 투입용 아님) |
| **OHT / AMHS** | 천장 레일로 FOUP을 자동 운반. 장비 상부의 로드포트에 직접 내려놓음 |
| **로드포트 + 오프너** | FOUP 도어를 열고(웨이퍼를 꺼낼 수 있게) 장비 내부 청정 공간과 연결. 도어 개방부는 **하향 기류로 보호** |
| **매핑 센서** | FOUP 안 몇 번 슬롯에 웨이퍼가 있는지 스캔. **더블 슬롯/크로스 슬롯 검출**(웨이퍼가 비스듬히 걸침) → 강제 정지 |

## 3. 로봇 — 대기 로봇과 진공 로봇

| 구분 | 대기(ATM) 로봇 | 진공(VAC) 로봇 |
|------|----------------|----------------|
| 위치 | EFEM 내부 | 트랜스퍼 챔버 내부 |
| 척킹 방식 | **진공 흡착 척**(대기이므로 가능) 또는 엣지 그립 | **마찰/엣지 접촉 패드**(진공에서는 흡착 불가) |
| 구조 | SCARA(수평 다관절), 듀얼 아암 흔함 | 프로그 레그(frog-leg), SCARA, 듀얼/트리플 블레이드 |
| 재질 | 알루미늄·세라믹 블레이드 | 세라믹(알루미나/SiC) — **고온 웨이퍼를 받기 때문** |
| 관통부 | 일반 베어링 | **자기 유체 실 / 마그네틱 커플링**(진공 유지하며 회전 전달) |
| 특이 요구 | 파티클 최소화, 정전기 관리 | 고온 내성(수백 ℃ 웨이퍼), 저아웃개싱, 윤활 제한 |

```
   [듀얼 아암의 이유 — 처리량]

   단일 아암:  챔버에서 완료 웨이퍼 꺼냄 → 로드락 가서 새 웨이퍼 집음 → 챔버 투입
               (챔버가 비는 시간 = 왕복 시간 전체)

   듀얼 아암:  아암 A에 새 웨이퍼를 들고 간 상태로
               아암 B가 완료 웨이퍼를 꺼내고 → 즉시 아암 A가 투입
               (챔버 idle 시간 = 스왑 시간만)  ← WPH 크게 개선
```

### 로봇 관련 실무 항목

| 항목 | 내용 |
|------|------|
| **티칭(teaching)** | 로봇에게 각 스테이션의 좌표를 학습시키는 작업. PM 후 필수. 잘못되면 웨이퍼가 엣지에 긁히거나 척 중심에서 벗어남 |
| **ATC (Auto Teach) / 웨이퍼 센터링 센서** | 통과하는 웨이퍼의 엣지를 감지해 중심 편차를 자동 계산·보정 |
| **슬립(slip) 검출** | 가속 중 웨이퍼가 블레이드에서 미끄러짐. 반복되면 파티클·미스얼라인. 가속도 프로파일 튜닝 |
| **블레이드 마모/변형** | 세라믹 블레이드 끝단 마모 → 파티클. 고온 반복으로 처짐(sag) |
| **웨이퍼 존재 센서** | 광학/용량식. 오검출 시 "없는 웨이퍼를 잡으러 가거나", 더 나쁘게는 **웨이퍼가 있는 자리에 또 놓아 파손** |
| **크래시 후 절차** | 웨이퍼 파손 시: 파편 완전 회수 → 챔버·반송부 청소 → 진공/파티클 확인 → 티칭 재검증 → qual. **파편 한 조각이 몇 주간 파티클을 냄** |

## 4. 얼라이너 — 웨이퍼의 방향을 맞추는 장치

```
   웨이퍼 원주에는 노치(notch, 300 mm) 또는 플랫(flat, 200 mm 이하)이 있다.
   → 결정 방위(crystal orientation)의 기준이자, 공정 간 회전 방향의 기준

   [얼라이너 동작]
   ① 웨이퍼를 회전 스테이지에 올림
   ② 저속 회전하며 라인 센서(또는 CCD)로 엣지 위치를 연속 측정
   ③ 엣지 곡선에서 노치 위치와 중심 편심(eccentricity)을 동시에 계산
   ④ 목표 각도로 회전 정지 + 중심 보정값을 로봇에 전달
```

| 왜 필요한가 | 설명 |
|-------------|------|
| **공정 방향성** | 식각 프로파일, 임플란트 tilt/twist, 스퍼터 지향성, CMP 방향 등은 웨이퍼 방향에 의존 |
| **계측 재현성** | 항상 같은 좌표계로 측정해야 맵 비교가 가능 |
| **임플란트 채널링 회피** | 결정 방위 기준으로 tilt/twist를 정확히 줘야 함 ([07장](07-ion-implantation.md)) |
| **결정 방위 의존 식각** | 웻 식각(KOH 등)은 결정면에 따라 식각률이 다름 |

**OCR / ID 리딩**: 웨이퍼 엣지에 각인된 ID(레이저 마크)를 읽어 로트·슬롯을 검증합니다. 얼라이너에 함께 붙는 경우가 많습니다.

## 5. 청정도 — 반송부가 파티클의 주범인 이유

기계적으로 움직이는 부분은 반드시 마찰 입자를 냅니다. 팹은 이걸 여러 층으로 막습니다.

| 대책 | 내용 |
|------|------|
| **FFU (Fan Filter Unit) + 하향 기류** | EFEM 상부에서 HEPA/ULPA로 청정 공기를 하향 공급. 파티클이 웨이퍼 위로 떨어지지 않게 **위→아래** 층류를 만듦 |
| **웨이퍼는 항상 수평, 이동 경로 위쪽에 장애물 최소** | 위쪽에 마찰 부위가 있으면 파티클이 떨어짐 |
| **베어링/구동부 밀폐 + 국부 배기** | 구동부에서 나온 입자를 국부적으로 빨아냄 |
| **N₂ 퍼지 EFEM** | 산화·수분 민감 공정(에피, 금속, 하이브리드 본딩 전) 은 EFEM 자체를 N₂로 채워 O₂를 ppm 이하로 |
| **이오나이저 (정전기 제거)** | 웨이퍼·FOUP의 대전은 파티클을 강하게 끌어당김. 이온 발생기로 중화 |
| **AMC 관리 (Airborne Molecular Contamination)** | 파티클이 아닌 **분자 오염**(아민, 산, 유기물). 포토 공정의 레지스트 T-top 등을 유발 → 케미컬 필터 |
| **엣지/백사이드 접촉 최소** | 웨이퍼 뒷면 파티클은 노광 시 포커스 오류(디포커스)와 척킹 불량을 유발 → **백사이드 청정이 중요** |

> **정전기(ESD)의 두 가지 피해**: ① 파티클을 끌어당김, ② 소자 자체를 전기적으로 파괴(특히 게이트). 그래서 반송부에는 이오나이저와 접지 관리가 같이 들어갑니다.

## 6. 진공 반송의 특수 문제

| 문제 | 원인 | 대책 |
|------|------|------|
| **고온 웨이퍼 취급** | 공정 직후 웨이퍼가 수백 ℃ | 세라믹 블레이드, 쿨링 스테이션(로드락 겸용), 냉각 대기 시간 |
| **웨이퍼 휨(warpage)** | 응력 막, 후면 연마 웨이퍼, 본딩 웨이퍼 | 그립 방식 변경, 저속 반송, 척킹 파라미터 조정 |
| **웨이퍼 부착(sticking)** | ESC 잔류 전하, 고온 밀착 | 디척 시퀀스, 리프트 핀 속도 |
| **슬릿 밸브 파티클** | O링 마모, 개폐 마찰 | PM 주기 관리, 저마찰 설계 |
| **압력 차에 의한 비산** | 로드락 급배기 | 슬로우 펌프/벤트 시퀀스 ([0-2장](00-2-vacuum.md)) |
| **진공 중 윤활 문제** | 오일은 아웃개싱 → 사용 제한 | 고체 윤활, 특수 그리스, 마그네틱 커플링 |

## 7. 장비 자동화 인터페이스 — SECS/GEM

장비는 사람이 버튼만 누르는 기계가 아니라 **호스트(MES)와 통신하는 노드**입니다.

| 용어 | 의미 |
|------|------|
| **SECS-I / HSMS** | 물리·전송 계층(직렬 / TCP-IP) |
| **SECS-II** | 메시지 포맷(Sxx Fyy 형식) |
| **GEM (E30)** | 장비 공통 동작 표준(상태 모델, 이벤트, 알람, 레시피 관리) |
| **E84** | **로드포트 자동 반송 핸드셰이크**(OHT가 FOUP을 놓기/집기 전 광통신으로 신호 교환) |
| **E87 / E40 / E94** | 캐리어 관리 / 프로세스 잡 / 컨트롤 잡 |
| **EDA / Interface A (E120 등)** | 장비 데이터 수집(FDC용 고속 트레이스 데이터) |

> 실무: "E84 핸드셰이크 에러"는 팹에서 흔한 알람입니다. OHT와 로드포트 간 광센서 정렬·오염 문제인 경우가 많습니다.

## 8. 300 mm와 450 mm, 그리고 캐리어 규격의 역사

| 세대 | 웨이퍼 | 반송 방식 | 비고 |
|------|--------|-----------|------|
| ~1980s | 100 / 125 mm | 오픈 카세트, 사람이 운반 | 클린룸 자체가 청정도 유일 방어선 |
| 1990s | 150 / 200 mm | SMIF 포드(일부), 카세트 | 부분 자동화 |
| 2000s ~ 현재 | **300 mm** | **FOUP + OHT 완전 자동화** | 인간 손이 웨이퍼에 닿지 않음. 무게 때문에 자동화가 필수가 됨 |
| 시도 | 450 mm | — | 투자 대비 효익 부족으로 사실상 중단. 대신 **미세화 + 3D 적층 + 패키징**으로 방향 전환 |

> **의미**: 450 mm가 멈춘 것은 "장비 발전의 방향이 크기에서 정밀도·적층으로 바뀌었다"는 신호입니다. 그 결과가 EUV, ALD, 하이브리드 본딩 시대입니다.

## 9. 트러블슈팅 — 반송

| 증상 | 의심 | 확인 |
|------|------|------|
| 웨이퍼 미스픽 / 픽 실패 | 티칭 오차, 웨이퍼 존재 센서, FOUP 안착 | 센서 신호, 티칭 값, FOUP 클램프 |
| 반복적 슬립 | 가속도 프로파일, 블레이드 패드 마모, 웨이퍼 뒷면 상태 | 로봇 속도 파라미터, 패드 교체 |
| 파티클이 특정 슬롯/특정 웨이퍼에만 | FOUP 오염, 특정 스테이션 | FOUP 교체 테스트, 스테이션별 파티클 웨이퍼 |
| 웨이퍼 파손 다발 | 핀 높이, 디척 불량, 크래시 후 잔여 파편 | 리프트 레벨링, 파편 수색, 챔버 내부 검사 |
| 매핑 에러(크로스 슬롯) | FOUP 내 웨이퍼 기울어짐, 매핑 센서 오염 | FOUP 상태, 센서 청소 |
| E84 에러 | OHT-로드포트 광통신 정렬/오염 | 센서 청소, 정렬 |
| 노치 정렬 실패 | 얼라이너 센서 오염, 엣지 결손 웨이퍼 | 센서 청소, 웨이퍼 엣지 상태 |
| 백사이드 파티클 → 노광 디포커스 | 척/블레이드/리프트 핀 오염 | 백사이드 검사, 관련 부품 청소 |
