# 부록 D. 트러블슈팅 치트시트 (전 공정 통합)

> 사용법: 증상으로 찾고 → 확인 순서를 따라가고 → 해당 장으로 넘어가 원리를 확인합니다.
> 원칙: **유틸리티 → 반송/척킹 → 가스/진공 → 플라즈마/에너지 → 소모품 → 레시피 → 계측** 순서로 의심합니다.

---

## D-0. 모든 트러블의 첫 5분 — 공통 절차

```
 ① 안전 확인: 가스 경보·이상 소음·이상 냄새·누액 → 있으면 즉시 조치/보고 (진단보다 안전 우선)
 ② 언제부터인가: 알람 발생 시각 ↔ 변경 이력(PM, 부품 교체, 레시피 수정, 유틸리티 작업) 대조
     ★ 트러블 원인 1위는 "무엇이 바뀌었는가" 이다
 ③ 범위 확인: 특정 챔버만? 전체 장비? 특정 로트/제품만? 특정 슬롯만?
 ④ 유틸리티 확인: PCW 온도/유량, CDA 압력, 배기 차압, N₂ 압력, 전원
 ⑤ 재현성 확인: 더미 웨이퍼로 재현되는가? (재현 안 되면 웨이퍼/제품 기인)
```

**공간축으로 원인 범위 좁히기**

| 편차 형태 | 의심 범위 |
|-----------|-----------|
| 웨이퍼 내(센터-엣지, 방향성) | 챔버 내부: 가스 분포, 온도, 링/전극, 플라즈마 대칭 |
| 웨이퍼 간(로트 내 순서 의존) | 챔버 상태 변화(열/퇴적), 첫 장 효과, 아웃개싱 |
| 챔버 간(PM3만) | 소모품 수명 위치, 갭/링 실측, 센서 캘, seasoning |
| 장비 간 | 툴 매칭, 캘 표준, 부품 리비전 |
| 특정 슬롯/FOUP | 반송·FOUP 오염 |
| 특정 제품만 | 패턴 밀도·개구율 의존(장비 문제 아닐 수 있음) |

## D-7. "이건 장비 문제가 아닐 수 있다" 체크리스트

트러블슈팅에서 시간을 가장 많이 낭비하는 경우가 **장비가 아닌 것을 장비 문제로 본 것**입니다.

| 확인 | 왜 |
|------|-----|
| 계측 재현성(게이지 R&R) | 측정 산포를 공정 산포로 오인 |
| 제품/패턴 변경 | 개구율·패턴 밀도가 바뀌면 같은 레시피에서도 결과가 다름 |
| 이전 공정 이력 | 앞 공정의 두께·막질 변화가 이 공정 결과로 나타남 |
| 재료 로트 변경 | 레지스트·슬러리·전구체·타겟·테이프 로트 |
| 유틸리티 작업 | 팹 공사, 냉각수·배기 계통 작업 |
| 소프트웨어/레시피 변경 | 변경 관리 기록 확인 |
| Q-time 초과 | 대기 시간 경과로 산화·오염 |
| 환경(온습도·AMC) | 특히 포토 |
