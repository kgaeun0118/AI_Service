# 04. 식각 장비 — 깎아내는 기술의 정밀도

> 선행 학습: [0-4 플라즈마와 RF](00-4-plasma-and-rf.md), [0-5 척](00-5-thermal-and-chuck.md), [0-8 부품과 소모품](00-8-parts-and-consumables.md)
> 다루는 장비: 웻 벤치(습식) · **CCP 유전막 식각기** · **ICP/TCP 컨덕터 식각기** · HAR 식각(크라이오/펄스) · **ALE** · 애셔(스트립) · 베벨 식각 · 다운스트림 식각

## 1. 공정이 장비에 요구하는 것

식각은 "레지스트 패턴을 아래 막에 옮기는" 공정입니다. 요구는 5개입니다.

| 요구 | 의미 | 왜 어려운가 |
|------|------|-------------|
| **선택비 (selectivity)** | 목표 막은 깎고, 마스크와 하부 막은 남김 | 이온 에너지를 올리면 식각률은 오르지만 선택비는 떨어진다(상충) |
| **방향성 (anisotropy)** | 수직 측벽. 측면으로 파고들면 CD가 무너진다 | 화학 반응은 본질적으로 등방성 → 플라즈마 이온으로 방향을 부여 |
| **CD 제어 / 프로파일** | 목표 선폭·측벽 각도·바닥 형상 | 종횡비가 커질수록 이온·라디칼이 바닥까지 못 감 |
| **균일도** | 웨이퍼 내/간/챔버 간 | 가스·플라즈마·온도·부품 마모 전부가 영향 |
| **무손상 / 무잔류** | 하부 소자 손상, 폴리머 잔류, 금속 오염 없음 | 플라즈마는 본질적으로 손상원 |

```
   [식각 프로파일 용어]

      마스크 ▓▓▓▓            ▓▓▓▓              ▓▓▓▓
      ┌──┐             ┌────┐            ┌──┐
      │  │  수직        ╱      ╲ 테이퍼    │ ╱╲ │  보잉(bowing)
      │  │             ╱        ╲          │╱  ╲│
   ───┴──┴───       ──┴────────┴──      ──┴────┴──
      이상적           경사 측벽           중간이 부풀음(HAR 문제)

   언더컷(undercut): 마스크 아래로 파고듦 → CD 손실
   노칭(notching): 하부 계면 근처에서 옆으로 파임 → 차징(charging) 기인
   마이크로트렌칭: 바닥 모서리가 더 깊게 파임 → 이온 반사
   ARDE / RIE lag: 좁은 패턴이 넓은 패턴보다 느리게 파임
```

## 2. 변천사 — 왜 습식에서 플라즈마로, 그리고 ALE로

| 세대 | 방식 | 한계 → 다음 이유 |
|------|------|-----------------|
| 1960 ~ 70s | **웻 식각(습식)** — 산/염기 용액 | **완전 등방성**. 패턴이 µm 이하로 내려가면 언더컷으로 형상 유지 불가 |
| 1970s 말 | **배럴 플라즈마 식각** (등방성 다운스트림) | 방향성 없음. 레지스트 스트립/등방 제거용으로 남음 |
| 1980s | **RIE (Reactive Ion Etch, CCP)** | 방향성 확보. 이온 에너지·밀도가 함께 변해 제어 한계 |
| 1990s | **MERIE**(자장 보조), **ICP/TCP** 고밀도 저압 | 밀도와 이온 에너지 분리 제어 → 선택비·프로파일 개선 |
| 1990 ~ 2000s | **다중 주파수 CCP** | 유전막 HAR 식각(컨택/비아) 대응 |
| 2000s ~ | **펄스 플라즈마**, 저온/크라이오, **고선택비 화학** | 차징·ARDE 완화, 3D NAND 초고종횡비 대응 |
| 2010s ~ | **ALE (Atomic Layer Etching)** | 원자층 단위 제어. 게이트/스페이서/채널의 극미세 제어 |
| 현재 | **선택적 식각(선택비 무한 지향)**, 등방성 ALE, 3D 구조 전용 | GAA 나노시트 채널 릴리즈, 3D NAND 고단수 |

> **핵심 통찰**: 식각 장비의 역사는 "**같은 화학으로 더 정밀하게**"가 아니라,
> **① 플라즈마 소스 분리 제어 → ② 시간 분해(펄스/ALE) → ③ 온도 축 추가(크라이오)** 로 **제어 축을 하나씩 늘려온** 역사입니다.

## 3. 장비 전체 구조

### 3-1. CCP 유전막 식각 챔버 (옥사이드/나이트라이드, HAR)

```
                    RF #1 (예: 60 ~ 100 MHz, 소스: 밀도)
                          │
         ┌────────────────┴─────────────────┐
         │  상부 전극 = 샤워헤드 (Si 또는 SiC) │ ← 가스 공급 + 전극 겸용
         │  (온도 제어됨, 소모성)              │   상부 전극 재질이 화학에 참여(Si는 F 스캐빈저)
         ├──────────── 갭 (mm 단위, 가변) ────┤
         │      ░░░░░░ 플라즈마 ░░░░░░        │
         ├──────────────────────────────────┤
         │   ███ 웨이퍼 ███                   │
         │   포커스 링 / 에지 링 (소모성)        │ ← 엣지 전기장·열 환경 정합
         │   ESC (멀티존 히터 + He 백사이드)    │
         └────────────────┬─────────────────┘
                          │  RF #2 (2 MHz / 400 kHz, 바이어스: 이온 에너지)
                          │
         [챔버 라이너 (Y₂O₃ 코팅), 배기 링, APC, 터보 펌프]
         [OES 윈도우, IEP 윈도우, 압력 게이지(CDG), 리크 포트]
```

### 3-2. ICP/TCP 컨덕터 식각 챔버 (폴리/금속/실리콘)

```
              RF 소스 (13.56 MHz) ─── 매처
                       │
         ┌─────────────┴────────────────┐
         │   평면 코일 (안테나, 내·외측 분할)│ ← 내/외 비율로 균일도 튜닝
         ╞══════ 유전체 윈도우(석영/알루미나) ══════╡  ← 소모성, 증착물 퇴적
         │     ░░░ 고밀도 플라즈마 ░░░      │
         │   가스 인젝션: 상부 노즐 / 가스 링 │
         ├──────────────────────────────┤
         │   ███ 웨이퍼 ███               │
         │   ESC + 포커스 링              │
         └─────────────┬────────────────┘
                       │  바이어스 RF (이온 에너지 독립 제어)
         [터보 펌프 + APC, 원격 플라즈마 클린 포트]
```

### 3-3. 모듈·부품 사전

| 부품 | 역할 | 소모/고장 시 증상 | 관리 |
|------|------|-------------------|------|
| **샤워헤드/상부 전극** | 가스 분배 + 전극. 재질(Si/SiC/Al+코팅)이 **화학에도 참여** | 홀 확장·막힘 → 균일도/시그니처, 두께 감소 → 갭 변화 → 결과 시프트 | 두께 실측, 교체 주기, 온도 제어 |
| **포커스 링 / 에지 링** | 웨이퍼 외곽의 전기장·플라즈마 경계 정합 | 마모 → **엣지 CD/식각률 드리프트**, 엣지 틸트 | 두께 실측, RF hour 카운트. 최신 장비는 **in-situ 링 높이 보정** 기능 보유 |
| **ESC** | 웨이퍼 고정 + 온도 제어 | He 누설↑, 국부 온도 이상 | [0-5장](00-5-thermal-and-chuck.md) |
| **챔버 라이너/실드 (Y₂O₃)** | 벽 보호, 라디칼 재결합 제어 | 퇴적물 박리 → 파티클, 코팅 소진 → 금속 오염 | 누적 두께·RF hour, 재생 관리 |
| **유전체 윈도우(ICP)** | RF 결합 통로 | 증착물 → 결합 효율 변화(식각률 드리프트) | 청소/교체 |
| **코일(ICP)** | 플라즈마 생성 | 변형·오염 | 내·외 밸런스 점검 |
| **가스 링/인젝터** | 가스 공급 위치 | 막힘 → 방향성 있는 편차 | 세정 |
| **APC + 터보펌프** | 압력 제어 | 개도 드리프트 → 배기 저하 | [0-3장](00-3-gas-and-fluids.md) |
| **OES/IEP 윈도우** | 종점 검출 | 흐려짐 → 종점 미검출 | 정기 청소 |
| **원격 플라즈마 클린(RPS)** | 챔버 내 퇴적물 제거 | 효율 저하 → 파티클 | NF₃ 유량·소스 상태 |

## 4. 작동 원리 — 웨이퍼 한 장의 여정

```
 ① 로드락 → TM → 챔버 (슬릿 밸브 열림/닫힘)
 ② 척킹: ESC 전압 인가 → He 백사이드 공급 → 누설률 확인 (불량이면 중단)
 ③ 가스 도입 + 압력 안정화 (stabilization step, 수 초)
 ④ 플라즈마 점화(strike): 점화 용이 조건 → 본 조건으로 이행, 매처 튜닝
 ⑤ 메인 식각: 다중 스텝 (브레이크스루 → 메인 → 오버에치)
      · 브레이크스루: 자연산화막/하드마스크 상단 제거
      · 메인: 목표 막 식각, 종점 검출(OES/IEP)
      · 오버에치: 잔류 제거 + 균일도 보정 (선택비 높은 조건으로 전환)
 ⑥ 플라즈마 오프 → 퍼지 → 디척킹(잔류 전하 제거) → 리프트 → 반출
 ⑦ (필요 시) WAC(웨이퍼리스 오토클린) 수행 후 다음 웨이퍼
```

**왜 스텝을 나누는가**
- 각 단계의 목적이 다릅니다(뚫기 / 파기 / 남은 것 정리).
- 한 조건으로는 "빠르게 + 선택적으로 + 균일하게"를 동시에 만족할 수 없습니다.
- 오버에치는 **웨이퍼 내 편차를 흡수하는 완충 구간**입니다. 이 구간의 선택비가 하부 손상을 결정합니다.

## 5. 식각 화학 — 무엇으로 무엇을 깎는가

| 대상 막 | 주요 가스 | 부산물 | 포인트 |
|---------|-----------|--------|--------|
| **SiO₂ (옥사이드)** | CF₄, CHF₃, C₄F₈, C₄F₆ + O₂ + Ar | SiF₄, CO, COF₂ | 폴리머 생성/제거 균형이 선택비를 만든다. Ar은 희석·이온 충격 |
| **Si₃N₄ (나이트라이드)** | CH₂F₂, CHF₃, CH₃F + O₂ | SiF₄, HCN 등 | 옥사이드 대비 선택비 확보가 핵심(스페이서) |
| **폴리실리콘** | Cl₂, HBr, (+O₂, CF₄) | SiCl₄, SiBr₄ | 게이트 식각. 산화막 선택비·프로파일 관리 |
| **단결정 Si (딥 트렌치)** | HBr/Cl₂, SF₆/O₂(크라이오), Bosch(SF₆/C₄F₈) | — | HAR, MEMS/TSV |
| **W (텅스텐)** | SF₆, NF₃, Cl₂ | WF₆ | 금속 비아/게이트 |
| **Al** | Cl₂ + BCl₃ (+ N₂) | AlCl₃ | **BCl₃가 자연산화막(Al₂O₃) 제거**. 식각 후 즉시 부식 방지 처리 필요(Cl 잔류 → 대기 수분과 부식) |
| **TiN / Ti** | Cl₂ 계열 | TiCl₄ | 배리어 |
| **Cu** | **실용적 플라즈마 식각 불가** | — | 휘발성 화합물이 저온에서 없음 → **다마신 + CMP**로 우회 ([06장](06-metallization-pvd-ecp.md), [08장](08-cmp.md)) |
| **레지스트/폴리머 (애싱)** | O₂ (+N₂/H₂, 포밍가스) | CO₂, H₂O | 다운스트림(무손상) 방식 선호. 저유전막은 O₂ 손상 → H₂/N₂ 계열 |
| **고유전막(HfO₂)** | BCl₃/Cl₂ 계열, 고온 | — | 난식각. ALE 적용 |

### 폴리머 — 식각의 숨은 주인공

```
   플루오로카본 가스는 식각만 하는 게 아니라 측벽에 폴리머(CFx) 막을 만든다.

   측벽: 이온이 거의 안 오므로 폴리머가 살아남음 → 측벽 보호 → 수직 프로파일
   바닥: 이온이 수직으로 때려 폴리머를 제거 → 식각 진행

   → 즉 "쌓으면서 깎는다". 이 균형을 조절하는 것이 식각 레시피의 본질이다.

   C/F 비율이 높은 가스(C₄F₆ > C₄F₈ > CHF₃ > CF₄) → 폴리머 많음 → 선택비↑, 프로파일↑
   O₂ 추가 → 폴리머 제거 → 식각률↑, 선택비↓
```

| 폴리머가 너무 많으면 | 폴리머가 너무 적으면 |
|---------------------|---------------------|
| 식각 정지(etch stop), 바닥 잔류, 파티클, 홀 막힘 | 언더컷, 측벽 손실, 마스크 소모, CD 확대 |

## 6. 고종횡비(HAR) 식각 — 3D NAND가 만든 극한

3D NAND의 채널 홀은 종횡비가 수십:1 이상(수 µm 깊이 / 수십 nm 직경)에 이릅니다. 여기서 새로운 물리가 지배합니다.

| 문제 | 원인 | 대책(장비/공정) |
|------|------|-----------------|
| **ARDE / RIE lag** | 좁은 구멍은 라디칼·이온 공급이 부족 | 압력↓, 펄싱, 고이온에너지, 시간 증가 |
| **보잉(bowing)** | 상부에서 이온이 측벽에 반사/산란 | 이온 에너지 분포 제어, 폴리머 강화, 마스크 형상 |
| **트위스팅(twisting)** | 깊어질수록 이온 궤적이 미세하게 휘어 구멍이 비틀림 | 차징 제어(펄스), 스택 스트레스, 마스크 |
| **차징(charging)** | 절연막에 전하 축적 → 이온 감속·편향 | **펄스 플라즈마**(전자를 주기적으로 공급), 저주파 바이어스 |
| **마스크 소모** | 긴 식각 시간 | 초후막 하드마스크(비정질 카본 등), 선택비 화학 |
| **바닥 잔류/에치 스톱** | 부산물이 빠져나오지 못함 | 압력/유량, 주기적 퍼지, 온도 |
| **열 문제** | 장시간 고파워 | 척 냉각, He 압력, 크라이오 |

### 크라이오 식각 — 온도를 제어 축으로 추가

```
   웨이퍼를 매우 낮은 온도(예 −40 ~ −100 ℃ 대)로 유지하면
    · 부산물/폴리머의 측벽 흡착이 강해져 측벽 보호가 개선
    · 등방성 성분이 억제되어 프로파일이 수직에 가까워짐
    · 식각률과 선택비가 동시에 향상되는 조건 창이 존재

   장비 요구: 극저온 칠러, ESC 열설계, 결로/응축 방지, 척킹 특성 변화 대응
   → 최신 HAR 식각의 중요한 무기 중 하나
```

## 7. ALE (Atomic Layer Etching) — 원자층 단위 제어

```
   [열적/플라즈마 ALE 사이클 — 예: Si의 Cl 기반 ALE]

   ① 표면 개질(modification): Cl₂ 라디칼을 흡착시켜 표면 1~2 원자층만 반응층으로 만든다
   ② 퍼지: 잔류 반응종 제거
   ③ 제거(removal): 저에너지 Ar 이온으로 반응층만 물리적으로 떼어냄
      (에너지를 "반응층은 떼어지고 순수 Si는 안 떼어지는" 창에 맞춤)
   ④ 퍼지 → 반복

   → 사이클당 제거량(EPC)이 수 Å로 고정 = "자기 제한적(self-limiting)"
   → 균일도·선택비·손상 면에서 압도적, 대신 느리다 (사이클 수 × 시간)
```

| 항목 | 내용 |
|------|------|
| 장점 | 원자층 수준 두께 제어, 웨이퍼 내 균일도 우수, 손상 최소, 종횡비 의존 감소 |
| 단점 | 처리량 낮음 → **꼭 필요한 마지막 단계에만** 적용 |
| 장비 요구 | 빠른 가스 스위칭(밸브·압력식 MFC), 정밀 저에너지 이온 제어(펄싱), 짧은 퍼지 |
| 적용 | 게이트/스페이서 정밀 트리밍, 나노시트 채널 릴리즈, 고유전막, 원자층 세정 |

> **ALD와 대칭적 사고**: ALD는 자기제한 증착, ALE는 자기제한 식각입니다. 둘 다 "화학을 시간으로 분리"해 정밀도를 얻습니다([05장](05-deposition-cvd-ald.md)).

## 8. 기타 식각 관련 장비

| 장비 | 역할 | 특징 |
|------|------|------|
| **애셔 (asher / 스트립)** | 레지스트·폴리머 제거 | 다운스트림(원격) 플라즈마로 이온 손상 없이. 저유전막에는 H₂/N₂ 계열 |
| **베벨/엣지 식각기** | 웨이퍼 최외곽·경사면의 막 제거 | 엣지 막 박리 → 파티클 근원 차단. 전용 챔버 |
| **웻 벤치 / 싱글 웻 식각** | 등방성 제거, 선택적 제거(예: SiGe 대 Si, 산화막 HF) | 나노시트 릴리즈, 희생층 제거에서 다시 중요해짐 ([09장](09-cleaning.md)) |
| **기상 식각 (vapor HF / COR)** | 무액체 등방 제거 | 패턴 붕괴 회피, 자연산화막 제거 |
| **선택적 식각(ALE/열적)** | 특정 재료만 제거 | GAA 채널 릴리즈 등 3D 구조 필수 |
| **플라즈마 다이싱** | 웨이퍼를 식각으로 절단 | 후공정이지만 식각 장비 기술 ([11장](11-packaging.md)) |

## 9. 장비 노브 ↔ 공정 결과 (식각 종합표)

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| **소스 파워 ↑** | 라디칼·이온 밀도 ↑ | 식각률 ↑ | 선택비 변화, 부품 소모, 열 |
| **바이어스 파워 ↑** | 이온 에너지 ↑ | 방향성 ↑, HAR 진행 ↑, 잔류 제거 | **선택비 ↓**, 마스크 소모 ↑, 하부 손상 ↑, 부품 스퍼터 |
| **압력 ↑** | 라디칼 밀도 ↑, 평균자유행정 ↓ | 화학 성분 ↑, 식각률 ↑ | 등방성 ↑, ARDE 악화, 폴리머·파티클 |
| **C/F 비 높은 가스** | 폴리머 ↑ | 선택비 ↑, 측벽 보호 ↑ | 잔류·에치스톱, 홀 막힘 |
| **O₂ 추가** | 폴리머 제거 | 식각률 ↑, 잔류 ↓ | 선택비 ↓, 레지스트 소모 ↑ |
| **Ar 희석** | 이온 충격·희석 | 프로파일 안정 | 식각률 ↓ |
| **웨이퍼 온도 ↑** | 부산물 탈착 ↑ | 잔류 ↓, 식각률 ↑ | 선택비 ↓, 측벽 보호 ↓ |
| **웨이퍼 온도 ↓(크라이오)** | 측벽 흡착 ↑ | 프로파일·선택비 ↑ | 결로, 장비 복잡도 |
| **펄싱(듀티/주파수)** | 라디칼/이온 비, 차징 완화 | HAR 프로파일·ARDE 개선, 선택비 ↑ | 실효 식각률 ↓ |
| **갭(CCP)** | 전력 밀도·체류시간 | 균일도·프로파일 | 재튜닝 필요, 아킹 |
| **센터/엣지 가스 비** | 반경 방향 라디칼 분포 | 웨이퍼 내 균일도 | 과보정 시 반전 |
| **멀티존 척 온도 프로파일** | 반경 방향 반응 속도 | **CD 균일도 미세 보정** | 상충 항목 발생 |
| **오버에치 시간** | 잔류 흡수 | 잔류 제거, 균일도 | 하부 손상, CD 손실 |

## 10. 불량과 장비 원인 (트러블슈팅)

| 증상 | 의심 | 확인 순서 |
|------|------|-----------|
| 엣지 CD/식각률만 드리프트 | **포커스/에지 링 마모**, 웨이퍼 휨, 엣지 온도 | 링 두께 실측 + RF hour, He 누설률, 교체 후 회복 여부 |

| 바닥 잔류(etch stop) | 폴리머 과다, 압력/온도, 부산물 배출 | O₂ 비율, 압력, 오버에치, HAR이면 펄싱 |

| 노칭(하부 계면 측면 파임) | 차징 | 펄스 플라즈마, 바이어스 저주파화 |
| 파티클 급증 | 라이너/실드 박리, 아킹, 폴리머 | 누적 두께 카운트, 아크 로그, 클린 주기, 조성 분석(EDX) |
| 챔버 간 CD 차 | 소모품 수명 위치, 갭, 센서 캘, seasoning | 실측 비교, 카운터 비교, 매칭 절차 |
| PM 후 결과 시프트 | 부품 리비전/두께, seasoning 부족, 접지 | 부품 스펙 확인, 더미 수 증가, RF 접지 점검 |
| 금속 오염 검출 | 챔버 부품 스퍼터(코팅 소진), 실드 | 부품 수명, 코팅 상태, TXRF 원소로 부품 추정 |
| 하부 소자 손상(누설 증가) | 바이어스 과다, 차징, VUV | 파워 하향, 펄싱, 다운스트림 방식 검토 |
| Al 배선 식각 후 부식 | Cl 잔류 + 대기 수분 | 식각 후 in-situ 패시베이션/H₂O 퍼지, 즉시 세정(Q-time 단축) |

## 11. 실무 — PM/Qual 체크리스트 (식각 챔버)

```
 PM 전:  클린 수행 → 레시피 정지 → 벤트 → LOTO
 분해:   상부 전극/샤워헤드 → 링류 → 라이너/실드 → ESC 점검
 실측:   전극 두께, 링 두께, 갭, ESC 표면 상태(육안·조도)
 조립:   세정 부품만 사용, O링 홈 무결점, 지정 토크, 접지 가스켓 필수 장착
 검증:   리크 체크(He/ROR) → 베이스 압력 → 게이지·MFC 확인 → RF 매칭 범위 확인
 Seasoning: 더미 웨이퍼 N장(챔버별 표준화)
 Qual:  ① 파티클(비패턴) ② 식각률·균일도 ③ CD/프로파일(SEM) ④ 선택비 ⑤ 챔버 매칭
 릴리즈: 데이터 승인 후 양산 투입
```

**일상 모니터링 항목**: 식각률·균일도 트렌드, 파티클, APC 개도, RF 반사/매처 포지션, He 누설률, OES 지표, 부품 카운터.
