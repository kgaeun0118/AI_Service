# 0-3. 가스와 유체 계통 — 장비의 혈관

> 선행 학습: [0-2 진공](00-2-vacuum.md)
> 요지: 공정의 결과는 "무엇을 얼마나 정확히, 어떤 순서로 넣었는가"로 결정된다. 그 정확도를 만드는 하드웨어가 이 장의 내용이다.

---

## 1. 왜 가스 계통이 공정 품질을 지배하는가

증착막 두께, 식각률, 도핑 농도 — 전부 **단위시간당 공급된 반응물의 양**에 1차적으로 비례합니다.
가스 유량이 1 % 틀어지면 막 두께도 대략 그 수준으로 틀어집니다. 그런데 팹에서 요구하는 두께 재현성은 보통 **1 % 이내**입니다.
→ 즉 **가스 계통은 공정 스펙과 같은 정밀도**를 요구받습니다.

또한 가스 계통은 **장비에서 가장 위험한 부분**입니다. 반도체 특수가스에는 자연발화성(SiH₄), 맹독성(AsH₃, PH₃, B₂H₆), 부식성(Cl₂, HBr, HF, WF₆), 강산화성(F₂, NF₃, O₃)이 모두 있습니다.

## 2. 가스가 팹 벽에서 챔버까지 오는 전 경로

```
 [① 가스 야드 / 실린더 캐비닛]   팹 외부 또는 별도 격리실
    · 실린더(또는 벌크 탱크/ISO 탱크)
    · 자동 밸브, 과압 방지, 가스 검출기, 배기 인터락
         │
         ▼
 [② VMB / VMP (Valve Manifold Box/Panel)]  공급 구역 분배
    · 실린더 교체 시 무중단 공급(A/B 뱅크 자동 전환)
    · 퍼지(purge) 시퀀스: 진공-N₂ 반복으로 대기/수분 제거
         │
         ▼
 [③ 팹 배관 (SS316L EP 튜브, orbital weld)]
    · 전해연마(EP) 내면, 용접부 최소화, 데드볼륨 최소화
         │
         ▼
 [④ 장비 가스박스 (Gas Box / Gas Panel)]  ← 장비 뒷문 열면 있는 그것
    · 채널별: 필터 → 레귤레이터 → 프라이머리 밸브 → MFC → 다운스트림 밸브 → (체크밸브)
    · 퍼지 매니폴드(N₂), 진공 제너레이터
         │
         ▼
 [⑤ 스틱/매니폴드 → 챔버 유입부]
    · 샤워헤드 / 가스 링 / 사이드 인젝터 / 이중 채널(듀얼 존)
    · 히팅 라인(응축 방지), VCR 피팅
         │
         ▼
 [⑥ 챔버] ──▶ [⑦ 포어라인] ──▶ [⑧ 드라이 펌프] ──▶ [⑨ 스크러버] ──▶ 팹 배기(exhaust)
                 (히팅+N₂퍼지)                        (연소/습식/건식/플라즈마)
```

각 단계에서 무엇을 신경 쓰는지가 이 장의 본문입니다.

## 3. MFC — 유량을 만드는 핵심 부품

**MFC(Mass Flow Controller)** 는 "설정값(sccm)대로 질량 유량을 흘려주는" 폐루프 장치입니다. 공정 레시피의 `Ar 100 sccm`이 실제 물리량으로 바뀌는 지점입니다.

### 3-1. 원리 두 가지

| 방식 | 원리 | 특징 |
|------|------|------|
| **열식 (thermal MFC)** | 바이패스 관을 우회한 가느다란 센서 튜브에 히터 2개. 기체가 흐르면 열이 하류로 실려가 온도차 발생 → 그 차이가 **질량 유량**에 비례 | 가장 보편적. 응답 1~2초. 기체 종류별 **비열/열전도 보정계수(CF)** 필요 |
| **압력식 (pressure-based / PC-MFC)** | 음속 노즐(critical orifice)에 상류 압력을 정밀 제어. 상류압 ∝ 유량 | 응답 빠름(수백 ms), 조성 변화·오염에 강함. **ALD의 짧은 펄스**에 유리 |

```
  [열식 MFC 개념도]

   입구 ──┬─── 바이패스(주 유로) ────┬── 컨트롤 밸브 ── 출구
          │                          │        ▲
          └─ 센서튜브 ─(히터1)(히터2)─┘        │ (폐루프)
                     ΔT  ──▶  유량 신호 ──▶ 비교기(설정값) ──┘
```

### 3-2. MFC에서 반드시 알아야 할 실무

| 항목 | 내용 |
|------|------|
| **환산계수(CF, Conversion Factor)** | MFC는 보통 N₂로 캘리브레이션됨. 다른 가스는 CF로 환산. **가스를 바꿔 쓰면 값이 틀어짐** — 레시피 이관 시 제1의 함정 |
| **Full Scale와 사용 범위** | 풀스케일의 **10 ~ 90 %** 구간에서만 정확. 100 sccm MFC로 3 sccm을 흘리면 오차가 큼 → 저유량 채널은 별도 소용량 MFC 사용 |
| **응답시간과 오버슈트** | 레시피 스텝 전환 시 오버슈트가 막질에 영향. ALD는 오버슈트가 치명적 → 압력식/빠른 밸브 사용 |
| **드리프트와 캘리브레이션** | 필라멘트 오염·파우더 퇴적으로 서서히 어긋남. **정기 검증(ROR, Rate-of-Rise)** 필수 |
| **ROR 검증법** | 다운스트림 밸브를 닫고 일정 체적에 채워 압력 상승률 측정 → 실유량 계산. 장비 자체 기능으로 들어있는 경우가 많음 |
| **부식성 가스 대응** | 습기와 만나 산 생성(HF, HCl) → 부식·파티클. **퍼지 후 벤팅** 규칙 준수, 내식 사양 MFC 사용 |

> **트러블 예**: 증착 두께가 웨이퍼 전체에서 2 % 낮아졌고, 챔버 청소·부품 교체로 회복되지 않는다.
> → MFC 드리프트 의심. ROR로 실유량 확인 → 설정 100 sccm에 실제 97 sccm이면 원인 확정.

## 4. 압력 제어 — APC와 가스 흐름의 관계

공정압은 `유입 유량`과 `배기 능력`의 균형으로 결정됩니다.

```
   P_chamber ≈ Q_in / S_eff(밸브 개도)

  · 유량 고정 + APC 개도 조절 → 압력 제어 (가장 일반적)
  · 밸브 고정 + 유량 조절 → 압력 제어 (특수 케이스)
```

| 제어 모드 | 방식 | 쓰는 곳 |
|-----------|------|---------|
| **Pressure mode** | CDG 읽고 APC 개도를 폐루프로 조절 | 대부분의 식각/CVD |
| **Position mode** | APC 개도를 고정값으로 | 압력이 아니라 **컨덕턴스**를 고정하고 싶을 때, 재현성 디버깅 시 |
| **Throttled / Full open** | 스로틀 없음 | 초저압 공정(PVD 베이스 근처) |

**실무 포인트**
- **APC 개도 값을 트렌드로 보세요.** 같은 레시피에서 개도가 점점 열리고 있다면 = 배기 능력 저하(파우더 퇴적/펌프 열화) 또는 누설. 압력은 스펙 안에 있어도 이미 상태는 나빠지고 있습니다. 대표적인 **선행지표(FDC 지표)** 입니다.
- 개도가 한쪽 끝(거의 닫힘/거의 열림)에 붙으면 **제어 불능** — 레시피 설계 오류이거나 계통 문제입니다.

## 5. 가스 유입 구조 — 균일도를 만드는 하드웨어

같은 가스를 넣어도 **어디로 어떻게 넣는지**가 웨이퍼 내 균일도를 결정합니다.

| 구조 | 형태 | 특성 | 쓰이는 곳 |
|------|------|------|-----------|
| **샤워헤드 (showerhead)** | 웨이퍼 위 평행판에 수천 개 홀 | 수직·균일 공급. 홀 지름/피치/배압이 균일도 결정. 전극 겸용인 경우 많음 | PECVD, CCP 식각, ALD |
| **듀얼 채널 샤워헤드** | 두 종류 가스를 챔버 안에서 처음 만나게 | 전구체 간 사전 반응(gas-phase reaction, 파우더 생성) 방지 | TEOS+O₃, ALD |
| **가스 링/노즐 (gas ring)** | 웨이퍼 둘레에서 측면 유입 | 웨이퍼 위 공간이 비어야 하는 구조(ICP 등)에 적합. 엣지 편중 주의 | ICP 식각, PVD |
| **센터/엣지 분리 주입 (dual zone)** | 중앙과 외곽에 유량 배분 | **균일도 튜닝 노브**. C/E 비율로 센터-엣지 프로파일 보정 | 최신 식각/CVD |
| **인젝터 + 회전 서셉터** | 회전하며 순차 노출 | 공간분리형 ALD, 에피 | Spatial ALD, 일부 에피 |

**샤워헤드에서 신경 쓰는 것**
1. **홀 막힘**: 부산물 퇴적 → 국부 유량 저하 → 웨이퍼에 그 패턴이 그대로 찍힘(시그니처 결함).
2. **배압(back pressure)**: 홀을 통과할 때 적절한 압력 강하가 있어야 전면 균일 분배가 됩니다. 홀이 넓으면 중앙 편중.
3. **전극 겸용 시 갭(gap)**: 샤워헤드-웨이퍼 간격은 플라즈마 특성과 균일도를 동시에 바꾸는 강력한 노브(보통 mm 단위).
4. **온도**: 샤워헤드가 차면 응축·파우더, 뜨거우면 전구체 조기 분해. 그래서 샤워헤드도 **가열/냉각 제어**합니다.

## 6. 응축과 Cold Spot — 액체·고체 전구체를 다루는 법

> 이 절은 [06장 Metallization](06-metallization-pvd-ecp.md)과 [05장 ALD](05-deposition-cvd-ald.md)의 전제입니다. **"재료마다 물성이 달라 기화가 다른 문제"** 의 핵심 하드웨어 이야기입니다.

상온에서 기체인 가스(Ar, N₂, SiH₄, NF₃, WF₆)는 그냥 MFC로 흘리면 됩니다. 문제는 **상온에서 액체·고체인 전구체**입니다.

### 6-1. 전달 방식 4가지

| 방식 | 구조 | 적용 | 장단점 |
|------|------|------|--------|
| **버블러 (bubbler)** | 캐리어 가스(Ar/N₂)를 액체 속으로 불어넣어 포화 증기를 실어냄 | TEOS, TMA, TiCl₄ 등 증기압이 비교적 높은 액체 | 단순·안정. 유량 = f(캐리어 유량, 앰플 온도, 헤드스페이스 압력) → **3개를 모두 제어**해야 재현성 확보 |
| **베이퍼 드로우 (vapor draw)** | 캐리어 없이 증기만 뽑음 | 증기압 충분한 액체 | 캐리어 희석 없음. 유량 안정성 확보가 어려움 |
| **DLI / 기화기 (Direct Liquid Injection + vaporizer)** | 액체를 액체 MFC로 계량 → 기화기에서 순간 기화 | 증기압 낮은 고분자 전구체(Hf/Zr/Sr/Ba 계열) | 유량 정밀·대유량 가능. 기화기 막힘/열분해 리스크 |
| **고체 앰플 승화 (solid source sublimation)** | 고체를 가열해 승화, 캐리어로 이송 | HfCl₄, ZrCl₄, MoO₂Cl₂, 일부 Ru 전구체, AlCl₃ | 표면적 변화로 **공급량이 시간에 따라 감소**(depletion) → 잔량 관리·앰플 설계(다공성 캐리어)가 핵심 |

### 6-2. 온도 프로파일 규칙 — "진행 방향으로 계속 더 뜨겁게"

전구체는 어디든 **가장 차가운 지점(cold spot)에서 응축/석출**합니다. 그래서 배관 설계의 절대 원칙이 있습니다.

```
   앰플(80 ℃) ──▶ 밸브(90 ℃) ──▶ 라인(100 ℃) ──▶ MFC/밸브(110 ℃) ──▶ 샤워헤드(120 ℃) ──▶ 챔버
        온도가 흐름 방향으로 단조 증가 (보통 각 구간 +5 ~ +10 ℃)

   ※ 어느 한 곳이라도 앞보다 차가우면 → 거기서 응축
      → ① 유량 저하/불안정  ② 파티클  ③ 밸브 고착  ④ 막 두께 드리프트
```

| 실무 포인트 | 설명 |
|-------------|------|
| **히팅 자켓/히팅 케이블의 사각지대** | 피팅, 밸브 보디, 센서 포트, 지지 브라켓은 열이 빠져나가 국부적으로 차가워짐 → 여기가 상습 cold spot. PM 후 재장착 시 자켓 밀착 확인이 중요 |
| **상한 온도** | 너무 뜨거우면 전구체가 배관 내에서 **열분해**되어 벽에 막이 생기고 파티클·막힘 유발. 온도창이 좁다 |
| **앰플 온도 정밀도** | 증기압은 온도에 대해 지수적(클라우지우스-클라페이롱). 앰플 ±1 ℃는 공급량 수 %에 해당 → 두께 변동 직결 |
| **앰플 잔량과 depletion** | 액체는 액면 감소 → 헤드스페이스 증가, 고체는 표면적 감소 → 공급량 감소. **잔량 구간별 보정** 또는 조기 교체로 관리 |
| **압력 제어(Pressure-based delivery)** | 헤드스페이스 압력을 일정하게 유지(압력 컨트롤러)해 캐리어 희석비를 고정하면 재현성이 크게 개선 |
| **잔류 전구체 제거** | 교체·PM 전에 반드시 퍼지/진공 사이클. 공기와 만나면 발화하는 전구체(TMA, DEZ 등 pyrophoric)가 많음 |

> **이것이 "재료마다 물성이 달라 기화가 다르다"는 문제를 장비가 푸는 방식입니다.**
> 증기압이 높으면 → 버블러/베이퍼 드로우. 낮으면 → 가열 + DLI. 고체면 → 승화 앰플 + 표면적 설계.
> 전부 안 되면 → **애초에 다른 화학을 선택**하거나 **PVD/도금으로 전환**합니다. 상세 사례는 [06장](06-metallization-pvd-ecp.md) 참조.

## 7. 팹 유틸리티 — 장비가 먹고 마시는 것들

장비 사양서 뒤쪽 "Facility Requirements" 에 나오는 항목들입니다. 장비 설치(installation)와 트러블의 상당수가 여기서 옵니다.

| 유틸리티 | 약어 | 전형적 조건 | 장비에서의 역할 | 이상 시 증상 |
|----------|------|-------------|-----------------|--------------|
| **공정 냉각수** | PCW (Process Cooling Water) | 20 ~ 25 ℃, 2 ~ 5 bar, 도전율 관리 | RF 전원, 매처, 펌프, 챔버 벽, 타겟, 척 냉각 | 온도 드리프트, RF 트립, 타겟 크랙, 인터락 다운 |
| **청정 건조 공기** | CDA (Clean Dry Air) | 6 ~ 7 bar, dew point 낮게 | 공압 밸브·실린더·도어 구동 | 밸브 오동작, 반송 에러 |
| **질소** | N₂ | 순도 5N~6N | 퍼지, 벤트, 펌프 희석, 에어커튼 | 수분 유입, 부식, 파우더 |
| **아르곤** | Ar | 고순도 | 플라즈마/스퍼터, 캐리어 | 방전 불안정 |
| **초순수** | UPW / DIW | 18.2 MΩ·cm | 세정, CMP, 웻 벤치 | 워터마크, 결함 |
| **진공(하우스 진공)** | HV | — | 척킹(대기측 반송), 클램프 | 웨이퍼 미스픽/드랍 |
| **배기** | Exhaust | 가스별 분리(산/알칼리/가연/VOC/열) | 유해가스 배출 | 가스 누출 경보, 인터락 |
| **전력** | — | 200/380/480 V 3상, 수십~수백 kVA | 전원반 | 전압 변동에 의한 RF/히터 이상 |

> **초보자가 놀라는 사실**: 장비 알람의 상당 부분은 장비 자체가 아니라 **PCW 온도/유량, CDA 압력, 배기 차압** 같은 유틸리티 쪽입니다.
> 그래서 트러블슈팅 첫 단계는 언제나 **"유틸리티부터 확인"** 입니다.

## 8. 배기 후처리 — 스크러버

챔버에서 나온 가스는 그대로 버릴 수 없습니다. 미반응 전구체, 독성·가연성 가스, PFC(온실가스), 파우더가 들어 있습니다.

| 스크러버 종류 | 원리 | 잘 잡는 것 | 특징 |
|---------------|------|-----------|------|
| **연소식 (burn/combustion, thermal)** | 연료(보통 천연가스/수소) + 공기로 태움 | SiH₄, PFC(CF₄/NF₃/SF₆), 가연성 | 고온 필요. 파우더(SiO₂) 생성 → 정기 청소 |
| **습식 (wet)** | 물/알칼리 용액에 용해·중화 | HCl, HF, Cl₂, NH₃, 수용성 산/염기 | 배수 처리 필요. 부식 관리 |
| **건식 (dry, 흡착제)** | 화학 흡착 매체를 통과 | 소량 독성가스(AsH₃, PH₃) | 카트리지 교체형, 소용량 |
| **플라즈마 (plasma abatement)** | 플라즈마로 분해 후 습식 흡수 | PFC/N₂O 등 난분해성 | PFC 저감 규제 대응, 전력 소모 |
| **콤보 (burn-wet)** | 연소 후 습식 | 대부분의 팹 표준 | 유지보수 항목 많음 |

**포어라인 관리 3대 항목**
1. **히팅**: 응축 방지(보통 100 ~ 150 ℃). 히터 단선이 곧 배관 막힘.
2. **N₂ 퍼지**: 부산물 희석·이송.
3. **트랩(파우더 트랩)**: 챔버 하류에서 파우더를 걸러 펌프를 보호. 트랩 청소 주기가 곧 펌프 수명.

## 9. 가스별 위험과 취급 — 반드시 아는 최소 지식

| 가스 | 위험 성질 | 대표 용도 | 장비/시설 대응 |
|------|-----------|-----------|----------------|
| **SiH₄ (실란)** | **자연발화성(pyrophoric)** | CVD Si/SiO₂/SiN | 이중 배관, 과잉 배기, 연소식 스크러버, 누출 검지 |
| **AsH₃ / PH₃ (아르신/포스핀)** | **극독성**(ppb 수준 관리) | 임플란트, 에피 도핑 | 독성가스 검지기, 흡착 스크러버, 서브어톰 실린더(저압 저장) |
| **B₂H₆ (디보란)** | 독성·가연성 | 도핑, W 핵생성 | 상동 |
| **Cl₂ / HBr / BCl₃** | 부식성·독성 | 금속/Poly 식각 | 내식 배관, 습식 스크러버, 배기 후 퍼지 |
| **HF / WF₆ / F₂ / NF₃** | 부식성·산화성(F계) | 세정, W 증착, 챔버 클린 | 수분 절대 금지(HF 생성), 특수 실 |
| **O₃ (오존)** | 강산화성, 불안정 | SACVD, 세정 | 현장 발생기(저장 불가), 오존 파괴기 |
| **H₂** | 가연성(넓은 폭발 범위) | 에피, EUV, 어닐 | 방폭 설계, 누출 검지, 희석 |
| **NH₃** | 독성·자극성 | SiN 증착 | 습식 스크러버 |
| **PFC (CF₄, C₄F₈, SF₆, NF₃)** | 강력한 온실가스(GWP 수천~수만) | 식각/챔버 클린 | 저감 장치 의무화, NF₃ 원격 플라즈마로 대체 추세 |

> **안전은 "규정 준수"가 아니라 물리입니다**: 실란 배관을 열 때 왜 반드시 진공-N₂ 사이클 퍼지를 반복하는지 이해하면 규정을 어길 수 없습니다.
> 잔류 실란 + 공기 = 즉시 발화. 예외가 없습니다. 상세는 [0-9 안전](00-9-operations-and-safety.md).

## 10. 가스 계통 트러블슈팅

| 증상 | 의심 | 확인 |
|------|------|------|
| 막 두께가 서서히 얇아짐 | MFC 드리프트, 앰플 depletion, 샤워헤드 막힘 | ROR 검증, 앰플 잔량/온도 로그, 샤워헤드 육안 |
| 웨이퍼에 국부적(spot) 두께/식각 이상 | 샤워헤드 홀 막힘/손상 | 시그니처 패턴 대조, 샤워헤드 교체 시 개선 여부 |
| 센터-엣지 프로파일 반전 | 듀얼존 유량 배분, 챔버 갭, APC 개도 | C/E 비율 스윕, 갭 확인 |
| 레시피 스텝 초반 불안정 | MFC 오버슈트, 밸브 응답, 압력 정착 시간 | 트레이스 데이터의 초기 1~3초 확인, stabilization step 추가 |
| 파티클 급증 (특정 스텝) | 기상 반응(전구체 조기 혼합), cold spot 응축 | 듀얼채널 확인, 히팅 자켓 온도 맵 |
| 밸브 고착/누설 | 응축물·부식 | 히팅 라인 온도, 퍼지 시퀀스 이력 |
| 압력 도달 실패 + 개도 풀 오픈 | 배기 계통 막힘, 유량 과다 | 트랩/포어라인, 실제 유량 |
| 부식성 가스 사용 챔버의 급격한 파티클 | 수분 유입 → 산 생성 | 벤트/퍼지 시퀀스 준수, 리크 체크 |
