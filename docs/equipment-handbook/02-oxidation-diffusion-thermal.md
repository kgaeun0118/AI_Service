# 02. 산화·확산·열처리 장비 — 열을 다루는 기술

> 선행 학습: [0-3 가스](00-3-gas-and-fluids.md), [0-5 온도와 척](00-5-thermal-and-chuck.md)
> 다루는 장비: **수직 퍼니스(배치)** · LPCVD 튜브 · **RTP(급속열처리)** · 스파이크/플래시/레이저 어닐 · ISSG · 어닐 챔버

## 1. 공정이 장비에 요구하는 것

열처리 장비가 하는 일은 4가지입니다.

| 목적 | 예 | 요구 |
|------|-----|------|
| **산화막 성장** | 게이트 산화막, 패드 산화막, 희생 산화막 | 두께 정밀도(Å 단위), 균일도, 계면 품질(트랩 밀도), 재현성 |
| **불순물 활성화·확산** | 임플란트 후 어닐, 도핑 드라이브인 | 열버짓 최소화(확산 억제) + 활성화 최대화 (**상충**) |
| **막질 개선/치밀화** | 어닐, 질화, 산화 후 처리, 응력 완화 | 하부 구조 손상 없이 |
| **박막 증착(LPCVD)** | 폴리실리콘, SiN, 산화막 | 배치 균일도, 스텝 커버리지 |

핵심 갈등:

```
   높은 온도 · 긴 시간  → 활성화율 ↑, 결함 회복 ↑, 막질 ↑
                        그러나 도펀트 확산 ↑ (프로파일 붕괴), 하부 구조 손상 ↑

   → 미세화될수록 "짧고 뜨겁게"로 갈 수밖에 없다 = 장비 발전의 방향
```

## 2. 변천사 — 열버짓이 만든 장비 진화

| 세대 | 장비 | 온도 × 시간 | 등장 이유 | 한계 |
|------|------|-------------|-----------|------|
| 1960 ~ 80s | **수평 퍼니스** (horizontal tube) | 800 ~ 1200 ℃ × 수십 분 ~ 수 시간 | 저비용 대량 처리 | 파티클(수평 반송 시 낙하), 균일도, 풋프린트 |
| 1990s ~ | **수직 퍼니스** (vertical) | 동일 | 파티클 유리(웨이퍼 수평 배치, 위에서 떨어지는 입자 감소), 회전 가능, 풋프린트 작음 | 여전히 긴 열버짓 |
| 1990s ~ | **RTP (램프)** | 1000 ℃ × 수 초 | 열버짓 축소. 단일 웨이퍼로 균일 제어 | 온도 측정(방사율), 슬립 라인, 처리량 |
| 2000s | **Spike RTP** | 피크 유지 거의 0 (수백 ℃/s 승강온) | 얕은 접합(USJ) 확산 억제 | 램프/파워 한계, 패턴 의존 가열 |
| 2000s ~ | **플래시 램프 / 레이저 어닐** | ms ~ µs, 표면만 | 확산 거의 없이 활성화 | 패턴 의존 흡수, 응력/균열, 균일도 |
| 2000s ~ | **ISSG / 라디칼 산화** | 감압 + in-situ 스팀 | 얇고 치밀한 산화막, 코너 산화 균일 | 설비 복잡 |
| 현재 | **저온 대체 공정** | ALD/PEALD, 플라즈마 질화(DPN), 저온 에피 | 열처리 자체를 회피 | 막질/생산성 트레이드오프 |

> **한 줄 정리**: "오래 굽는 장비 → 짧게 굽는 장비 → 굽지 않는 공정으로" 진화했습니다.

## 3. 수직 퍼니스 — 구조와 부품

### 3-1. 전체 구조

```
                    ┌──────────────┐
                    │  배기(exhaust)│  ← 스크러버로
                    └──────┬───────┘
      ┌────────────────────┴────────────────────┐
      │        단열 하우징 / 히터 케이싱          │
      │   ┌──────────────────────────────┐      │
      │   │  히터 존 1 (TOP)              │      │  ← 각 존 독립 PID 제어
      │   │ ┌──────────────────────────┐ │      │     (보통 3 ~ 7 존)
      │   │ │  석영(또는 SiC) 이너 튜브  │ │      │
      │   │ │   ┌──────────────────┐   │ │      │
      │   │ │   │  보트(quartz/SiC) │   │ │      │
      │   │ │   │  ═══ 웨이퍼 ═══   │   │ │      │  ← 25 ~ 150장, 슬롯 피치
      │   │ │   │  ═══ 웨이퍼 ═══   │   │ │      │
      │   │ │   │  ═══ 웨이퍼 ═══   │   │ │      │
      │   │ │   └──────────────────┘   │ │      │
      │   │ │   가스 인젝터(다중 노즐,   │ │      │  ← 높이별 분사(균일도 핵심)
      │   │ │   상부/중간/하부 분사)     │ │      │
      │   │ └──────────────────────────┘ │      │
      │   │  히터 존 5 (BOTTOM)           │      │
      │   └──────────────────────────────┘      │
      │        시일 플랜지 / 베이스 플레이트      │
      └────────────────┬────────────────────────┘
                       │  보트 엘리베이터 (상승·하강) + 보트 회전
                 ┌─────┴─────┐
                 │ 로딩 영역  │ ← N₂ 퍼지 박스, 웨이퍼 이재기(transfer)
                 │ FOUP 스테이지│
                 └───────────┘
```

### 3-2. 모듈·부품 사전

| 부품 | 역할 | 고장/열화 시 | 관리 포인트 |
|------|------|--------------|-------------|
| **석영 튜브(리액션 튜브)** | 공정 공간. 고순도·고온 내성 | 열사이클로 **실투(devitrification)**, 크랙 → 파티클·파손 | 사용 시간 카운트, 정기 교체/재생, 급승온 금지 |
| **이너 튜브 / 라이너** | 가스 흐름 성형, 오염 차단 | 퇴적물 축적 | 청소/교체 주기 |
| **히터 엘리먼트(존별)** | 가열 | 단선·저항 변화 → 특정 존 온도 이상 | 저항·전력 트렌드, 존별 프로파일 |
| **단열재** | 열 프로파일, 에너지 효율 | 열화 → 승온 시간 증가, 프로파일 변화 | 상태 점검 |
| **열전대 (프로파일 TC / 스파이크 TC)** | 온도 측정(존 제어 + 웨이퍼 근접) | 드리프트·단선 | 정기 캘, 이중화, 위치 고정 |
| **보트(석영/SiC)** | 웨이퍼 지지 | 슬롯 마모, 처짐, 웨이퍼 스틱 | 재질 선택(고온은 SiC), 슬롯 상태 |
| **보트 회전 기구** | 원주 방향 균일화 | 회전 정지 시 편차 | 회전 확인, 실(seal) 관리 |
| **보트 엘리베이터** | 로딩/언로딩(속도 제어) | 급속 이동 시 열충격·파티클 | 램프 업/다운 속도 레시피 |
| **가스 인젝터(다중 노즐)** | 높이별 가스 공급 | 막힘 → T/C/B 편차 | 세정/교체, 노즐 위치 |
| **시일 플랜지 / 베이스** | 진공·기밀 | 누설 | O링·수냉 관리 |
| **배기 계통(+ 트랩)** | 부산물 배출 | 막힘 | 트랩 청소, 스크러버 |
| **N₂ 퍼지 박스(로딩부)** | 로딩 중 산화·오염 방지 | 산소 유입 → 자연산화·오염 | O₂ 농도 모니터 |
| **보일러/토치(산화용)** | H₂+O₂ 연소로 수증기 생성 | 안전 이슈 | 수소 안전 인터락 |

### 3-3. 배치 퍼니스 균일도의 3차원 문제

```
   ① 축방향(T/C/B, top-center-bottom)
      원인: 존별 온도, 가스 소모(상류에서 소진 → depletion), 배기 흐름
      해법: 존 온도 오프셋(온도 램프/틸트), 다중 노즐 분사, 유량 증가

   ② 반경방향(웨이퍼 내 center-edge)
      원인: 가스가 웨이퍼 엣지부터 들어와 중앙까지 확산해야 함
      해법: 저압(LPCVD)으로 확산 속도↑, 슬롯 피치 조정, 온도 조정

   ③ 원주방향
      원인: 노즐 위치 편중
      해법: 보트 회전
```

> **LPCVD가 왜 저압인가**: 압력을 낮추면 확산계수가 커져(D ∝ 1/P) 웨이퍼 사이 좁은 틈으로 가스가 잘 들어갑니다.
> 즉 **반응 지배(reaction-limited) 영역**으로 들어가 두께가 "온도"로 결정되고 "가스 도달"에 덜 의존하게 됩니다 → 배치 균일도 확보.
> 이 개념이 배치 장비 설계의 핵심 논리입니다.

### 3-4. 열산화의 원리와 노브

```
   Deal-Grove 모델:  x² + A·x = B·(t + τ)

   초기(얇은 막): 반응 지배 → 두께 ∝ 시간 (선형)
   후기(두꺼운 막): 확산 지배 → 두께 ∝ √시간  (산화종이 산화막을 통과해야 함)
```

| 방식 | 가스 | 특징 |
|------|------|------|
| **드라이 산화 (dry O₂)** | O₂ | 느림, **막질 우수** → 게이트 산화막 |
| **웨트 산화 (wet, steam)** | H₂O(스팀) | 빠름, 막질 상대적으로 낮음 → 후막/필드 산화 |
| **파이로제닉/토치** | H₂ + O₂ 연소 → 초순수 스팀 | 청정한 스팀 생성. 수소 안전 관리 필수 |
| **ISSG (In-Situ Steam Generation)** | 감압에서 H₂+O₂를 웨이퍼 근처에서 반응 → 산소 라디칼 | **매우 얇고 치밀**, 코너/측벽 산화 균일, 결정 방위 의존 감소 |
| **HCl 첨가 산화** | O₂ + HCl | 금속 오염 게터링, 계면 개선 |
| **질화(NO, N₂O, DPN)** | 산화막에 질소 도입 | 유전율↑, 보론 침투 억제, 신뢰성 |

| 노브 | 결과 | 부작용 |
|------|------|--------|
| 온도 ↑ | 산화 속도 ↑(지수적) | 확산·열버짓 ↑, 웨이퍼 슬립 |
| 시간 ↑ | 두께 ↑(후기엔 √t) | 열버짓 ↑ |
| 압력 ↑ (고압 산화) | 저온에서 같은 두께 | 설비 복잡 |
| 웨트/드라이 | 속도 vs 막질 | — |
| 도핑 농도(기판) | 고농도에서 산화 가속 | 두께 편차(패턴 의존) |

## 4. RTP (Rapid Thermal Processing) — 급속열처리

### 4-1. 구조

```
        ┌───── 램프 어레이 (텅스텐 할로겐, 수십 ~ 수백 개) ─────┐
        │   ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ (존별 그룹 제어)      │
        ╞══════════════ 석영 윈도우 ══════════════╡
                      ░░░░░░  복사열  ░░░░░░
        ┌──────────────────────────────────────┐
        │        웨이퍼 (에지 링/서셉터 위, 회전)  │  ← 가드 링으로 엣지 열손실 보상
        └──────────────────────────────────────┘
        ╞══════════════ 석영 윈도우 ══════════════╡
        │   파이로미터 (다파장, 뒷면 온도 측정)      │  ← 리플렉티비티 보정
        │   리플렉터 플레이트(반사판)               │
        └──────────────────────────────────────┘
          가스: O₂/N₂/H₂/NH₃/Ar,  압력: 대기압 ~ 감압
```

### 4-2. 부품과 관리 포인트

| 부품 | 역할 | 문제 |
|------|------|------|
| **램프 어레이** | 복사 가열. 존별로 그룹 제어해 반경 방향 프로파일 조형 | 램프 노후 → 광량 저하·프로파일 변화. 개별 램프 단선 감시 |
| **석영 윈도우** | 램프와 공정 공간 분리 | 오염·증착물 → 광 투과 저하 → 온도 오차 |
| **에지 링 / 가드 링** | 웨이퍼 엣지 열손실 보상(엣지는 사방으로 복사 손실) | 마모·오염 → 엣지 온도 편차 |
| **서셉터/서포트 핀** | 웨이퍼 지지(접촉 최소화) | 접촉점 온도 불균일 → 슬립 라인 |
| **파이로미터(다파장 + 반사율 보정)** | 실제 웨이퍼 온도 측정 | **방사율 의존**이 최대 난점 ([0-5장](00-5-thermal-and-chuck.md)) |
| **리플렉터** | 뒷면 복사를 되돌려 방사율 영향 완화(가상 흑체) | 오염 시 보정 붕괴 |
| **회전 기구** | 원주 균일화 | — |

### 4-3. 방사율 문제와 해결

```
   문제: 파이로미터는 "복사 세기"를 재서 온도를 계산한다.
         복사 세기 = 방사율(ε) × 흑체 복사
         → 웨이퍼 뒷면 막(산화막 두께, 금속 유무)이 바뀌면 ε이 바뀜
         → 같은 온도인데 다른 값으로 읽힘 → 공정 결과 편차

   해결책:
    ① 리플렉터 플레이트로 웨이퍼-반사판 사이를 가상 흑체 공간화 (ε 영향 축소)
    ② 다파장 측정 + 실시간 반사율 측정으로 ε 보정
    ③ 램프 광의 파장 대역과 측정 대역 분리(필터)
    ④ 제품별 보정 테이블 운영
```

### 4-4. 슬립(slip) — RTP 고유의 파손 모드

급속 승온 시 웨이퍼 내 온도차 → 열응력 → 결정면을 따라 미끄러짐(슬립 라인). 심하면 파손.

| 대책 | 내용 |
|------|------|
| 승온율 제한 | 고온 구간에서 램프율 낮춤 |
| 엣지 링/가드 링 | 엣지 온도 손실 보상 |
| 회전 | 원주 균일화 |
| 서포트 설계 | 접촉점 최소·대칭 |
| 패턴 의존 흡수 고려 | 패턴(금속/폴리) 밀도 차로 국부 과열 → 레이아웃 의존 이슈 |

## 5. 밀리세컨드 어닐 — 플래시와 레이저

| 방식 | 시간 | 원리 | 특징/문제 |
|------|------|------|-----------|
| **플래시 램프 어닐 (FLA)** | ms | 제논 플래시 램프로 표면만 순간 가열 (벌크는 예열 상태) | 확산 거의 없음. 열응력에 의한 웨이퍼 파손·슬립 위험, 패턴 의존 |
| **레이저 스파이크 어닐 (LSA)** | µs ~ ms | 레이저 빔을 스캔 | 국부·고정밀. **패턴 의존 흡수(pattern effect)**, 스캔 이음부(stitching) 관리 |
| **DSA (Dynamic Surface Anneal)** | ms | 레이저 라인 빔 스캔 | 고활성화, 낮은 확산 |
| **마이크로파 어닐** | s | 마이크로파 흡수 | 저온 활성화 시도 |

```
   [열버짓 비교 개념도]

   온도
    │      ┌──┐           ← 레이저/플래시: 극히 짧은 피크, 표면만
    │     ╱    ╲
    │    ╱ ┌────┐ ╲        ← Spike RTP: 초 단위
    │   ╱ ╱      ╲ ╲
    │  ╱ ╱  ┌──────────┐   ← Furnace: 분~시간
    │ ╱_╱___│__________│__
    └────────────────────── 시간
     확산량(Dt): 레이저 ≪ Spike ≪ RTP ≪ Furnace
```

> **왜 이렇게까지 하는가**: 미세 트랜지스터의 소스/드레인 접합 깊이는 수 nm입니다.
> 도펀트를 활성화(격자 자리로 넣기)하려면 고온이 필요한데, 고온이면 확산해서 접합이 깊어집니다.
> 이 모순을 "시간을 극단적으로 줄여" 푸는 것이 밀리세컨드 어닐입니다.

## 6. 장비 노브 ↔ 공정 결과 종합표

| 장비 | 노브 | 물리 | 결과 | 부작용 |
|------|------|------|------|--------|
| 퍼니스 | 존 온도 오프셋 | 축방향 온도 프로파일 | T/C/B 두께 균일도 | 과보정 시 반대 편차 |
| 퍼니스 | 가스 유량/노즐 배분 | 반응종 공급 | 축방향 균일도 | 파티클, 소모량 |
| 퍼니스 | 압력(LPCVD) | 확산/반응 지배 전환 | 웨이퍼 내 균일도, 스텝 커버리지 | 속도 저하 |
| 퍼니스 | 보트 슬롯 피치 | 웨이퍼 간 공간 | 균일도, 배치 수량(처리량) | 처리량 trade-off |
| 퍼니스 | 승/강온 램프율 | 열충격 | 파티클, 슬립, 사이클 타임 | 튜브 수명 |
| RTP | 램프 존 파워비 | 반경 온도 프로파일 | 웨이퍼 내 균일도 | 엣지 슬립 |
| RTP | 승온율 | 열응력 | 열버짓 vs 파손 | 슬립 |
| RTP | 분위기(O₂/N₂/NH₃/H₂) | 표면 화학 | 산화/질화/환원 | 원치 않는 산화 |
| 어닐 | 피크 온도/시간 | 활성화 vs 확산 | 시트 저항, 접합 깊이 | 상충 관계 |
| 레이저 | 에너지 밀도·스캔 속도 | 표면 용융/고상 | 활성화율 | 패턴 의존, 균열 |

## 7. 트러블슈팅

| 증상 | 의심 | 확인 |
|------|------|------|
| 배치 T/C/B 두께 편차 | 존 온도, 가스 depletion, 노즐 막힘, 배기 | 존 오프셋 이력, 노즐 점검, 유량 증가 테스트 |
| 웨이퍼 내 센터-엣지 편차 | 압력, 슬롯 피치, 온도 | 압력 스윕, 피치 변경, 존 조정 |
| 파티클 급증 | 석영 튜브 실투/크랙, 보트 마모, 퇴적물 박리 | 튜브 사용시간, 육안 검사, 클린/교체 |
| 산화막 두께 드리프트(장기) | 열전대 드리프트, 히터 열화, 튜브 상태 | TC 캘, 히터 저항, 튜브 교체 이력 |
| 웨이퍼 슬립/파손(RTP) | 승온율, 엣지 링, 서포트 | 램프율 하향, 링 상태, 회전 |
| RTP 웨이퍼 간 편차 | 파이로미터 방사율(뒷면 막 변경), 윈도우 오염 | 제품 이력, 윈도우 청소, 보정 테이블 |
| 시트 저항 스펙 이탈 | 어닐 온도/시간, 임플란트 도즈 | 어닐 프로파일 검증(thermal wafer), 임플란트 이력 |
| 게이트 산화막 신뢰성 불량 | 계면 오염, 로딩 중 산화, 금속 오염 | 로딩부 O₂ 농도, 세정 이력(Q-time), 튜브 청정도 |
| 접합 깊이 과다 | 열버짓 과다 | 스파이크/레이저 조건 재검토 |

> **Q-time(대기 시간) 개념**: 세정 후 산화까지 시간이 길면 자연산화막·오염이 생겨 게이트 품질이 나빠집니다.
> 그래서 팹은 공정 간 최대 대기 시간을 규정합니다. 장비 다운이 곧 품질 리스크가 되는 이유입니다.

## 8. 최근 동향

| 동향 | 내용 |
|------|------|
| **열버짓 최소화 지속** | 레이저/플래시 어닐 적용 확대, 저온 공정화 |
| **선택적 어닐** | 특정 층/영역만 가열(레이저) → 3D 적층에서 하부 소자 보호 |
| **3D 적층 호환 열처리** | 하부에 이미 배선이 있으면 400 ℃ 이하로 제한 → **저온 공정이 필수 요건**(모놀리식 3D, 하이브리드 본딩) |
| **라디칼 산화/질화 확대** | ISSG, 원격 플라즈마 질화로 초박막 품질 확보 |
| **배치 장비의 생존 전략** | 고생산성이 필요한 층(패드/하드마스크/폴리)은 여전히 배치. ALD 배치화로 경쟁 |
| **하이브리드 본딩용 어닐** | Cu 팽창 접합을 위한 250 ~ 350 ℃ 정밀 어닐 ([11장](11-packaging.md)) |
