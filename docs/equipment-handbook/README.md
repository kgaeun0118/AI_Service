# 반도체 장비 총서 (Semiconductor Equipment Handbook)

> **"공정을 배웠는데 장비는 모른다"** 는 사람을 위한 기본서.
> 8대 공정 + 후공정(패키징/테스트) 장비를 **구조 → 부품 → 원리 → 공정 영향 → 발전사 → 실무 관리** 순서로 파고듭니다.

---

## 0. 이 총서는 무엇인가

대부분의 반도체 입문서는 **공정(process)** 을 설명합니다. "산화막을 성장시킨다", "포토레지스트를 노광한다" 같은 식입니다.
그런데 현장에서 엔지니어가 실제로 마주하는 대상은 공정이 아니라 **장비(equipment)** 입니다.

- 산화막 두께가 1 % 틀어졌을 때 만지는 것은 "산화 공정"이 아니라 **퍼니스의 3번 존 히터 세팅과 보트 회전 속도** 입니다.
- 패턴 CD가 흔들릴 때 보는 것은 **포커스 링 두께, 챔버 wall 온도, RF 매처 포지션** 입니다.
- 수율이 떨어질 때 원인은 대개 레시피가 아니라 **소모성 부품의 수명, 진공 누설, 파티클, 반송 아암의 미세 미스얼라인** 입니다.

이 총서는 **"장비를 하나도 모르는 사람"** 을 기준으로 씁니다. 그래서 다음을 지킵니다.

| 원칙 | 실제 서술 방식 |
|------|----------------|
| **부품 단위까지 내려간다** | 각 장에 "모듈·부품 사전" 표를 두고, 부품 / 위치 / 역할 / 고장 시 증상 / 관리 포인트를 모두 적습니다. |
| **왜 그렇게 생겼는지 설명한다** | "진공을 잡는다"로 끝내지 않고, 평균자유행정·오염·플라즈마 점화 조건까지 계산 수준으로 풀어씁니다. |
| **변천사를 공정 요구로 설명한다** | "g-line → i-line → KrF → ArF → ArF-i → EUV → High-NA"를 연표가 아니라 **"무엇이 막혀서 무엇으로 갔는가"** 로 서술합니다. |
| **장비 노브 ↔ 공정 결과를 연결한다** | 모든 장에 `파라미터 → 물리 → 결과 → 부작용` 4열 표가 있습니다. |
| **꼬리를 물고 들어간다** | 예: "금속마다 증기압이 다른데 어떻게 같은 장비로 다루나?" → 증발 vs 스퍼터, 합금 타겟, 전구체 전달(버블러/DLI/고체 앰플), 히팅 라인 cold spot까지 ([06장](06-metallization-pvd-ecp.md)) |

## 3. 모든 장의 공통 틀

어느 장을 열어도 같은 순서로 나옵니다. 익숙해지면 새 장비를 만나도 이 순서로 스스로 분해할 수 있습니다.

| 절 | 제목 | 답하는 질문 |
|----|------|-------------|
| 1 | 공정이 장비에 요구하는 것 | 이 장비는 애초에 **무엇을 못 해서** 만들어졌나 |
| 2 | 변천사 | 세대별로 **무엇이 한계였고 무엇으로 돌파**했나 |
| 3 | 장비 전체 구조 | 겉·속 도해. 어디서 웨이퍼가 들어와 어디로 나가나 |
| 4 | 모듈·부품 사전 | 부품 / 역할 / 고장 증상 / 관리 포인트 |
| 5 | 작동 원리 — 웨이퍼 한 장의 여정 | 시간 순서로 실제 무슨 일이 일어나나 |
| 6 | 환경(진공·가스·온도)을 왜 그렇게 잡나 | 물리적 이유 |
| 7 | 장비 노브 ↔ 공정 결과 | 무엇을 돌리면 무엇이 변하고, 무엇이 나빠지나 |
| 8 | 불량과 장비 원인 | 증상에서 부품까지 역추적 |
| 9 | 실무 — PM / Qual / 체크리스트 | 실제로 어떻게 다루나 |
| 10 | 최근 동향과 앞으로 | 지금 무엇이 바뀌는 중인가 |
| 11 | 사진·영상으로 확인하기 | 어디서 실물을 볼까 (검색어 제공) |
| 12 | 자기 점검 질문 | 이해했는지 스스로 확인 |

## 4. 장비 사진에 대한 안내 (중요)

이 총서는 **실제 제품 사진 파일을 저장소에 포함하지 않습니다.** 장비 사진은 거의 전부 장비사(ASML·AMAT·Lam·TEL·KLA 등)의 저작물이고, 무단 복제·재배포가 어렵습니다. 대신 두 가지로 대체합니다.

1. **직접 그린 단면 도해**: 각 장의 `3. 장비 전체 구조` 에 ASCII 단면도/블록도를 넣었습니다. 사진보다 오히려 **내부 부품 배치와 흐름**을 보기에 낫습니다.
   (사진은 대부분 "회색 큰 상자" 외관만 보이고, 정작 중요한 챔버 속은 안 보입니다.)
2. **공식 출처 안내**: [부록 C](appendix-C-image-sources.md) 에 장비별로 *어느 사이트에서 어떤 검색어로* 사진·컷뷰·영상을 볼 수 있는지 정리했습니다.
   장비사 뉴스룸/제품 페이지, 학회 공개자료, 위키미디어 커먼즈, 유튜브 공식 채널 등 **합법적으로 열람 가능한 경로** 만 담았습니다.

> 실무 팁: 장비 외관 사진보다 **① 챔버 단면 도해, ② 소모성 부품 실물(포커스 링, 샤워헤드, 패드, 타겟), ③ PM 작업 영상** 이 훨씬 공부가 됩니다. 부록 C도 그 우선순위로 정리했습니다.

## 5. 수치와 정확도에 대한 고지

- 이 총서의 수치(압력, 온도, 파워, 처리량 등)는 **전형적인 범위(typical range)** 입니다. 실제 값은 장비 모델·노드·회사 레시피마다 다릅니다.
- 특정 장비 모델의 스펙(예: 스캐너 처리량, NA)은 **공개된 일반적 수치를 근사로** 적었고, 공식 스펙은 반드시 벤더 데이터시트를 확인해야 합니다.
- 레시피 수준의 구체적 수치(예: 어떤 노드의 실제 식각 조건)는 각 사의 영업기밀이므로, 이 총서는 **원리와 방향성**(무엇을 올리면 무엇이 어떻게 변하는가)에 집중합니다.
- 틀린 부분이나 업데이트가 필요한 부분은 이 저장소에서 바로 수정·확장하도록 문서를 파일별로 쪼개 두었습니다.
