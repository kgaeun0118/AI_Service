# 부록 E. 90일 학습 로드맵 — 완전 초보에서 장비 대화가 되는 상태까지

> 대상: 장비를 하나도 모르는 상태에서 시작하는 사람(신입, 전공 무관 입문자, 면접 준비자).
> 목표: 90일 후 **"장비 앞에서 무엇을 봐야 하고, 무엇을 물어야 하고, 이상 징후를 어떻게 말해야 하는지"** 아는 상태.

---

## 전체 설계

```
 [1~30일] 공통 기초 — 진공·플라즈마·열·반송·부품
          → "모든 장비를 같은 틀로 분해하는 능력"
 [31~60일] 공정별 장비 — 리소/식각/증착/금속/임플/CMP/세정/계측
          → "각 장비가 무엇을 못해서 그렇게 생겼는지 설명하는 능력"
 [61~90일] 실무 감각 — 트러블슈팅·PM·데이터·패키징·최신 동향
          → "증상에서 부품을 역추적하고 보고하는 능력"
```

**하루 학습량 기준**: 평일 1 ~ 1.5시간 × 5일 + 주말 정리 1시간 (무리한 계획은 실패합니다)

2. 베이스 압력이 안 떨어질 때 누설과 아웃개싱을 어떻게 구분하나?
3. 라디칼과 이온의 역할 차이가 프로파일에 어떻게 나타나나?
4. He 백사이드가 필요한 이유는?
5. 매처 포지션이 왜 진단 데이터인가?
6. Seasoning은 무엇을 복원하는 것인가?

## 훈련법 — 효과 순서대로

| 순위 | 방법 | 이유 |
|------|------|------|
| **1** | **백지에 챔버 단면 그리기** (보지 않고) | 부품 배치와 흐름이 머리에 남는 유일한 방법 |
| **2** | **노브-결과-부작용 표를 직접 채우기** | 현장 대화의 문법. 암기가 아니라 관계 이해 |
| **3** | **증상 → 의심 부품 플래시카드** | 실무에서 바로 쓰임 |
| **4** | **특허 도면 해독** | 무료·정확·무한 공급 |
| **5** | 남에게 설명하기 (또는 글로 쓰기) | 이해의 구멍이 즉시 드러남 |
| 6 | 영상 시청 | 감각 형성에는 좋지만 수동적 |
| 7 | 단순 반복 읽기 | 효율 가장 낮음 |

## 현장 배치 첫 주에 해야 할 일 (실전 팁)

| 항목 | 내용 |
|------|------|
| **담당 장비의 5대 구성 파악** | 어디가 EFEM/로드락/챔버/소스/제어부인지 손으로 짚기 |
| **소모품 목록과 PM 주기 확보** | 이 장비의 소모품 10개와 카운터 기준을 적어두기 |
| **알람 이력 1개월치 훑기** | 어떤 알람이 자주 나는지 = 이 장비의 약점 |
| **일상 모니터링 항목 확인** | 어떤 지표를 매일 보는지, 정상 범위는 얼마인지 |
| **PM 입회 요청** | 실물 부품을 보는 가장 빠른 길. 마모 흔적을 눈에 담기 |
| **안전 교육·LOTO 절차 숙지** | 예외 없음 |
| **질문 노트 만들기** | "왜?"를 적고, 답을 얻으면 옆에 기록. 3개월 뒤 자산이 됨 |
| **용어 즉시 물어보기** | 모르는 약어를 넘기면 3개월간 계속 모른다 |

## 마지막 조언

```
   장비를 아는 사람의 특징은 "많이 외운 사람"이 아니라
   **"처음 보는 장비를 스스로 분해해 볼 수 있는 사람"** 입니다.

   그래서 이 총서는 모든 장을 같은 12절 틀로 썼습니다.
   새 장비를 만나면 그 틀로 질문하세요:

     ① 이 장비는 무엇을 못 해서 만들어졌나?
     ② 세대별로 무엇이 한계였고 무엇으로 돌파했나?
     ③ 웨이퍼는 어디로 들어와 어디로 나가나?
     ④ 소모되는 부품은 무엇이고, 닳으면 무엇이 변하나?
     ⑤ 어떤 노브가 있고, 각각 무엇을 같이 나빠지게 하나?
     ⑥ 이 장비의 대표 불량은 무엇이고 어느 부품에서 오나?

   이 6개를 스스로 물을 수 있으면, 이미 장비를 아는 사람입니다.
```
