# 부록 B. 장비 벤더 지도 — 누가 무엇에 강하고, 왜 강한가

> 목적: 장비 이름을 들었을 때 "어느 공정, 어느 회사" 정도가 바로 떠오르게 하는 것.
> 주의: 시장 점유율·순위는 해마다 바뀌고 자료마다 다릅니다. 이 문서는 **"어떤 영역에서 이름이 알려져 있는가"** 수준으로만 적고, 구체적 수치는 싣지 않습니다. 최신 현황은 각 사 IR 자료·업계 리포트로 확인하세요.

## B-2. "왜 그 회사가 강한가" — 구조적 이유

| 벤더 유형 | 강함의 원천 |
|-----------|-------------|
| **ASML (EUV)** | 광원(Cymer 인수), 광학(Zeiss와의 독점적 협력), 스테이지·제어, 수십 년 축적된 결상 노하우. 어느 하나만 있어도 안 되는 **복합 시스템 통합력**이 진입장벽 |
| **Applied Materials** | 폭넓은 포트폴리오(증착·식각·PVD·CMP·임플란트·RTP·계측)와 클러스터 플랫폼(Endura/Producer 등)의 표준화. "여러 공정을 한 플랫폼에" |
| **Lam Research** | 식각(특히 HAR·컨덕터)과 증착·도금의 조합. 3D NAND·DRAM 공정 스케일링과 함께 성장 |
| **Tokyo Electron** | 트랙(코터/디벨로퍼) 사실상 표준 + 식각·증착·세정·프로버까지 넓은 커버 |
| **ASM International** | ALD 선도. 초박막·고유전막·스페이서 시대에 수요 급증 |
| **KLA** | 검사·계측 데이터가 곧 수율 엔지니어링. 알고리즘·감도·레퍼런스 데이터베이스의 누적 효과 |
| **DISCO** | 블레이드·그라인딩 휠 등 **소모품까지 수직 통합**. 절단·연삭의 노하우가 소모재에 담김 |
| **Ebara** | 진공펌프(드라이 펌프)와 CMP를 동시에. 유체·회전기계 기반 기술 |
| **Advantest / Teradyne** | 테스터는 하드웨어 + 테스트 프로그램 생태계. 전환 비용이 매우 큼 |
| **EVG / SUSS** | 웨이퍼 본딩·정렬의 정밀 기계·광학. 하이브리드 본딩 시대에 재조명 |

> **패턴**: 강한 벤더의 공통점은 ① **소모품/서비스까지 수직 통합**(장비 판매 후에도 수익과 데이터 확보),
> ② **플랫폼화**(같은 메인프레임에 여러 챔버), ③ **고객 팹과의 공동 개발 이력**(레시피 노하우 축적)입니다.
> 반도체 장비 산업의 진입장벽은 기계 그 자체가 아니라 **"양산에서 검증된 이력"** 입니다.

> "어느 부품이 어느 회사 것이고, 리드타임이 얼마이며, 재생 품질이 어떤가"를 아는 것이 현장 역량입니다.

## B-4. 장비 이름 읽는 법 (플랫폼/모델 네이밍 감각)

장비명은 보통 `[플랫폼] + [챔버/응용]` 형태입니다. 예시 형태만 이해하면 충분합니다.

| 요소 | 의미 | 예 |
|------|------|-----|
| **플랫폼(메인프레임)** | 반송·로드락·제어부 공통 골격 | 진공 클러스터 플랫폼, 대기 플랫폼 |
| **챔버/모듈명** | 실제 공정 수행부 | 식각 챔버, ALD 챔버, PVD 챔버 |
| **세대 표기** | 개선 버전 | "II", "XT", "Gen5" 류 |
| **응용 표기** | 대상 공정 | Oxide Etch, Metal ALD, Cu Plating 등 |

> 즉 "같은 플랫폼 + 다른 챔버" 구성이 흔합니다. 그래서 **플랫폼을 알면 반송·로드락·제어는 공통**이고, 챔버만 새로 배우면 됩니다.
> 이것이 [0-1장](00-1-equipment-literacy.md)에서 "장비는 5개 덩어리"라고 한 것의 실용적 의미입니다.

## B-5. 국내(한국) 장비 생태계 개괄

| 영역 | 특징 |
|------|------|
| **종합** | 세메스(삼성 계열, 세정·식각·트랙·패키징 등), 원익IPS(증착), 주성엔지니어링(증착/ALD), KCTech(CMP·세정), 한미반도체·한화세미텍(패키징 본더), 제우스, 테스, 유진테크(증착), AP시스템(레이저) 등 |
| **강점 형성 경로** | 국내 팹과의 밀착 개발 → 특정 공정·특정 층에서 국산화 → 점진적 확대 |
| **부품·소모품** | 코미코, 원익QnC, 하나머티리얼즈, 티씨케이(SiC 부품) 등 — 세라믹·석영·SiC·코팅 영역에서 글로벌 공급 |
| **현실적 구도** | 최첨단 리소·계측은 해외 의존, 증착·식각·세정·CMP·패키징 일부에서 국산 비중 확대 중 |

## B-6. 장비 선정(구매) 시 실제로 보는 항목

장비 엔지니어·공정 엔지니어가 신규 장비를 평가할 때 보는 체크리스트입니다.

| 항목 | 질문 |
|------|------|
| **공정 성능** | 목표 스펙(두께/CD/균일도/선택비)을 재현 가능하게 만족하나? 마진은? |
| **재현성/매칭** | 챔버 간·장비 간 편차가 관리 가능한가? |
| **처리량(WPH)** | 실제 레시피 기준(공표 스펙이 아니라) 처리량은? |
| **가동률** | MTBF/MTTR, PM 주기와 PM 소요 시간 |
| **CoO** | 소모품 비용, 케미컬/가스 사용량, 전력, 부품 국산화·재생 가능성 |
| **확장성** | 차세대 노드·다른 응용으로 전환 가능한가? |
| **데이터/제어** | 트레이스 데이터 제공 범위(FDC/VM 가능성), 인터페이스 표준 준수 |
| **안전/규제** | SEMI S2/S8, 배기·저감 대응, PFC 저감 |
| **서비스** | 현지 엔지니어, 부품 재고·리드타임, 원격 진단 |
| **레퍼런스** | 다른 팹의 양산 실적 — 실무에서 가장 무겁게 보는 항목 |
