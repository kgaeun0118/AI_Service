# 0-1. 장비를 보는 눈 — 처음 보는 장비도 읽어내는 법

> 선행 학습: 없음. **이 총서의 첫 문서입니다.**
> 목표: 팹에 들어가 낯선 장비 앞에 섰을 때, 어디를 보고 무엇을 물어야 할지 아는 상태가 되는 것.

---

## 1. 반도체 장비는 결국 5개 덩어리다

장비사와 공정이 달라도, 전공정 장비의 90 %는 아래 5개 덩어리의 조합입니다.
이 5개를 머릿속에 고정시키면, "이 장비는 어디가 다르지?"만 물으면 됩니다.

```
                     ┌───────────────────────────────────────────────┐
                     │            ⑤ 제어부 / 유틸리티                 │
                     │  PLC·EC(Equipment Controller)·HMI·SECS/GEM     │
                     │  전원반, PCW(냉각수), CDA, N2, 배기, 스크러버   │
                     └───────────────────────────────────────────────┘
                                        ▲ (모든 덩어리에 연결)
   ① 웨이퍼 반입부(EFEM)      ② 진공 반송부            ③ 프로세스 챔버
  ┌──────────────────┐   ┌─────────────────────┐   ┌──────────────────┐
  │ FOUP 로드포트 ×2~4│   │  로드락(2)           │   │ 챔버 A  챔버 B   │
  │ 대기 로봇         │──▶│  트랜스퍼 챔버       │──▶│ 챔버 C  챔버 D   │
  │ 얼라이너          │   │  진공 로봇           │   │ (동일 or 이종)   │
  │ FFU/청정도        │   │  슬릿 밸브           │   └──────────────────┘
  └──────────────────┘   └─────────────────────┘             ▲
                                                             │
                     ┌───────────────────────────────────────┴───────┐
                     │            ④ 소스부 (에너지·물질 공급)          │
                     │  가스박스/MFC, RF 제너레이터·매처, 히터/칠러,   │
                     │  광원·전자원·이온원, 진공펌프                   │
                     └───────────────────────────────────────────────┘
```

| 덩어리 | 하는 일 | 대표 구성품 | 여기가 고장나면 |
|--------|---------|-------------|-----------------|
| **① EFEM** (Equipment Front End Module) | 대기 중에서 FOUP을 열고 웨이퍼를 꺼내 정렬 | 로드포트, 대기(ATM) 로봇, 얼라이너, FFU, 이오나이저 | 웨이퍼 미스픽/파손, 파티클 급증, 장비 전체 정지 |
| **② 진공 반송부** | 대기 → 진공으로 웨이퍼를 넘김 | 로드락, 트랜스퍼(TM) 챔버, 진공 로봇, 슬릿 밸브 | 처리량(WPH) 저하, 진공도 불량, 파티클 |
| **③ 프로세스 챔버** | 실제 공정(식각·증착·노광 등) | 챔버 바디, 척, 샤워헤드/타겟/스테이지, 소모성 부품 | 공정 스펙 아웃, 챔버 간 편차(matching) |
| **④ 소스부** | 물질과 에너지를 정량 공급 | 가스박스·MFC, RF·DC 전원, 히터, 펌프, 광원 | 두께/CD 드리프트, 재현성 붕괴 |
| **⑤ 제어/유틸리티** | 시퀀스·인터락·데이터·수도전기 | EC, PLC, HMI, SECS/GEM, PCW, CDA, 배기, 스크러버 | 알람/다운, 데이터 유실, 안전사고 |

> **첫 질문 5개**: 낯선 장비를 만나면 이 순서로 물어보면 대화가 됩니다.
> ① 싱글 웨이퍼야 배치야? ② 진공이야 대기야? 몇 Torr까지? ③ 플라즈마 쓰나? 어떤 소스? ④ 웨이퍼 온도는 뭘로 잡나? ⑤ 소모성 부품 PM 주기가 며칠이야?

## 2. 싱글 웨이퍼 vs 배치 — 장비 형태를 가르는 첫 갈림길

장비 외형이 왜 그렇게 다른지 절반은 이것으로 설명됩니다.

| 구분 | 싱글 웨이퍼 (single wafer) | 배치 (batch) |
|------|---------------------------|--------------|
| 한 번에 | 1장 | 25 ~ 150장 |
| 대표 장비 | 식각, PECVD/ALD, PVD, 스캐너, CMP, 싱글 세정 | 수직 퍼니스, LPCVD 튜브, 웻 벤치, 일부 배치 ALD |
| 장점 | 장당 균일도·재현성 관리 쉬움, 레시피 유연, 트러블 시 손실 1장 | 압도적인 원가/처리량, 열 안정성 |
| 단점 | 처리량 확보를 위해 **챔버를 여러 개 붙임**(클러스터) | 배치 내 위치 편차(top/center/bottom), 사고 시 100장 전량 손실 |
| 형태적 귀결 | **클러스터 툴**: 육각/사각 트랜스퍼 챔버 주변에 챔버 4~6개 꽃잎처럼 배치 | **타워형**: 세로로 긴 퍼니스 + 보트 엘리베이터 |

```
 [싱글 웨이퍼 클러스터]                    [배치 수직 퍼니스]
                                              ┌─────┐
        ┌────┐  ┌────┐                        │ 배기 │
        │Ch A│  │Ch B│                        └──┬──┘
        └──┬─┘  └─┬──┘                     ┌─────┴─────┐
           │      │                        │  히터 존 1 │  ← 존별 독립 제어
     ┌─────┴──────┴─────┐                  │  히터 존 2 │
     │  Transfer Chamber │                  │  히터 존 3 │  ← 석영 튜브 안에
     │   (진공 로봇)      │                  │  히터 존 4 │     보트(100+장)
     └─────┬──────┬─────┘                  │  히터 존 5 │
        ┌──┴─┐  ┌─┴──┐                     └─────┬─────┘
        │Ch C│  │Ch D│                        ┌───┴───┐
        └────┘  └────┘                        │가스 유입│
     ┌──────────────────┐                     └───────┘
     │ 로드락 L/L ×2     │                    ┌─────────┐
     ├──────────────────┤                     │ 보트     │ ← 엘리베이터로
     │ EFEM (대기 로봇)  │                     │ 엘리베이터│    아래에서 상승
     ├──┬──┬──┬──┬──────┤                     └─────────┘
     │FOUP│FOUP│FOUP│   │
     └──┴──┴──┴──┴──────┘
```

- **클러스터 툴의 진짜 이유**: 진공을 깨지 않고 여러 공정을 연속으로 하기 위해서입니다(예: PVD에서 *디개스 → 프리클린 → 배리어 → 시드* 를 한 번의 진공 안에서). 대기 노출 = 산화/수분 흡착 = 컨택 저항 상승이기 때문입니다. 자세히는 [06장](06-metallization-pvd-ecp.md).
- **배치의 진짜 이유**: 열을 안정시키는 데 시간이 오래 걸리는 공정(고온 산화/LPCVD)은 한 장씩 하면 경제성이 없습니다. 반면 열 버짓이 작아야 하는 미세 공정은 RTP/싱글로 갈 수밖에 없습니다([02장](02-oxidation-diffusion-thermal.md)).

## 3. 장비 사진을 볼 때 실제로 보이는 것 / 안 보이는 것

입문자가 장비 사진을 봐도 배우는 게 적은 이유가 있습니다.

| 사진에 보이는 것 | 실제로 중요한데 사진에 안 보이는 것 |
|-------------------|-------------------------------------|
| 회색/흰색 커버(패널), 시그널 타워, 터치 HMI | 커버 안의 챔버 배치, 배관 경로 |
| FOUP 로드포트와 FOUP 3~4개 | 챔버 내부 소모성 부품(링, 샤워헤드, 라이너) |
| 장비 상부 FFU, 하부 펌프룸 덕트 | 진공 계통(어떤 펌프가 어디에, 어떤 순서로) |
| 장비 뒤편 전원반, 가스박스 문 | MFC 채널 구성, RF 케이블 경로/길이 |

그래서 이 총서는 **사진 대신 단면 도해**를 씁니다. 실물 사진은 [부록 C](appendix-C-image-sources.md)의 공식 경로로 보되, 볼 때 다음을 찾으세요.

1. **웨이퍼 흐름선**: FOUP → 얼라이너 → 로드락 → TM → 챔버. 이걸 손가락으로 따라갈 수 있으면 절반 이해입니다.
2. **커버 열린 사진(cutaway)** 을 우선 찾기: 벤더 전시 부스 사진, IEEE/SPIE 발표자료, 특허 도면이 좋은 소스입니다.
3. **소모성 부품 사진**: 검색어에 `focus ring`, `showerhead`, `edge ring`, `CMP pad`, `sputter target` 처럼 **부품명** 을 넣으면 실물이 나옵니다.
4. **특허 도면**: 구글 특허에서 장비사 이름 + 모듈명으로 검색하면 **정확한 내부 구조 도면**을 합법적으로 볼 수 있습니다. 실무자들이 실제로 쓰는 방법입니다.

## 4. 장비 좌표계와 위치 표현 — 현장 언어

현장 대화는 위치 표현으로 굴러갑니다. 미리 익히면 유리합니다.

| 용어 | 의미 |
|------|------|
| **12시 / 3시 / 6시 / 9시 방향** | 웨이퍼 노치(notch) 기준 원주 위치. "6시 쪽 CD가 작다" = 웨이퍼 특정 방향 편차 |
| **center / mid / edge / far-edge(bevel)** | 반경 방향 구역. 균일도 문제는 거의 이 언어로 표현됨 |
| **top / center / bottom (T/C/B)** | 배치 퍼니스의 보트 내 위치 |
| **upstream / downstream** | 가스 흐름 기준 상류/하류. "다운스트림 플라즈마" = 웨이퍼가 플라즈마 생성부 하류에 있음 |
| **frontside / backside / bevel** | 웨이퍼 앞면/뒷면/경사면. backside 파티클과 bevel 결함은 전혀 다른 문제 |
| **chamber A/B/C/D, PM1~PM6** | 클러스터의 프로세스 모듈 번호. "PM3만 CD가 높다" = 챔버 매칭 문제 |
| **툴 / 챔버 / 슬롯 / 로트 / 캐리어** | 장비 / 모듈 / FOUP 내 위치 / 웨이퍼 묶음 / FOUP 자체 |

## 5. 공정 장비에 공통으로 걸리는 6가지 요구

모든 장비는 결국 아래 6개를 동시에 만족시키라는 요구를 받습니다. **장비의 모든 부품은 이 중 하나를 위해 존재합니다.**

| 요구 | 구체적 의미 | 이걸 담당하는 부품 예 |
|------|-------------|----------------------|
| **1. 균일도 (uniformity)** | 웨이퍼 내(WIW), 웨이퍼 간(WTW), 로트 간, 챔버 간 | 샤워헤드 홀 배치, 히터 존, 마그넷 회전, 가스 링, 멀티존 척 |
| **2. 재현성 (repeatability)** | 어제와 오늘이 같아야 함 | seasoning, 소모품 수명 관리, MFC 캘리브레이션, APC |
| **3. 청정도 (cleanliness)** | 파티클/금속오염/유기물 | FFU, 라이너, 코팅, 퍼지, 실드, 반송 경로 설계 |
| **4. 처리량 (throughput)** | WPH. 원가를 지배 | 챔버 수, 로드락 펌핑 속도, 로봇 궤적, 병렬 처리 |
| **5. 제어성 (controllability)** | 노브를 돌리면 예측대로 변해야 함 | 센서, 종점검출, 폐루프 제어(APC/R2R) |
| **6. 안전 (safety)** | 사람·장비·팹 보호 | 인터락, 가스 검출기, 스크러버, 배기 모니터, EMO |

> **핵심 통찰**: 장비의 발전사는 대부분 "①균일도와 ④처리량을 동시에 올리라"는 상충 요구를 기술로 푸는 역사입니다.
> 예: 싱글 웨이퍼 ALD는 균일도 최고 but 느림 → **공간 분리형(spatial) ALD, 배치 ALD, 멀티 스테이션 챔버** 등장.

## 6. 장비 상태를 나타내는 말 (현장 알람 언어)

| 상태 | 의미 | 입문자가 알아야 할 점 |
|------|------|------------------------|
| **Idle** | 대기. 레시피 수행 가능 | 진공/온도는 유지되고 있는 상태(스탠바이) |
| **Run / Processing** | 공정 중 | 이때 문 열거나 인터락 만지면 웨이퍼 폐기 |
| **Down (Unscheduled)** | 고장 정지 | 팹에서 가장 비싼 시간. MTTR 관리 대상 |
| **PM (Scheduled)** | 계획 정비 | 주기(웨이퍼 수/RF hour/일수) 도달로 진입 |
| **Qual / Requal** | PM 후 품질 확인 | 더미 웨이퍼로 두께/CD/파티클 측정 후 합격해야 양산 투입 |
| **Engineering / Hold** | 실험·보류 | 양산 로트 못 들어감 |
| **Seasoning / Conditioning** | 챔버 길들이기 | 더미 웨이퍼 or 웨이퍼 없이 플라즈마만 돌려 챔버 내벽 상태를 양산 상태로 맞춤 ([0-8장](00-8-parts-and-consumables.md)) |

## 7. 이 총서에서 반복될 4가지 사고 도구

### 도구 1. "왜 이 환경인가?" 3단 질문
`무엇을 막고 싶은가 → 그걸 막는 물리량은 무엇인가 → 그 물리량을 만드는 부품은 무엇인가`
예) 산소 오염을 막고 싶다 → 잔류 산소 분압 → 게이트 밸브 + 크라이오/터보 펌프 + 로드락 퍼지.

### 도구 2. 노브 → 물리 → 결과 → 부작용 (4열 사고)
현장에서 "파워 올리면 되죠?"가 위험한 이유. 모든 노브는 최소 2개를 동시에 바꿉니다.
예) 식각 RF 바이어스 ↑ → 이온 에너지 ↑ → 식각률 ↑ **+ 선택비 ↓ + 마스크 소모 ↑ + 챔버 부품 스퍼터링 ↑**

### 도구 3. 시간축 3층
`ms~s(펄스/시퀀스)` / `분~시간(웨이퍼/로트)` / `일~월(부품 수명/드리프트)`
문제가 어느 층에서 생겼는지 구분하면 원인 범위가 확 줄어듭니다.

### 도구 4. 공간축 3층
`웨이퍼 내(mm)` / `챔버 내(cm)` / `팹 내(m)`
CD 편차가 웨이퍼 내인지, 챔버 간인지, 툴 간인지로 원인이 완전히 달라집니다.
