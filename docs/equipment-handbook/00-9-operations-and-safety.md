# 0-9. 장비 운영 지표와 안전 — 장비 엔지니어가 실제로 하는 일

> 선행 학습: [0-8 부품과 소모품](00-8-parts-and-consumables.md)
> 요지: 장비를 "안다"는 것은 원리를 아는 것 + **가동률과 안전을 지켜내는 것**이다. 현장 평가는 후자로 이루어진다.

---

## 1. 장비 시간의 회계 — 가동률 지표 체계

팹은 장비의 모든 시간을 회계처럼 분류합니다(SEMI E10 기반).

```
 총 시간 (Total Time)
 ├─ 비가동 시간 (Non-Scheduled Time)   : 주말/휴무/미설치 등 운영 계획 외
 └─ 운영 시간 (Operations Time)
    ├─ 정지 시간 (Down Time)
    │   ├─ 계획 정지 (Scheduled Down)   : PM, 캘리브레이션, qual
    │   └─ 비계획 정지 (Unscheduled Down): 고장, 알람, 부품 파손  ← 가장 비싼 시간
    └─ 가동 시간 (Uptime)
       ├─ 대기 (Standby)               : 일감 없음, 작업자 없음
       ├─ 엔지니어링 (Engineering)      : 실험, 평가
       └─ 생산 시간 (Productive Time)   : 실제 양산 웨이퍼 처리  ← 돈 버는 시간
```

| 지표 | 정의 | 실무 의미 |
|------|------|-----------|
| **Availability (가동 가능률)** | Uptime / Operations Time | 설비 신뢰성의 대표 지표. 90 % 초반 ~ 90 % 후반을 목표 |
| **Utilization (이용률)** | Productive / Operations Time | 일감 유무까지 반영. 낮으면 병목이 아님을 의미 |
| **OEE** | Availability × Performance × Quality | 종합 설비 효율 |
| **MTBF** | 평균 고장 간격 | 얼마나 자주 고장나나 |
| **MTTR** | 평균 수리 시간 | 고장 시 얼마나 빨리 복구되나 |
| **MTBA** | 평균 알람 간격 | 알람 빈도(소소한 정지 포함) |
| **WPH (Wafers Per Hour)** | 시간당 처리 웨이퍼 | 처리량. 장비 구매 스펙의 핵심 |
| **Cost of Ownership (CoO)** | 장비 수명 전체 비용/웨이퍼 | 장비 가격보다 중요한 판단 기준 |

> **핵심 감각**: 첨단 노광기는 대당 수천억 원대입니다. 1시간 정지가 곧 막대한 손실입니다.
> 그래서 팹 조직은 **"MTTR을 줄이는 활동"**(부품 사전 준비, 표준 절차, 원격 진단, 숙련도)에 강하게 투자합니다.

### WPH 계산의 실전 감각

```
   싱글 웨이퍼 클러스터, 챔버 4개, 공정 시간 60초/장, 반송 오버헤드 10초/장이라면

   이론 처리량 ≈ 챔버 4개 병렬 → 60/4 = 15초당 1장 (챔버 기준)
   그러나 로봇이 1대라면 스왑 시간이 병목 → 반송 한계에 걸림
   → 실제 WPH는 min(챔버 병렬 능력, 반송 능력, 로드락 사이클)로 결정
```

| 병목 후보 | 개선 방법 |
|-----------|-----------|
| 챔버 공정 시간 | 레시피 최적화, 챔버 수 증가 |
| 로봇 반송 | 듀얼/트리플 아암, 궤적 최적화 |
| 로드락 배기/벤트 | 로드락 2 ~ 4개, 배기 속도 향상 |
| 얼라이너 | 인라인 센터링으로 대체 |
| WAC/클린 | 웨이퍼 간 클린 시간 최소화, 주기 조정 |
| qual/seasoning | 자동화, 시간 단축 |

## 2. 장비 엔지니어의 하루 (현실적인 업무 구성)

| 시간대 | 하는 일 |
|--------|---------|
| **교대 인수** | 전 교대 이슈, 다운 장비 현황, 진행 중 PM, 홀드 로트 확인 |
| **모니터링** | SPC/FDC 알람, 파티클 트렌드, 소모품 카운터, 챔버 매칭 상태 |
| **트러블 대응** | 알람 발생 → 1차 판단(유틸리티/반송/공정) → 조치 or 에스컬레이션 |
| **PM 수행/입회** | 절차서 기반 작업, 부품 준비, 리크 체크, qual |
| **Qual 판정** | 파티클/두께/CD 측정 결과로 양산 해제 여부 결정 |
| **개선 과제** | 파티클 저감, PM 주기 연장, WPH 향상, 부품 국산화·재생 검증 |
| **문서화** | 작업 이력, 부품 교체 기록, 이슈 리포트, 절차서 개정 |

> **경험적 사실**: 신입에게 가장 많이 요구되는 역량은 물리 지식보다 **① 절차 준수, ② 기록의 정확성, ③ 이상 징후를 말로 정확히 전달하는 능력** 입니다.
> "장비가 이상해요"가 아니라 **"3번 챔버에서 어제 14시부터 APC 개도가 62 %에서 71 %로 올랐고, 파티클은 스펙 내이나 상승 추세입니다"** 라고 말하는 사람이 신뢰를 얻습니다.

## 3. 안전 — 반도체 장비의 4대 위험

| 위험 | 구체적 형태 | 방어 체계 |
|------|-------------|-----------|
| **화학적 위험** | 독성가스(AsH₃/PH₃), 자연발화(SiH₄), 부식성(HF/Cl₂), 강산화(F₂/O₃), 케미컬(HF 액체) | 가스 검지기, 이중배관, 과잉배기, 스크러버, 인터락, 보호구(PPE), MSDS, **HF 노출 시 칼슘글루코네이트** |
| **전기적 위험** | 고전압(HV: 임플란트 수백 kV, ESC 수 kV), RF(비접촉 화상), 대전류 | LOTO(Lock-Out Tag-Out), 잔류전하 방전 절차, 인터락, 접지 |
| **기계적 위험** | 로봇 구동부, 도어, 엘리베이터, 회전체(펌프/폴리셔), 웨이퍼 파편 | 안전 커버, 라이트 커튼, EMO(비상정지), 2인 작업 |
| **물리적 위험** | 고온(퍼니스 1000 ℃, 램프), 극저온(크라이오/액화가스), 방사선(임플란트 X선, 이온화), 레이저, 소음 | 차폐, 내열 장갑, 방사선 관리구역, 레이저 인터락, 인원 피폭 관리 |

### 인터락(interlock) — 장비 안전의 뼈대

| 인터락 예 | 왜 있는가 |
|-----------|-----------|
| 챔버 도어 열려 있으면 RF/HV 인가 불가 | 감전·플라즈마 노출 방지 |
| 배기 차압 부족 시 유해가스 공급 차단 | 가스 누출 시 확산 방지 |
| 가스 검지기 경보 시 자동 차단 + 경보 | 독성/가연성 가스 |
| 냉각수 유량 부족 시 RF/히터 차단 | 부품 소손·화재 방지 |
| 압력 조건 미달 시 이온 게이지 점등 금지 | 필라멘트 보호 |
| 스크러버 이상 시 공정 진행 불가 | 미처리 배출 방지 |
| 웨이퍼 존재 센서 불일치 시 반송 정지 | 웨이퍼 파손 방지 |

> **절대 원칙**: 인터락 우회(bypass)는 **승인된 절차와 기록 하에서만** 가능하고, 작업 종료 시 반드시 원복합니다.
> 현장 사고의 상당수는 "잠깐만 우회하고 잊음"에서 옵니다.

### LOTO 절차의 핵심

```
 1. 정지 통보 · 작업 계획 승인
 2. 에너지원 식별: 전기 / RF / 가스 / 케미컬 / 압축공기 / 냉각수 / 진공 / 열
 3. 차단 (밸브·브레이커) → 잠금(Lock) → 표지(Tag)
 4. 잔류 에너지 해제: 잔압 배출, 잔류 가스 퍼지, 커패시터 방전, 냉각 대기
 5. 영점 확인 (검전, 압력계, 가스 검지)
 6. 작업 수행
 7. 역순 복구 → 기능 테스트 → 인터락 정상 확인 → 해제
```

### 특히 주의할 물질 3가지

| 물질 | 왜 특별한가 | 대응 |
|------|-------------|------|
| **HF (불산, 액체/증기)** | 통증이 지연되어 **노출을 늦게 인지**. 칼슘과 결합해 심부 조직·뼈까지 손상, 전신 독성 | 전용 PPE, 세안·세척 설비, 칼슘글루코네이트 젤 상비, 즉시 의료 대응 |
| **SiH₄ (실란)** | 공기와 접촉 시 **자연발화**. 누출 시 즉시 화염 또는 지연 폭발 | 이중 배관, 과잉 배기, 퍼지 절차 절대 준수, 무단 배관 개방 금지 |
| **AsH₃/PH₃** | 극미량으로 치명적(ppb 관리), 무색 | 상시 검지, 실린더 캐비닛 배기 인터락, 흡착 스크러버, 교체 시 전용 절차 |

## 4. 클린룸 규율 — 사람이 가장 큰 오염원

| 규칙 | 이유 |
|------|------|
| 방진복·마스크·장갑·부츠 착용, 정해진 갱의 순서 | 사람에게서 나오는 입자(피부·머리카락·섬유)가 최대 오염원 |
| 화장품·향수·특정 종이/필기구 금지 | 아민·유기물(AMC)이 포토 공정 불량 유발 |
| 빠른 동작·달리기 금지 | 난류 발생 → 파티클 비산 |
| 웨이퍼 위쪽으로 손·팔을 지나가지 않기 | 하향 기류에 실려 파티클이 웨이퍼에 낙하 |
| 지정 와이퍼/알코올만 사용 | 일반 재료는 섬유·유기물 방출 |
| FOUP 도어를 함부로 열지 않기 | 내부 청정 파괴 |

## 5. 문서와 규격 — 현장에서 실제로 참조하는 것

| 문서 | 내용 |
|------|------|
| **절차서 (SOP / Work Instruction)** | PM 절차, 부품 교체, qual 판정 기준. **모든 작업의 근거** |
| **레시피 문서 / 변경 관리(Change Control)** | 레시피 변경은 승인·기록·검증이 필수. 무단 변경은 중대 사고 |
| **장비 사양서 / Facility Requirement** | 유틸리티 조건, 설치 요건 |
| **SEMI 표준** | E10(가동률 정의), E30(GEM), E84(반송 핸드셰이크), S2/S8(안전·인간공학), F47(전압 변동 내성) 등 |
| **MSDS / SDS** | 화학물질 위험성·대응 |
| **Qual 스펙** | 파티클 상한, 두께/CD 범위, 균일도 기준 |
| **이력 기록 (equipment log)** | 부품 교체·알람·조치. 불량 추적 시 유일한 근거 |

> **Change Control의 중요성**: 팹에서 "원인 불명 수율 하락"의 상당수가 **기록되지 않은 변경**(부품 리비전, 레시피 미세 수정, 유틸리티 조건)입니다. 그래서 변경 관리가 엄격합니다.

## 6. 신규 장비 도입 흐름 (참고)

```
 스펙 검토 → 구매(발주) → Facility 준비(전기/가스/배기/PCW)
   → 입고·설치(install) → 훅업(hook-up) → 리크·기능 점검
   → 벤더 검수(acceptance test): 처리량/균일도/파티클 등
   → 공정 조건 셋업(process qualification)
   → 챔버 매칭 → 양산 인증(release) → 양산
```

| 단계 | 흔한 이슈 |
|------|-----------|
| Facility | 배기 용량 부족, PCW 온도 불안정, 전원 용량 |
| 설치/훅업 | 배관 청정도, 리크, 케이블 경로 |
| 검수 | 파티클 스펙 미달, WPH 미달(반송 병목) |
| 공정 셋업 | 기존 장비와의 결과 차(매칭), 레시피 이관 실패(MFC CF, 온도 정의 차이) |
