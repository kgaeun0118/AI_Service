# 01. 웨이퍼 제조 장비 — 모래에서 거울면까지

> 선행 학습: [0-1 장비를 보는 눈](00-1-equipment-literacy.md), [0-5 온도와 척](00-5-thermal-and-chuck.md)
> 다루는 장비: 폴리실리콘 반응기(참고) · **CZ 그로워** · 와이어 소 · 랩핑/그라인딩 · 에처 · **폴리셔(CMP의 조상)** · 에피 반응기 · 웨이퍼 검사기

## 1. 공정이 장비에 요구하는 것

웨이퍼는 단순한 "판"이 아닙니다. 그 위에 nm 수준 구조를 수백 층 쌓을 **기준면**입니다. 그래서 요구가 극단적입니다.

| 요구 | 수준(300 mm 프라임 웨이퍼, 전형) | 왜 필요한가 |
|------|-----------------------------------|-------------|
| **단결정성** | 전위(dislocation) 사실상 0, 단일 방위 | 결정 결함 하나가 소자 누설/불량 |
| **평탄도** | 사이트 평탄도(SFQR) 수십 nm 급 | 노광 초점심도(DOF)가 수십 nm뿐 → 웨이퍼가 울면 초점이 안 맞음 |
| **표면 거칠기** | Å(옹스트롬) 수준, 거울면 | 게이트 산화막 신뢰성, 결함 |
| **두께 균일도** | ±1 µm 급 | 척킹, 노광, CMP |
| **금속 오염** | 표면 금속 10¹⁰ atoms/cm² 이하 | Fe, Cu, Ni은 소수캐리어 수명을 파괴 |
| **산소·탄소 농도 제어** | Oi 를 목표 범위로 | 산소는 게터링(gettering)·강도에 유리, 과다하면 결함 |
| **엣지 형상** | 규정된 라운딩 프로파일 | 엣지 크랙 방지, 반송 안정, 엣지 결함 억제 |

## 2. 전체 흐름과 장비

```
 규사(SiO₂) ──▶ [금속급 Si 제련] ──▶ [삼염화실란 정제 + 지멘스 공정]
                                       └─▶ 폴리실리콘(11N 순도, 덩어리/막대)
                                                  │
                                                  ▼
 ┌────────────────────────── 웨이퍼 제조(웨이퍼링) ──────────────────────────┐
 │ ① 결정 성장 (CZ 그로워 / FZ)      → 잉곳(단결정 기둥)                     │
 │ ② 크로핑·그라인딩 (외경 연삭)      → 규정 직경 + 노치 가공                 │
 │ ③ 슬라이싱 (와이어 소)             → 원판(as-cut wafer)                   │
 │ ④ 랩핑 / 양면 그라인딩             → 두께 균일화, 소잉 손상층 제거          │
 │ ⑤ 엣지 프로파일링 (엣지 그라인더)   → 엣지 라운딩                          │
 │ ⑥ 에칭 (알칼리/산 웻)              → 가공 응력층 제거                      │
 │ ⑦ 양면 폴리싱(DSP) + 최종 폴리싱   → 거울면                               │
 │ ⑧ 세정 (RCA 등) + 건조                                                   │
 │ ⑨ 검사 (평탄도/결함/금속오염) + 레이저 마킹 + 포장                          │
 │ ⑩ (옵션) 에피택셜 성장 / 어닐드 웨이퍼 / SOI                              │
 └──────────────────────────────────────────────────────────────────────────┘
```

## 3. CZ 그로워 (Czochralski Puller) — 결정을 당겨 올리는 장비

### 3-1. 구조

```
                    ┌──── 시드 리프트 + 회전 기구 (케이블/샤프트) ────┐
                    │        (인상 속도 mm/min, 회전 rpm)             │
       ┌────────────┴────────────┐
       │   상부 챔버(풀 챔버)      │ ← 성장한 잉곳이 올라가는 공간
       │   뷰포트 / 직경 센서 카메라│
       ├─────────────────────────┤
       │  ░░ 시드 결정 ░░          │  ← 씨앗 단결정 (원하는 방위: (100)/(111))
       │  ▓▓▓ 넥(neck) ▓▓▓        │  ← 가늘게 뽑아 전위를 소멸시키는 구간(다시 라스 넥킹)
       │  ███ 잉곳 본체 ███        │
       │  ╲───── 멜트 표면 ─────╱  │
       │   ╲  실리콘 융액 1420℃ ╱  │  ← 석영 도가니(crucible) 안
       │    ╲__석영 도가니____╱    │
       │      흑연 서셉터          │  ← 석영을 지지 + 열 전달
       │      흑연 히터 (측면/하부) │  ← 저항 가열
       │      단열재(그래파이트 펠트)│
       │      도가니 회전·상승 기구  │  ← 액면 높이 유지(잉곳이 자라면서 액면이 내려감)
       └─────────────────────────┘
          Ar 유입(상부) → 배기(하부) : SiO 증기 제거
          자기장 코일(MCZ): 융액 대류 억제
```

### 3-2. 모듈·부품 사전

| 부품 | 역할 | 고장/열화 시 | 관리 포인트 |
|------|------|--------------|-------------|
| **석영 도가니** | 융액을 담는 용기 | 사용 중 실투·변형, Si와 반응해 **산소 공급원**(Oi 농도의 근원) | 1회성 소모품. 내면 품질이 결정 품질 지배 |
| **흑연 서셉터** | 도가니 지지·열 전달 | 산화·균열 | 수명 관리, 파티클 |
| **흑연 히터** | 융액 가열(1420 ℃ 이상) | 단선, 변형 | 전력·저항 트렌드 감시 |
| **단열재(hot zone)** | 열 프로파일 형성 | 열화 시 축방향 온도 기울기 변화 | **핫존 설계가 결정 품질의 핵심** |
| **시드 홀더 + 인상 기구** | 시드 회전·상승 | 진동 → 결정 결함 | 진동·편심 관리 |
| **직경 제어 센서(카메라/광학)** | 메니스커스(액면 곡률) 밝은 링 관찰 → 직경 피드백 | 오독 시 직경 변동 | 뷰포트 청정 |
| **Ar 유입/배기 계통** | SiO·CO 증기 배출 | 막히면 융액 오염·결정 결함 | 유량·압력 관리 |
| **자기장 코일(MCZ)** | 융액 대류 억제 | — | 산소 농도·결함 제어 노브 |
| **웨이트/케이블 시스템** | 수백 kg 잉곳 인상 | 파단 시 중대 사고 | 정기 점검 |

### 3-3. 작동 원리 — 시간 순서

```
 ① 충전(charge): 폴리실리콘 덩어리를 도가니에 넣음
 ② 용융(melt-down): 1420 ℃ 이상으로 가열, 수 시간 ~ 십수 시간
 ③ 안정화(stabilize): 융액 온도·대류 안정화
 ④ 디핑(dip): 시드를 융액에 살짝 담금
 ⑤ 넥킹(necking): 시드를 빠르게 당겨 지름 수 mm로 가늘게 → 전위가 표면으로 빠져나가 소멸
    (Dash necking — 무전위 결정을 얻는 결정적 단계)
 ⑥ 크라운(crown): 지름을 목표까지 확대
 ⑦ 바디(body): 등지름 성장. 인상 속도와 온도로 지름 유지, 도가니 회전/상승으로 액면 보상
 ⑧ 테일(tail): 지름을 서서히 줄여 열충격에 의한 전위 발생 방지
 ⑨ 냉각 후 인출
```

**성장 속도의 물리 (Voronkov 기준)**
```
   V/G  (인상속도 / 고액계면 축방향 온도기울기) 가 결함 종류를 결정

   V/G 큼  → 공공(vacancy) 과잉 → COP/보이드 결함(void, Crystal Originated Particle)
   V/G 작음 → 자기간극(interstitial) 과잉 → 전위 클러스터(A-defect)
   V/G 적정 → 무결함(Perfect Silicon / neutral zone)  ← 목표

   → 그래서 핫존(G)과 인상속도(V)의 조합이 웨이퍼 품질의 핵심 기술이 된다.
```

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| 인상 속도 ↑ | V/G ↑ | 생산성 ↑ | 보이드 결함 ↑, 직경 제어 어려움 |
| 도가니 회전 ↑ | 융액 대류·경계층 변화 | 산소 농도, 균일도 변화 | 결정 결함, 편심 |
| 자기장(MCZ) 인가 | 융액 대류 억제 | **산소 농도 낮추고 균일화**, 결함 저감 | 설비 복잡·고가 |
| Ar 유량/압력 | SiO 배출 | 탄소·산소 오염 제어 | 온도 프로파일 변화 |
| 핫존 설계 변경 | G(온도기울기) | 무결함 영역 확보 | 개조 비용, 재검증 |

### 3-4. CZ vs FZ

| 항목 | CZ (초크랄스키) | FZ (부유대역, Float Zone) |
|------|------------------|---------------------------|
| 도가니 | 사용(석영) | **없음** — 그래서 산소 오염이 극히 낮음 |
| 가열 | 저항 히터 | RF 유도 코일 |
| 직경 | 300 mm 이상 가능 | 상대적으로 작음 |
| 산소 농도 | 높음(도가니 유래) | 매우 낮음 |
| 비저항 균일도 | 보통 | 우수 |
| 용도 | **IC용 대부분** | 전력반도체(IGBT, 다이오드), 검출기 |

> **산소가 왜 양면적인가**: 산소는 **내부 게터링(BMD, 벌크 미소결함)** 을 만들어 금속 불순물을 포획하고 웨이퍼 강도를 높입니다.
> 반면 과다하면 산소 석출물이 소자 영역에 결함을 만듭니다. 그래서 **목표 범위 안으로 정밀 제어**하는 것이 기술입니다.

## 4. 슬라이싱 — 와이어 소

```
   [다중 와이어 소 (multi-wire saw)]

      와이어 릴 ─── 와이어(직경 ~100 µm 내외, 다이아몬드 고정 or 슬러리식) ─── 권취 릴
                    │││││││││││││││││││││  ← 수백 ~ 수천 가닥이 평행 주행
                 ┌──┴┴┴┴┴┴┴┴┴┴┴┴┴┴┴┴┴──┐
                 │      잉곳 (접착 고정)    │ ← 서서히 밀어 넣어 동시에 전 매수 절단
                 └───────────────────────┘
      · 다이아몬드 와이어(고정 지립) : 절단 속도 빠름, 커프 손실 적음, 현재 주류
      · 슬러리식(유리 지립 + 와이어) : 표면 손상 적으나 느림
```

| 관리 항목 | 이유 |
|-----------|------|
| **커프 로스(kerf loss)** | 절단으로 사라지는 재료. 잉곳 원가 직결 → 와이어 세경화 경쟁 |
| **와이어 장력·주행 속도** | 웨이브(파형) 발생 → 두께 편차(TTV), 와프 |
| **워프/보우(warp/bow)** | 절단 응력 → 후속 랩핑/폴리싱 부담 |
| **소잉 마크(saw mark)** | 표면 손상층. 후속 랩핑/에칭으로 제거해야 함 |
| **와이어 파단** | 잉곳 손실(고가). 장력·마모 관리 |
| **냉각/슬러리 공급** | 열 손상, 지립 분포 |

> **손상층(damage layer)의 개념**: 기계 가공은 항상 표면 아래 수 µm에 미세 크랙·전위를 남깁니다.
> 그래서 **랩핑 → 에칭 → 폴리싱**으로 단계적으로 제거합니다. 이 "손상층 제거" 개념은 뒤에 [11장 백그라인딩](11-packaging.md)에서 다시 나옵니다.

## 5. 랩핑·그라인딩·엣지 프로파일링

| 공정 | 장비 | 목적 | 원리 |
|------|------|------|------|
| **랩핑(lapping)** | 양면 랩핑기(상하 정반 + 캐리어) | 두께 균일화, 소잉 손상 제거 | 유리 지립 슬러리 + 정반 회전 |
| **양면 연삭(DDG)** | 그라인더 | 랩핑 대체(생산성·평탄도) | 다이아몬드 휠 |
| **엣지 프로파일링** | 엣지 그라인더 | 규정 엣지 형상(라운딩) + 노치 가공 | 성형 휠 |
| **에칭** | 웻 배치(알칼리 KOH/NaOH 또는 산 HF-HNO₃-CH₃COOH) | 응력층·미세크랙 제거 | 화학적 제거 |

**엣지 형상이 왜 중요한가**
- 엣지가 날카로우면 **칩핑·크랙**이 생기고, 그 크랙이 열응력에서 자라 웨이퍼가 깨집니다(1장이 깨지면 챔버 오염 → 수 주간 파티클).
- 엣지 형상은 **포토 레지스트 엣지 비드, CMP 리테이닝 링 접촉, 반송 그립**에도 영향을 줍니다.
- 그래서 엣지는 규격화된 프로파일(반경, 각도)로 가공되고, 엣지 전용 검사 장비가 따로 있습니다.

## 6. 폴리싱 — 거울면 만들기 (CMP의 원형)

```
   [DSP: Double Side Polishing]
      상부 정반 (패드)
   ═══════════════════════════
      ○ ○ ○  ← 캐리어에 웨이퍼 여러 장
   ═══════════════════════════
      하부 정반 (패드) + 슬러리(콜로이달 실리카 + 알칼리)

   화학(알칼리가 Si 표면을 연화/용해) + 기계(실리카 입자가 제거) = CMP
   → 양면 동시 → 평탄도 우수

   이후 [최종 CMP / 파이널 폴리싱]: 매우 미세한 슬러리로 거칠기 Å 수준까지
```

| 항목 | 내용 |
|------|------|
| 슬러리 | 콜로이달 실리카 + KOH/NH₄OH(알칼리) — Si를 화학적으로 연화시켜 기계적 제거를 도움 |
| 패드 | 폴리우레탄 계열, 그루브 패턴 |
| 캐리어 | 웨이퍼 보유·회전. 두께 관리가 평탄도 좌우 |
| 금속 오염 | 폴리싱 장비·슬러리가 금속 오염원이 될 수 있음 → 고순도 관리 |
| 종점 | 제거량 기반 시간 제어 + 두께 계측 |

상세한 CMP 원리·부품은 [08장 CMP](08-cmp.md)에서 다룹니다(원리는 동일합니다).

## 7. 세정과 검사, 그리고 출하

| 단계 | 장비/방법 | 확인 항목 |
|------|-----------|-----------|
| 최종 세정 | 배치/싱글 웻 세정 (SC1/SC2/DHF), 메가소닉, 스핀 건조 | 파티클, 금속, 유기물, 자연산화막 |
| 평탄도 계측 | 정전용량/광학 간섭식 웨이퍼 지오메트리 측정기 | TTV, Warp, Bow, SFQR/SBIR, 나노토폴로지 |
| 결함 검사 | 비패턴 표면 검사기(레이저 산란, SP 계열) | 파티클, COP, 스크래치, 마이크로 결함 |
| 금속 오염 | TXRF, VPD-ICPMS | 표면 금속 원소별 농도 |
| 벌크 특성 | 비저항 4점 탐침, FTIR(Oi/Cs), 소수캐리어 수명(µ-PCD) | 도핑, 산소·탄소, 라이프타임 |
| 마킹/포장 | 레이저 마커, FOSB 포장(클린룸 내) | ID 각인, 청정 유지 |

## 8. 에피택셜 웨이퍼와 특수 웨이퍼

| 종류 | 만드는 장비 | 왜 쓰나 |
|------|-------------|---------|
| **에피 웨이퍼** | 단일 웨이퍼 에피 반응기(RP-CVD, 램프 가열 + SiHCl₃/SiH₄ + H₂) | 표면 결함 없는 고품질 층, 도핑 프로파일 설계(급격한 계면), 래치업 억제 |
| **어닐드 웨이퍼 (AW)** | 고온 수소/아르곤 어닐 퍼니스 | 표면 근처 COP 소멸 → 표면 품질 개선 |
| **SOI (Silicon On Insulator)** | 본딩 + 스마트컷(수소 이온주입 + 박리) 또는 SIMOX(산소 임플란트) | 기생 용량 감소, 저전력, RF |
| **SiC / GaN 웨이퍼** | PVT(승화) 성장기, HVPE/MOCVD | 전력·RF 소자. SiC는 승화 성장이라 CZ와 전혀 다른 장비 |
| **본딩 웨이퍼 / 캐리어** | 본더, 그라인더 | 3D 적층·패키징 ([11장](11-packaging.md)) |

**에피 반응기 구조 요점**
```
   램프 가열(상·하) → 급속 승온/강온
   서셉터(SiC 코팅 그래파이트) 위 웨이퍼 1장, 회전
   가스: SiH₂Cl₂/SiHCl₃ + H₂ (+ 도판트 B₂H₆/PH₃) + HCl(in-situ 세정)
   석영 챔버(콜드월) → 벽에 증착 억제
   HCl 에칭으로 챔버/서셉터 클린 (증착물 누적 시 파티클)
```
- 고온(1000 ~ 1150 ℃) + H₂ 사용 → **수소 안전 설계 필수**
- 서셉터·석영 부품은 소모품. 증착물 축적 → 파티클/두께 드리프트
- 자세한 CVD 원리는 [05장](05-deposition-cvd-ald.md)

## 9. 변천사 — 왜 이렇게 발전했는가

| 시기 | 웨이퍼 | 장비/기술 변화 | 추동력 |
|------|--------|----------------|--------|
| 1960 ~ 70s | 25 ~ 75 mm | CZ 초기, 기계 절단·랩핑, 편면 폴리싱 | 소자 등장 |
| 1980s | 100 ~ 150 mm | 무전위 결정(Dash necking) 확립, 산소 제어 | 집적도 증가 |
| 1990s | 200 mm | 다중 와이어 소, DSP, MCZ(자기장), COP 인식 | 미세화·평탄도 요구 |
| 2000s | **300 mm** | 대구경 핫존 설계, 무결함(Perfect Si) 제어, 어닐드 웨이퍼, 정밀 나노토폴로지 | CMP·노광 DOF, 300 mm 전환 |
| 2010s ~ | 300 mm 고도화 | 초평탄·초저결함, 에피 고품질, SOI/FD-SOI | FinFET, 이미지센서, 저전력 |
| 현재 | 300 mm + 화합물 | SiC 6/8인치 전환, GaN-on-Si, 본딩/SOI 다양화 | 전기차·전력·RF, 3D 적층 |

> **450 mm는 왜 멈췄나**: 장비·팹 투자 대비 원가 이득이 불충분했고, 업계가 **미세화 + 3D + 패키징**으로 방향을 바꿨습니다([0-6장](00-6-wafer-handling.md) 참조).
