# 0-5. 온도와 웨이퍼 척 — 웨이퍼를 잡고, 식히고, 데우는 기술

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-4 플라즈마](00-4-plasma-and-rf.md)
> 요지: 반도체 공정의 거의 모든 반응은 **아레니우스 관계(지수적 온도 의존)** 를 따른다. 그래서 온도 1 ℃ 차이가 결과의 수 %를 만든다.

---

## 1. 온도가 왜 그렇게 중요한가 — 지수의 무서움

대부분의 표면 반응·확산·증착은 다음 형태를 가집니다.

```
   Rate ∝ exp( − Ea / kT )

   Ea = 0.5 eV, T = 400 ℃(673 K) 라면
     → 온도 10 ℃ 상승 시 반응률 약 1.1 ~ 1.3배 (10 ~ 30 % 변화)

   Ea = 2 eV (열산화 등) 라면
     → 10 ℃ 상승에 훨씬 큰 변화
```

정리하면:

| 요구 스펙 | 필요한 온도 균일도(대략) |
|-----------|-------------------------|
| 막 두께 균일도 1 % | 웨이퍼 내 온도 편차 **±1 ~ 3 ℃** |
| 열산화 두께 재현성 | 퍼니스 존 제어 **±0.5 ℃** 수준 |
| 임플란트 후 어닐(활성화/확산) | 열버짓(온도×시간)을 **ms 단위**로 관리 |

> 그래서 장비에는 히터, 칠러, 온도 센서, He 백사이드, 멀티존 척 등 "온도만을 위한" 하드웨어가 따로 존재합니다.

---

## 2. 진공에서 웨이퍼 온도를 잡는 것이 어려운 이유

진공에서는 **기체를 통한 열전달(대류·전도)이 거의 없습니다.** 남는 것은 두 가지뿐입니다.

| 경로 | 진공에서의 효율 | 설명 |
|------|-----------------|------|
| **복사(radiation)** | 고온에서만 유효 | 복사는 T⁴에 비례. 1000 ℃급에서는 지배적(RTP, 퍼니스), 100 ~ 300 ℃에서는 매우 약함 |
| **접촉 전도(conduction)** | 접촉 상태가 지배 | 웨이퍼와 척의 실제 접촉 면적은 표면 조도 때문에 **겉보기 면적의 극히 일부** → 그냥 올려놓으면 열이 거의 안 통한다 |

여기서 문제가 발생합니다.

```
 플라즈마 식각 중 웨이퍼로 들어오는 열 = 이온 충격 + 라디칼 재결합 + 복사
      → 수 W ~ 수십 W/cm² 수준의 열 유입
 진공이라 식힐 방법이 없음 → 웨이퍼 온도가 수십 초에 수십~수백 ℃ 상승
      → 레지스트 변형, 프로파일 변화, 재현성 붕괴
```

**해결책 = 정전척(ESC) + He 백사이드 냉각.** 이 두 개가 한 세트입니다.

---

## 3. 정전척(ESC, Electrostatic Chuck) — 진공에서 웨이퍼를 잡는 방법

### 3-1. 왜 정전척인가

| 방식 | 원리 | 한계 |
|------|------|------|
| 기계적 클램프 링 | 웨이퍼 테두리를 물리적으로 누름 | 엣지 영역 손실(dead zone), 파티클, 접촉 열전달 불균일 |
| 진공 척(vacuum chuck) | 뒷면을 진공으로 빨아 고정 | **진공 챔버 안에서는 압력차를 만들 수 없어 사용 불가** (대기 반송/포토 스테이지에서는 사용) |
| **정전척 (ESC)** | 전압으로 정전기력(쿨롱력/존슨-라벡력)을 만들어 전면 흡착 | 진공에서 유일한 실용해. 전면 균일 접촉 + He 백사이드 가능 |

### 3-2. 두 가지 타입

| 타입 | 유전체 | 원리 | 특징 |
|------|--------|------|------|
| **쿨롱형 (Coulombic)** | 고저항 유전체 (Al₂O₃ 등) | 순수 정전 유도 | 응답 빠름, 척킹력 상대적으로 작음, 온도 의존 작음, 잔류 전하 적음 |
| **존슨-라벡형 (Johnsen-Rahbek, JR)** | 약도전성 세라믹 (도핑 AlN 등) | 미세 접촉점을 통한 전류로 실효 간극 축소 → 큰 힘 | 척킹력 큼(He 압력 높게 가능), **온도에 따라 저항이 변해 특성 변동**, 디척킹(잔류 전하) 관리 필요 |

```
   [ESC 단면]

    ┌────────────────── 웨이퍼 ──────────────────┐
    │▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│
    ├── 메사(mesa)/엠보싱 돌기 ── He 가스 공간 ───┤  ← 돌기가 접촉, 사이에 He
    │  유전체층 (Al₂O₃ / AlN, 수백 µm)            │
    │  전극 (단극/쌍극) ── HV DC (수백 ~ 수천 V)   │
    │  본체 (Al) + 냉각 채널(칠러 유체) + 히터     │
    │  He 공급 홀, 리프트 핀 홀, 온도센서          │
    └──────────────────────────────────────────────┘
```

| 부품/요소 | 역할 | 문제 시 증상 |
|-----------|------|--------------|
| **유전체층** | 정전기력 발생, 절연 | 마모·크랙 → 척킹 불량, He 누설, 아킹 |
| **메사(돌기) 패턴** | 접촉 면적을 의도적으로 줄여 파티클↓ + He 공간 확보 | 마모 → 웨이퍼 뒷면 파티클, 열전달 변화 |
| **전극 (단극/쌍극)** | 정전기력. 쌍극은 플라즈마 없이도 척킹 가능 | 단극은 플라즈마가 전하 귀환 경로 → 플라즈마 꺼지면 힘 약화 |
| **He 백사이드 홀** | 열전달 기체 공급 | 막히면 국부 hot spot, 누설되면 척킹 실패 |
| **리프트 핀 (3 ~ 4개)** | 웨이퍼 로딩/언로딩 시 들어올림 | 높이 불균일 → 웨이퍼 틀어짐/파손, 파티클 |
| **냉각 채널 + 칠러** | 척 본체 온도 제어 | 유량/온도 이상 → 드리프트 |
| **히터 (멀티존)** | 척 온도 상승·프로파일 제어 | 존 단선 → 링 형태 편차 |
| **온도 센서 (RTD/열전대/광섬유)** | 폐루프 제어 | RF 노이즈 유입 시 오독 |
| **에지 링 / 포커스 링** | 웨이퍼 외곽 전기장·열 환경 정합 | 마모 → 엣지 CD/식각률 드리프트 (매우 흔한 원인) |

### 3-3. He 백사이드 냉각 — 압력 선택의 논리

```
   웨이퍼와 척 사이 간극: 수 µm (표면 조도 + 메사 높이)
   여기에 He 를 5 ~ 30 Torr 로 채운다.

   왜 이 압력인가?
   · 너무 낮으면: 간극에서 He 의 평균자유행정이 간극보다 커져(크누센 영역)
                  열전달이 압력에 비례하는 저효율 구간 → 냉각 부족
   · 너무 높으면: He 가 웨이퍼를 들어올리는 힘이 척킹력을 넘어서 웨이퍼가 떠버림
                  → 슬립, 파손, 백사이드 오염, 챔버로 He 누설
   → 척킹력(전압)과 He 압력은 반드시 짝으로 설계된다.
```

| 실무 항목 | 내용 |
|-----------|------|
| **He 누설률(leak-back) 모니터** | 웨이퍼가 제대로 척킹되면 He가 챔버로 새는 양이 적음. 누설률 상승 = 척킹 불량/유전체 마모/웨이퍼 휨(warpage) |
| **웨이퍼 휨 문제** | 응력 높은 막이 쌓인 웨이퍼는 휘어서 밀착이 안 됨 → 엣지 냉각 불량 → 엣지 CD 이상 |
| **디척킹(de-chucking)** | 전압을 끊어도 잔류 전하가 남아 웨이퍼가 붙어 있음 → 리프트 시 파손. **역극성 펄스, 플라즈마 유지 중 디척, 대기 시간** 등의 시퀀스로 해결 |
| **He 홀 근처 국부 온도** | 홀 주변은 미세하게 온도가 다름 → 극단적으로 민감한 공정에서 홀 배치가 시그니처로 나타남 |

## 4. 온도 제어 하드웨어 도감

| 하드웨어 | 방식 | 온도 범위(전형) | 쓰이는 곳 |
|----------|------|-----------------|-----------|
| **저항 히터 (내장형)** | 세라믹/금속 히터 매설 | 상온 ~ 650 ℃ | ALD/CVD 척, PECVD 서셉터 |
| **램프 히터 (할로겐/텅스텐)** | 복사 가열, 초고속 승온 | ~ 1200 ℃, 램프 200 ℃/s 이상 | RTP, 에피 ([02장](02-oxidation-diffusion-thermal.md)) |
| **저항 퍼니스 (존 히터)** | 튜브 외부 코일, 3 ~ 7 존 | 300 ~ 1200 ℃ | 수직 퍼니스, LPCVD |
| **칠러 (recirculating chiller)** | 유체 순환(갈덴/불소유체/물+글리콜) | −20 ~ 150 ℃ | 식각/PVD 척, 샤워헤드, 챔버 벽 |
| **유체 온도 조절기(TCU)** | 가열+냉각 통합 | −10 ~ 200 ℃ | 다목적 |
| **크라이오 척** | 극저온 | −60 ~ −100 ℃ 이하 | 크라이오 식각(HAR) |
| **레이저 어닐** | 국부 순간 가열 | ~1300 ℃, ns ~ µs | 저열버짓 활성화 |
| **플래시 램프** | ms 펄스 | ~1300 ℃ | 밀리세컨드 어닐 |

### 온도 측정의 함정

| 센서 | 특징 | 함정 |
|------|------|------|
| **열전대 (TC)** | 저렴·견고 | 접촉 지점의 온도만 측정. **웨이퍼가 아니라 척의 온도**를 재는 경우가 많다 |
| **RTD (Pt100 등)** | 정밀 | RF 노이즈 민감 → 필터 필요 |
| **파이로미터 (방사 온도계)** | 비접촉, RTP 필수 | **방사율(emissivity) 의존**. 웨이퍼 뒷면 막 종류가 바뀌면 같은 온도인데 다르게 읽힘 → RTP의 고전적 문제. 다파장/리플렉턴스 보정으로 대응 |
| **광섬유 온도계** | RF 노이즈 무관 | 고가, 설치 제약 |
| **웨이퍼 온도 프로브(계측용 더미)** | 실제 웨이퍼 온도 직접 측정 | 양산 중 사용 불가. **PM 후 검증용**으로 사용(thermal wafer) |

> **중요한 구분**: `척 설정 온도` ≠ `웨이퍼 실제 온도`.
> 플라즈마 ON이면 이온 충격으로 웨이퍼가 척보다 수십 ℃ 높습니다. 레시피의 "온도"는 대개 척 설정값이고, 실제 웨이퍼 온도는 파워·압력·He에 따라 달라집니다. 이 차이를 모르면 레시피 이관이 실패합니다.

## 5. 온도 균일도를 만드는 방법

| 방법 | 설명 | 적용 |
|------|------|------|
| **멀티존 히터** | 척을 중심/중간/외곽 등 2 ~ 수십 존으로 나눠 독립 제어 | 최신 식각/ALD 척은 수십 존까지 (웨이퍼 내 CD 보정 목적) |
| **가드 링 / 엣지 링 온도 제어** | 엣지의 열 손실 보상 | 엣지 3 mm 스펙 확보 |
| **척 표면 조도/메사 설계** | 접촉 열저항 균일화 | — |
| **챔버 벽/샤워헤드 온도 제어** | 벽이 차면 부산물 응축, 뜨거우면 라디칼 소모 변화 | 재현성 확보의 숨은 핵심 |
| **보트 회전 (배치)** | 회전으로 원주 방향 편차 평균화 | 퍼니스 |
| **서셉터 회전 (에피/CVD)** | 상동 | 에피, MOCVD |

> **최신 트렌드**: 웨이퍼 내 CD 균일도를 마지막 0.1 nm까지 잡기 위해 **멀티존 척(수십~100 존급)** 으로 온도 프로파일을 mm 단위로 조형하는 방향으로 갑니다. 즉 **온도가 CD 보정 노브가 되었습니다.**

## 6. 열버짓 (Thermal Budget) — 장비 선택을 지배하는 개념

```
   열버짓 ≈ Σ (온도 × 시간)의 확산 영향  (정확히는 Dt = ∫ D(T) dt)

   미세화될수록: 이미 만든 도핑 프로파일과 계면이 후속 열처리에 망가지면 안 됨
   → 같은 결과를 "더 낮은 온도" 또는 "더 짧은 시간"에 얻어야 한다
```

이 요구가 장비 발전을 직접 밀어붙였습니다.

| 세대 | 장비 | 열처리 방식 | 시간 |
|------|------|-------------|------|
| 초기 | 퍼니스 | 800 ~ 1100 ℃ 장시간 | 수십 분 ~ 시간 |
| ↓ | RTP (램프) | 1000 ℃ 수 초 | 초 |
| ↓ | Spike RTP | 급속 승강온 | 1초 미만, 피크 유지 거의 0 |
| ↓ | 플래시/레이저 어닐 | 표면만 순간 가열 | ms ~ µs |
| 현재 | 저온 공정화 | ALD/PEALD로 증착 온도 자체를 낮춤 | — |

관련: [02장 산화·확산·열처리](02-oxidation-diffusion-thermal.md), [07장 이온주입](07-ion-implantation.md)

## 7. 트러블슈팅 — 온도·척 계통

| 증상 | 의심 | 확인 순서 |
|------|------|-----------|
| 웨이퍼 엣지만 결과가 다름 | 엣지 링 마모, 웨이퍼 휨, 엣지 히터 존 | 링 두께 측정, He 누설률, 존별 파워 로그 |
| He 누설률 상승 알람 | 척 유전체 마모/크랙, 웨이퍼 휨, 백사이드 파티클 | 더미로 재현 여부, 척 표면 검사, 웨이퍼 warpage 측정 |
| 디척킹 실패(웨이퍼가 안 떨어짐) | 잔류 전하, JR형 특성 변화, 시퀀스 부적절 | 디척 시퀀스(역극성/대기시간), 척 온도, 유전체 상태 |
| 온도 설정은 같은데 결과가 다름 | 칠러 유량/온도 실제값, 센서 드리프트, 플라즈마 부하 변화 | 칠러 실측, thermal wafer 검증, 파워/압력 로그 |
| RTP 웨이퍼 간 편차 | 파이로미터 방사율(뒷면 막 종류 변경) | 뒷면 막 이력 확인, 보정 테이블, 램프 열화 |
| 퍼니스 T/C/B 두께 편차 | 존 세팅, 가스 유입/배기, 보트 위치, 튜브 상태 | 존 오프셋 튜닝, 더미 배치 구성, 튜브 실투 확인 |
| 리프트 시 웨이퍼 파손 | 핀 높이 불균일, 디척 불량 | 핀 레벨링, 디척 시퀀스 |
| 국부 hot spot (웨이퍼에 점 형태) | He 홀 막힘, 척 표면 이물 | 척 육안·He 유량, 청소 |
