# 11. 패키징(후공정) 장비 총론 — 칩을 쓸 수 있는 물건으로 만드는 기계들

> 선행 학습: [0-5 척](00-5-thermal-and-chuck.md), [06 금속배선(도금)](06-metallization-pvd-ecp.md), [08 CMP](08-cmp.md), [10 테스트](10-metrology-inspection-test.md)
> 다루는 장비: **백그라인더** · **다이서(블레이드/레이저/스텔스/플라즈마)** · 다이 본더 · **플립칩·TC 본더** · 와이어 본더 · 몰딩 프레스 · 볼 마운터 · 리플로우 · 레이저 마커 · **TSV 장비군** · 임시 본딩/디본딩 · **하이브리드 본더** · RDL/팬아웃 장비 · X-ray/AXI/SAT 검사 · 테스트 핸들러 · 번인

## 1. 후공정이 갑자기 중요해진 이유

```
   과거: 전공정이 성능을 만들고, 후공정은 "보호하고 연결하는" 저부가 공정
   현재: 미세화 속도가 둔화 → 성능 향상의 상당 부분을 **패키징이 담당**

    · HBM: DRAM을 8 ~ 16단 쌓아 대역폭을 수십 배로 → AI 가속기의 핵심
    · 칩렛(chiplet): 큰 칩을 여러 개로 쪼개 수율·비용·혼합공정 최적화
    · 2.5D/3D 적층: 인터포저·TSV·하이브리드 본딩으로 칩 간 거리를 극단적으로 단축
    · 결과: "패키징이 성능·원가·수율을 좌우한다"  → 장비 투자 급증
```

**후공정 장비가 전공정 장비와 닮아가는 현상**
- TSV는 식각(HAR) + PVD + 도금 + CMP — **전공정 장비 그대로**
- RDL은 리소(스테퍼) + 도금 + 식각 — **전공정 장비 그대로**
- 하이브리드 본딩은 CMP 평탄도 + 초청정 세정 + nm 오버레이 — **전공정보다 더 엄격한 요구**
→ 그래서 요즘은 전/후공정 경계가 흐려지고, 이를 **중공정(middle-end)** 이라 부르기도 합니다.

## 2. 전체 흐름 지도

```
 [웨이퍼 완성] ──▶ ① 웨이퍼 테스트(EDS) ──▶ ② 백그라인딩(박화) ──▶ ③ 다이싱
                                                   │
        ┌──────────────────────────────────────────┘
        ▼
 ④ 다이 어태치 ──▶ ⑤ 인터커넥트 ──▶ ⑥ 몰딩/언더필 ──▶ ⑦ 볼 마운트/리플로우
   (DAF/페이스트)     (와이어본딩 or        (EMC 보호)      (외부 단자 형성)
                     플립칩/TCB/HB)
        │
        ▼
 ⑧ 마킹 ──▶ ⑨ 싱귤레이션 ──▶ ⑩ 파이널 테스트(핸들러+ATE) ──▶ ⑪ 검사·포장 ──▶ 출하

 [고급 패키징 경로]
   TSV 형성(식각·절연·PVD·도금·CMP) → 임시 본딩 → 박화 → 백사이드 RDL/범프
   → 적층(TCB / MR-MUF / 하이브리드 본딩) → 인터포저/기판 실장(CoWoS·InFO 등)
   → 몰딩 → 검사(X-ray/SAT) → 테스트
```

## 3. 백그라인딩(웨이퍼 박화) 장비

### 왜 얇게 만드는가
| 이유 | 설명 |
|------|------|
| 패키지 두께 | 모바일·적층 패키지의 높이 제한 |
| 열 방출 | 얇을수록 열 저항 감소 |
| **TSV 노출** | TSV 구리를 뒷면으로 노출시키려면 웨이퍼를 TSV 깊이까지 갈아야 함 |
| 적층 | HBM은 다이당 수십 µm까지 박화 |

### 장비 구조

```
   [인피드 그라인더 (2 ~ 3 스핀들)]

     ① 웨이퍼 앞면에 BG 테이프(보호 테이프) 부착 ── 테이프 라미네이터
     ② 진공 척(포러스 세라믹)에 뒷면이 위로 오게 고정
     ③ 스핀들 1: 조삭(coarse, #320 급 다이아몬드 휠) — 빠르게 두께 제거
     ④ 스핀들 2: 정삭(fine, #2000 ~ #8000 급) — 손상층 최소화
     ⑤ (필요 시) 스핀들 3 또는 후공정: 응력 완화
     ⑥ 두께 인라인 측정(접촉/비접촉) → 폐루프
     ⑦ 후처리: CMP / 드라이 폴리시 / 웻 에칭 / 플라즈마(DRIE) 로 **손상층 제거**
     ⑧ 테이프 박리(디테이프) → 다이싱 테이프 마운트
```

| 부품 | 역할 | 이슈 |
|------|------|------|
| **다이아몬드 휠** | 연삭 | 마모·막힘(loading) → 발열·손상층 증가. 수명 관리 |
| **진공 척(세라믹)** | 웨이퍼 흡착 | 척 평탄도가 곧 두께 균일도(TTV). 척 표면도 정기 연삭(self-grind) |
| **두께 게이지** | 인라인 측정 | 목표 두께 정확도 |
| **BG 테이프** | 앞면 보호 | 패턴 단차가 크면 테이프 두께·점착 선택이 중요(요철에 의한 균열) |
| **쿨링 DIW** | 발열·칩 제거 | 부족 시 열 손상·스크래치 |

**핵심 개념: 손상층(damage layer)과 다이 강도**
```
   연삭은 표면 아래 수 µm에 미세 크랙을 남긴다(=[01장] 와이어 소와 같은 원리)
   얇은 다이에서 이 크랙은 치명적 → 후속 공정·사용 중 균열로 파손

   → 반드시 "스트레스 릴리프"를 한다:
      드라이 폴리시 / CMP / 웻 에칭(혼산) / 플라즈마 에칭
   → 이 공정이 다이 강도(die strength)를 수 배 향상시킨다
```

## 4. 다이싱(절단) 장비 — 4가지 방식

| 방식 | 원리 | 장점 | 단점 | 적용 |
|------|------|------|------|------|
| **블레이드 다이싱** | 다이아몬드 블레이드 회전 절단(DIW 냉각) | 저비용·범용, 두꺼운 웨이퍼 | **칩핑(chipping)**, 커프 폭 큼, 저유전막·금속층에서 박리(peeling) | 전통적 대부분 |
| **레이저 그루빙 + 블레이드** | 레이저로 스크라이브 라인의 금속/저유전막 층만 먼저 제거 → 블레이드로 Si 절단 | 저유전막 박리 방지 | 2단 공정, 열 영향 | 첨단 로직 |
| **스텔스 다이싱 (레이저 내부 개질)** | 투과 파장 레이저를 Si 내부에 집광 → 내부에 개질층 형성 → **테이프 확장(expand)으로 쪼갬** | 무분진·무수(dry), 칩핑 거의 없음, 초박형 가능 | 재료·두께 제약, 장비 투자 | 초박 다이, 이미지센서, 메모리 적층 |
| **플라즈마 다이싱 (DBP: Dice Before Grind 포함)** | 식각으로 절단 | 커프 최소, 칩핑 없음, 다이 강도 우수, 이형(비사각) 가능 | 마스크 필요, 처리량·비용, 금속층 처리 | 초소형·초박, GaAs/이형 다이 |

```
   [블레이드 다이싱 구조]

      ┌─── 스핀들(3만 rpm 급) + 다이아몬드 블레이드(두께 수십 µm) ───┐
      │            DIW 노즐(냉각·칩 제거)                          │
      └──────────────────┬──────────────────────────────────────┘
                         ▼
        ═══════ 웨이퍼 (다이싱 테이프 + 링 프레임에 마운트) ═══════
        ▒▒▒▒▒▒▒ 척 테이블 (진공, XYθ 이동) ▒▒▒▒▒▒▒
      · 얼라인 카메라: 스크라이브 라인 인식
      · 컷 깊이 제어: 테이프를 살짝만 파고드는 하프컷/풀컷
      · 블레이드 높이 세팅(setup)·마모 보정, 블레이드 파손 감지
```

| 결함 | 원인 | 대책 |
|------|------|------|
| 칩핑(엣지 깨짐) | 블레이드 마모, 이송 속도, 냉각 부족, 결정 방향 | 블레이드 교체·드레싱, 속도 조절, 2단 컷(스텝 컷) |
| 층 박리(peeling) | 저유전막·금속 다층에 기계 응력 | 레이저 그루빙 선행 |
| 버(burr)/금속 스미어 | 금속층 절단 | 레이저 그루빙, 블레이드 선택 |
| 테이프 잔류·오염 | 접착제 | 테이프 종류, UV 박리형 사용 |
| 절단 편차(사행) | 얼라인, 스핀들 진동 | 카메라 정렬, 스핀들 점검 |

## 5. 다이 어태치(다이 본딩) 장비

```
   [다이 본더 동작 사이클]

   ① 웨이퍼 테이블(다이싱 테이프 상태)에서 굿 다이 좌표를 맵에서 읽음(EDS 결과)
   ② 이젝터 핀 + 상부 픽업 헤드로 다이를 테이프에서 떼어 올림(이때 얇은 다이는 파손 위험)
   ③ (필요 시) 플립(뒤집기) 유닛
   ④ 리드프레임/기판/하부 다이 위에 접착층을 준비
        · **DAF(Die Attach Film)**: 다이 뒷면에 미리 붙은 필름 접착제 (적층에 표준)
        · 은 페이스트/에폭시 디스펜싱: 니들·제팅 디스펜서
   ⑤ 지정 위치·각도로 정밀 배치(비전 정렬), 가압·가열
   ⑥ 큐어(오븐/UV) → 접착 완성
```

| 부품 | 역할 | 이슈 |
|------|------|------|
| **픽업 헤드/콜릿** | 다이 진공 흡착 | 얇은 다이 크랙, 콜릿 오염 |
| **이젝터 핀/블록** | 테이프에서 다이 분리 | 핀 형상·수가 초박 다이 파손을 결정 → 다핀 블록·저스트로크 |
| **비전 시스템** | 위치·각도 인식 | 배치 정밀도(µm) |
| **본딩 스테이지(가열)** | 접착 큐어 | 온도 균일도, 워피지 |
| **디스펜서** | 페이스트 정량 토출 | 보이드, 흘러넘침(bleed out) |
| **DAF/테이프 취급** | 필름 접착 | 보이드, 박리 |

## 6. 인터커넥트 — 3가지 계보

### 6-1. 와이어 본딩 (여전히 물량 최대)

```
   [열압착 + 초음파 볼 본딩]

    캐필러리(세라믹 툴) 안으로 금선/구리선이 지나감
    ① EFO(전기 방전)로 선 끝을 녹여 볼(free air ball) 형성
    ② 다이 패드에 내려 압착 + **초음파 진동** + 열 → 금속간 접합(볼 본딩, 1st bond)
    ③ 정해진 궤적으로 루프를 그리며 이동
    ④ 리드/기판에 웨지 형태로 압착(스티치 본딩, 2nd bond) → 선 절단
    → 초당 수십 개 속도. 가격 대비 압도적
```

| 부품 | 역할 | 이슈 |
|------|------|------|
| **캐필러리** | 와이어 가이드 + 압착 툴 | 마모·오염 → 접합 강도 저하. 소모품 |
| **초음파 트랜스듀서** | 계면 산화막을 깨고 금속 확산 촉진 | 파워 과다 → 패드 크랙(cratering) |
| **EFO 유닛** | 볼 형성 | 볼 크기 산포 |
| **히팅 스테이지** | 180 ~ 250 ℃ | 온도 균일도 |
| **와이어** | Au / **Cu**(저가·고전도) / Ag 합금 | Cu는 산화 방지 위해 **포밍가스(N₂+H₂)** 필요, 더 단단해 패드 손상 위험 |
| 대표 불량 | 논스틱(NSOP/NSOL), 볼 리프트, 크레이터링, 와이어 스윕(몰딩 중 쓸림), 숏 | |

### 6-2. 플립칩 — 다이를 뒤집어 범프로 직접 연결

```
   [매스 리플로우 방식]
    ① 다이에 솔더 범프(또는 Cu 필러 + 솔더 캡) 형성 (웨이퍼 단계: 도금)
    ② 플럭스 도포 → 다이를 기판에 배치(플레이스먼트)
    ③ **리플로우 오븐**에 통과 → 솔더 용융·접합 (다수 동시)
    ④ 플럭스 세정 → **언더필**(캐필러리 플로우) 주입·큐어

   [TCB: Thermo-Compression Bonding]
    다이를 하나씩 집어, 본딩 헤드로 가열·가압하며 접합
    · 헤드가 수백 ℃까지 급속 승온/강온(펄스 히팅)
    · 워피지(휨)를 눌러 평탄화하면서 접합 → 미세 피치·얇은 다이에 유리
    · NCF(Non-Conductive Film)를 미리 붙여 접합과 언더필을 동시에 = **TC-NCF**
    · 느리지만 정밀 → HBM 적층의 표준적 방법 중 하나
```

| 항목 | 매스 리플로우 | TCB |
|------|---------------|-----|
| 처리량 | 높음(동시 다수) | 낮음(1개씩) |
| 정밀도 | 보통 | 높음 |
| 워피지 대응 | 어려움 | **헤드로 눌러 제어** |
| 피치 | 상대적으로 큼 | 미세 피치 가능 |
| 적용 | 일반 플립칩, 대형 다이 | HBM 적층, 미세 피치 칩렛 |

| TCB 장비 부품 | 역할 | 이슈 |
|---------------|------|------|
| **본딩 헤드(펄스 히터)** | 급속 가열·가압 | 온도 프로파일 정확도, 평행도(parallelism) |
| **본딩 스테이지** | 하부 지지·가열 | 평탄도 |
| **하중 제어** | 수 N ~ 수십 N 정밀 | 과하면 범프 붕괴, 부족하면 미접합 |
| **비전 정렬** | µm 이하 정렬 | 적층 정렬 오차 누적 |
| **NCF 취급** | 필름 라미네이션 | 보이드, 필러 트랩 |

### 6-3. 하이브리드 본딩 (Hybrid Bonding) — 범프를 없앤다

```
   개념: 솔더 범프 없이 **Cu–Cu 직접 접합 + 절연막(SiO₂/SiCN) 직접 접합**

   [공정 시퀀스]
    ① 양쪽 면에 Cu 패드 + 유전막을 만들고 **CMP로 초평탄화**
       ★ 이때 Cu 패드를 유전막보다 아주 살짝 낮게(리세스 수 nm) 만든다
    ② 세정 + **플라즈마 활성화**(표면에 결합 가능한 상태 생성)
    ③ 상온에서 유전막끼리 접촉 → 반데르발스/수소결합으로 즉시 밀착(pre-bond)
    ④ 어닐(약 200 ~ 400 ℃): Cu가 열팽창하며 서로 밀려 접촉 → Cu 원자 확산으로 금속 접합
       (Cu의 열팽창계수가 유전막보다 커서 리세스가 채워진다 — 리세스 설계의 이유)
    ⑤ 결과: 피치 수 µm 이하, 초저저항, 초박 적층 가능

   장비 요구(극단적):
    · **CMP**: 패드 리세스 nm 단위 제어, 표면 거칠기 Å 단위 ([08장](08-cmp.md))
    · **세정/활성화**: 파티클 1개가 그 다이를 죽인다 → 초청정 (전공정보다 엄격)
    · **정렬**: W2W 수십 ~ 수백 nm, D2W 도 극미세 → 전용 본더(고정밀 스테이지·비전)
    · **어닐**: 온도·시간 정밀, 보이드 방지
    · **검사**: 보이드·미접합 검출(적외/초음파/X-ray)
```

| 방식 | 내용 | 특징 |
|------|------|------|
| **W2W (Wafer to Wafer)** | 웨이퍼 통째로 접합 | 처리량 좋음. 다이 크기가 같아야 하고 **양쪽 수율의 곱**이 최종 수율 |
| **D2W (Die to Wafer)** | 굿 다이만 골라 웨이퍼에 접합 | KGD 활용 가능(수율 유리). 처리량·정렬·청정도 난이도 매우 높음 |

> **왜 하이브리드 본딩이 중요한가**: 범프가 없어져 ① 피치를 µm 이하로 줄이고 ② 접합 높이를 없애 열/전기 성능이 크게 개선됩니다.
> 대가는 **장비·청정도·CMP 정밀도**입니다. 즉 **후공정이 전공정 수준의 관리 체계를 요구하게 된 사건**입니다.

## 7. TSV (Through Silicon Via) — 전공정 장비로 만드는 후공정 구조

```
   [Via-middle 흐름 예]

   ① HAR 식각: 직경 수 µm, 깊이 수십 µm (종횡비 10:1 이상) — Bosch 공정 또는 연속 식각
        ([04장](04-etch.md) 식각 장비)
   ② 절연막 증착: PECVD/ALD SiO₂ (측벽 컨포멀)
   ③ 배리어/시드: PVD 또는 ALD TiN/Ta + Cu 시드 (고종횡비 → 이온화 PVD/ALD 필수)
   ④ Cu 도금: 보텀업 충진(첨가제 설계가 핵심) — TSV 전용 도금 화학
        ([06장](06-metallization-pvd-ecp.md) ECP)
   ⑤ 어닐 (Cu 결정 성장, "Cu pumping" 억제)
   ⑥ CMP: 오버버든 제거 ([08장](08-cmp.md))
   ⑦ 임시 본딩(캐리어에 부착) → 박화 → **TSV 백사이드 노출** → 백사이드 절연/RDL/범프
   ⑧ 디본딩(캐리어 분리)
```

| 특유 이슈 | 내용 |
|-----------|------|
| **Cu 펌핑** | 어닐/사용 중 Cu가 열팽창해 위로 솟아올라 상부 층을 밀어냄 → 사전 어닐 + CMP 순서로 관리 |
| **KOZ (Keep Out Zone)** | TSV 주변 응력이 트랜지스터 특성을 바꿈 → 소자 배치 금지 구역 |
| **보이드/심** | 도금 충진 실패 → X-ray/단면 검사 |
| **박화 후 취급** | 수십 µm 웨이퍼는 캐리어 없이 반송 불가 |

### 임시 본딩 / 디본딩 장비

| 단계 | 방법 | 이슈 |
|------|------|------|
| 임시 접착 | 접착제 스핀 코팅 + 캐리어(유리/Si) 본딩(가열·가압, 진공) | 두께 균일도(TTV), 보이드 |
| 박화·후속 공정 | 그라인딩·식각·증착·도금 | 접착제 내열·내화학성 |
| 디본딩 | **레이저**(유리 캐리어 통과, 릴리스층 분해) / 기계적 박리 / 열 슬라이드 / 용매 | 다이 파손, 잔류 접착제 |
| 잔류물 세정 | 전용 세정 | 오염 |

## 8. 몰딩 · 언더필 · 워피지

| 장비/공정 | 원리 | 포인트 |
|-----------|------|--------|
| **트랜스퍼 몰딩** | EMC 타블렛을 가열·가압해 러너를 통해 캐비티로 주입 | 와이어 스윕, 보이드, 플래시(넘침), 이형(mold release) |
| **컴프레션 몰딩** | 캐비티에 EMC(과립/액상)를 넣고 위에서 눌러 성형 | 와이어 스윕 적음, 대면적·웨이퍼 레벨에 유리 |
| **MUF (Molded Underfill)** | 몰딩과 언더필을 동시에 (칩 아래까지 EMC가 채움) | 공정 단축. 유동 설계 중요 |
| **MR-MUF (Mass Reflow + MUF)** | 다수 다이를 리플로우로 한 번에 접합 후 MUF로 충진 | HBM 적층 방식의 하나. 열전도·처리량 이점 주장, 워피지·충진 난이도 |
| **캐필러리 언더필(CUF)** | 모세관력으로 액상 언더필을 칩 아래로 침투 | 보이드, 디스펜스 패턴, 큐어 |
| **PMC (후경화)** | 오븐에서 완전 경화 | 시간·온도 |
| **워피지(휨)** | 서로 다른 열팽창계수(Si/EMC/기판)로 인해 휨 발생 | **최대 난제**. 적층·대면적일수록 심각. 재료·구조·공정 온도로 관리, 측정(shadow moiré 등) |

## 10. 팬아웃 / RDL / 인터포저 — 리소가 후공정에 들어오다

| 기술 | 내용 | 사용 장비 |
|------|------|-----------|
| **RDL (재배선층)** | 다이 위/몰드 위에 미세 배선층을 새로 형성 | **리소(i-line/KrF 스테퍼 또는 전용 노광기)**, PVD, 도금, 식각, PECVD/폴리이미드 코팅 |
| **FO-WLP / FO-PLP (팬아웃)** | 기판 없이 몰드 위에 RDL로 배선. 패널 레벨로 확장하면 원가↓ | 몰딩, 리소, 도금, 검사 |
| **2.5D 인터포저** | Si 인터포저(TSV+RDL) 위에 로직 + HBM을 나란히 실장 | TSV 장비군 + 본더 + 몰딩 |
| **브리지형(임베디드 브리지)** | 인터포저 전면 대신 국부 브리지 다이로 연결 | 본딩 정밀도 |
| **패널 레벨(PLP)** | 웨이퍼가 아니라 사각 패널에서 공정 | 대면적 리소·도금·워피지 관리 |

| 팬아웃/RDL 특유의 장비 난제 | 내용 |
|----------------------------|------|
| **다이 시프트(die shift)** | 몰딩 중 다이가 움직여 설계 위치에서 벗어남 → RDL 노광 정렬이 안 맞음 → **다이별 적응 노광(adaptive patterning)** 이 등장 |
| **워피지** | 대면적일수록 심함 → 척킹·노광 초점 문제 |
| **대면적 노광 균일도** | 패널 전체에 균일한 CD |
| **두꺼운 레지스트/도금** | 수십 µm 두께 패터닝(전공levels과 다른 영역의 리소 기술) |

## 11. 후공정 검사 장비

| 장비 | 원리 | 잡는 것 |
|------|------|---------|
| **X-ray / 2D AXI** | 투과 X선 | 솔더 보이드, 미싱 볼, 브리지, 와이어 |
| **CT / 3D X-ray** | 단면 재구성 | TSV 보이드, 미세 크랙, 적층 내부 |
| **SAT / SAM (초음파)** | 초음파 반사 | **박리(delamination)**, 보이드 — X-ray가 못 보는 계면 결함 |
| **AOI (광학)** | 이미지 | 외관, 마킹, 볼 형상, 코플래너리티 |
| **3D 형상 측정(레이저/간섭)** | 높이 | 범프 높이·코플래너리티, 워피지 |

> **SAT가 특별한 이유**: 박리(계면이 떠 있는 상태)는 X-ray로 거의 안 보입니다(밀도 차가 작음).
> 초음파는 계면의 음향 임피던스 차에 민감해 **미세한 들뜸을 잡습니다.** 패키지 신뢰성 검사의 핵심 도구입니다.

## 12. 파이널 테스트 — 핸들러와 번인

```
   [테스트 핸들러 + ATE]
    · 핸들러: 패키지를 트레이/튜브/릴에서 집어 테스트 소켓에 넣고, 온도를 맞추고,
              결과에 따라 굿/배드/등급별로 분류(빈닝)
      - 픽앤플레이스 방식 / 터렛 방식 / 스트립 방식
      - 온도 챔버: -40 ~ +125 ℃ 급 (제품 스펙에 따라)
      - 소켓: 소모품. 접촉 저항·마모 관리가 오판정의 최대 원인
    · ATE: 전기 시험. 멀티사이트 병렬 테스트로 원가 절감
    · 번인(Burn-in): 고온·고전압으로 초기 불량(infant mortality)을 미리 걸러냄
      - 번인 보드, 챔버. 자동차·서버용은 필수적으로 강화
```

| 이슈 | 내용 |
|------|------|
| **소켓 수명** | 접촉 불량 → 굿 다이를 불량으로 판정(수율 손실). 정기 클리닝·교체 |
| **온도 안정** | 테스트 온도가 특성에 직접 영향 |
| **처리량(UPH)** | 핸들러 인덱스 시간 + 테스트 시간 |
| **KGD 테스트** | 적층 전 다이 양품 보증. HBM 원가의 핵심 |

## 13. HBM 사례로 정리 — 장비가 어떻게 협업하나

```
 DRAM 웨이퍼 (전공정 완료)
   │
   ├─ TSV 형성: HAR 식각 → 절연 → 배리어/시드(PVD/ALD) → Cu 도금 → 어닐 → CMP
   ├─ 마이크로범프 형성: 리소 + 도금(Cu 필러 + 솔더 캡) + 리플로우
   ├─ 웨이퍼 테스트(KGD 확보)  ← 여기서 굿 다이를 확정해야 적층 수율이 산다
   ├─ 임시 본딩 → 박화(수십 µm) → TSV 백사이드 노출 → 백사이드 범프 → 디본딩
   │
   ├─ 적층(8 ~ 16단):
   │    · TC-NCF 방식: TCB 본더로 한 장씩, NCF가 언더필 역할
   │    · MR-MUF 방식: 다수 적층 후 매스 리플로우 + 몰디드 언더필
   │    · (차세대) 하이브리드 본딩: 범프 제거, 초박·초미세 피치
   │
   ├─ 로직 다이(베이스)와 결합 → 인터포저 위에 로직 + HBM 실장(2.5D, CoWoS 계열)
   ├─ 몰딩 → 워피지 관리 → 검사(X-ray/SAT/3D)
   └─ 파이널 테스트 → 출하

 ★ 병목이 어디인가:
   ① TSV·박화·적층의 수율 (다이 1개 불량 = 스택 전체 폐기)
   ② 워피지와 열 (16단은 열 저항·휨이 급증)
   ③ 본딩 처리량 (TCB는 1개씩 → 장비 대수로 해결 → CAPEX)
   ④ 테스트 (KGD와 중간 테스트가 원가 지배)
```

| 워피지 과다 | 재료 CTE, 몰딩/큐어 조건, 두께 | shadow moiré 측정, 구조·재료 재설계 |
| 하이브리드 본딩 미접합 | 파티클, 리세스 과다/부족, 활성화, 어닐 | 파티클 검사, CMP 리세스 계측, 적외/SAT |
| TSV 보이드 | 도금 첨가제, 시드 연속성 | 단면·X-ray, 시드 커버리지 |
| 테스트 수율 저하(하드웨어 기인) | 소켓·프로브 접촉 | 접촉 저항, 소켓 교체 후 재시험 |
| 몰드 플래시/미충진 | 클램프 압력, 재료 유동성, 벤트 | 금형 점검, 재료 조건 |

## 16. 최근 동향

| 동향 | 내용 |
|------|------|
| **하이브리드 본딩 확산** | HBM 차세대·로직 3D 적층의 핵심. D2W 처리량·청정도가 승부처 |
| **적층 단수 증가** | 12 → 16단 이상. 박화 한계, 열, 워피지 |
| **패널 레벨 패키징** | 대면적 저원가. 다이 시프트·워피지·대면적 노광이 과제 |
| **유리 기판/유리 코어** | 평탄도·CTE·고주파 특성 이점 기대. 가공·크랙 관리 장비 필요 |
| **후공정의 전공정화** | 리소·CMP·ALD·식각이 후공정 라인에 들어옴 → 청정도 기준 상승 |
| **테스트 중요성 증가** | KGD, 중간 테스트, 시스템 레벨 테스트(SLT) |
| **열 관리** | TIM, 리드, 액침/직접 냉각까지 패키지 설계 범위로 |
| **표준화/칩렛 생태계** | 인터페이스 표준화에 따른 장비·검사 요구 정립 |
