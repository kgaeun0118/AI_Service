# 09. 세정 장비 — 물 한 방울이 패턴을 무너뜨린다

> 선행 학습: [0-6 반송과 청정도](00-6-wafer-handling.md), [08 CMP](08-cmp.md)
> 다루는 장비: **웻 벤치(배치 침지)** · **싱글 웨이퍼 스핀 세정기** · 배치 스프레이 · 스크러버(브러시) · 메가소닉 · **초임계 CO₂ 건조** · 기상 세정(vapor HF/COR) · 베벨/백사이드 세정

---

## 1. 공정이 장비에 요구하는 것

세정은 팹에서 **가장 많이 반복되는 공정**입니다(전체 공정 스텝의 20 ~ 30 %가 세정·린스). 제거 대상이 4종류입니다.

| 제거 대상 | 예 | 주된 화학/방법 |
|-----------|-----|----------------|
| **파티클** | 슬러리 입자, 식각 부산물, 반송 마찰 입자 | SC1(NH₄OH/H₂O₂), 메가소닉, 브러시 |
| **금속 오염** | Fe, Cu, Ni, Al, Na | SC2(HCl/H₂O₂), 희석 HF, 왕수계 |
| **유기물** | 레지스트 잔류, 휴먼 오염, 폴리머 | SPM(H₂SO₄/H₂O₂, "피라냐"), O₃/DIW, 애싱 후 세정 |
| **자연산화막 / 잔류막** | SiO₂ 자연산화막, 식각 잔류 | DHF(희석 HF), BOE, 기상 HF |

그리고 요구는 상충합니다.

```
   깨끗하게 하려면  → 세게 (강한 화학, 강한 물리력, 긴 시간)
   그런데           → 패턴이 무너지고, 막이 손상되고, 재료가 침식되고, 원가가 오른다

   → "필요한 것만 정확히 제거하고, 나머지는 건드리지 않는" 선택성이 세정 장비의 본질
```

## 2. 변천사

| 시기 | 기술 | 이유 / 한계 |
|------|------|-------------|
| 1970s | **RCA 세정** (SC1 + SC2) 정립 | 파티클·금속 제거의 표준 체계 확립 |
| 1980 ~ 90s | **웻 벤치(배치 침지)** — 카세트 단위 | 저원가·대량. 단점: 케미컬 오염 누적(크로스 컨탬), 배치 내 편차, 케미컬 소모 |
| 1990s | 배치 스프레이, 마랑고니 건조 | 린스/건조 개선 |
| 2000s | **싱글 웨이퍼 스핀 세정** 주류화 | 항상 새 케미컬 접촉(재현성↑), 앞/뒷면 분리 처리, 소량 화학, 미세 패턴 대응 |
| 2000s ~ | 메가소닉 파워 제어, 희석 화학(dilute chemistry) | 패턴 손상 억제 |
| 2010s ~ | **초임계 CO₂ 건조**, 기상 세정, 극저손상 세정 | 고종횡비 패턴 붕괴 방지 |
| 현재 | 선택적 습식 제거(나노시트 릴리즈), 표면 활성화(본딩 전), 극청정 | 3D 구조·하이브리드 본딩 |

> **결정적 전환**: 배치 → 싱글 웨이퍼.
> 이유는 "품질"입니다. 배치는 같은 탱크를 여러 로트가 공유하므로 오염이 누적되고, 웨이퍼 간 편차가 생깁니다.
> 싱글 웨이퍼는 **매 웨이퍼가 새 케미컬을 만나므로 재현성이 높고, 화학 사용량도 적습니다**(단 처리량을 챔버 수로 벌어야 함).

## 3. 장비 구조

### 3-1. 싱글 웨이퍼 스핀 세정기 (현대 팹의 주력)

```
   [1 챔버 단면]

            ┌─── 스캔 암 (노즐을 반경 방향으로 이동) ───┐
            │   · 케미컬 노즐 (SC1/DHF/SPM/DIW …)      │
            │   · 메가소닉 노즐 (음향 에너지)            │
            │   · IPA/N₂ 건조 노즐                     │
            └─────────────────┬─────────────────────┘
                              ▼
        ┌──────────────────────────────────────────┐
        │   ███████ 웨이퍼 (앞면 위) ███████          │
        │   스핀 척 (진공척 / 엣지 그립 / 베르누이)     │ ← 회전 수백 ~ 수천 rpm
        │   백사이드 린스 노즐 (뒷면 세정)              │
        │   컵(cup) + 배액/배기 (케미컬 회수·분리)      │ ← 산/염기/유기 분리 회수
        └──────────────────────────────────────────┘
   · 챔버 여러 개(4 ~ 12+)를 타워로 쌓고 로봇이 분배 → 처리량 확보
   · 케미컬 캐비닛: 온도 제어, 혼합, 필터, 농도 모니터
```

| 부품 | 역할 | 문제 시 |
|------|------|---------|
| **스핀 척** | 웨이퍼 고정·회전 | 진공척은 뒷면 접촉(오염), 엣지 그립은 엣지 결함 관리 필요 |
| **케미컬 노즐/스캔 암** | 반경 방향 균일 분배 | 막힘·위치 오차 → 링 형태 편차 |
| **메가소닉 노즐** | 음향 캐비테이션으로 입자 제거 | 파워 과다 → **패턴 파손**(가장 흔한 손상 원인) |
| **백사이드 노즐** | 뒷면 오염 제거 | 노광 디포커스 예방 |
| **컵/배기/배액** | 케미컬 회수·비산 방지 | 재부착 결함, 혼합 위험(산+염기) |
| **케미컬 공급부** | 혼합·온도·여과 | 농도/온도 오차 → 식각량 변동 |
| **DIW/린스** | 잔류 화학 제거 | 워터마크, 잔류 |
| **건조(IPA/N₂)** | 마랑고니/IPA 치환 건조 | 워터마크, 패턴 붕괴 |

### 3-2. 웻 벤치 (배치)

```
   [탱크 열]
   ┌──────┬──────┬──────┬──────┬──────┬──────┐
   │ SPM  │ 린스 │ SC1  │ 린스 │ DHF  │ 린스 │ → 스핀 건조기(SRD) 또는 IPA 건조
   │ 120℃ │ DIW  │ 70℃  │ DIW  │ 상온 │ DIW  │
   └──────┴──────┴──────┴──────┴──────┴──────┘
     로봇이 카세트(25 ~ 50장)를 순서대로 침지
   · 오버플로 린스, 퀵 덤프 린스(QDR)
   · 각 탱크: 순환 필터, 온도 제어, 농도 관리(보충/교체)
   · 배기: 산/염기 분리, 스크러버
```

| 여전히 쓰는 이유 | 한계 |
|------------------|------|
| 원가(웨이퍼당 화학·설비비 낮음), 처리량, 두꺼운 막 제거·희생층 제거에 유리 | 크로스 컨탬, 배치 내 편차, 케미컬 수명 관리, 미세 패턴 손상 |

### 3-3. 스크러버(브러시) — CMP 후 전용

PVA 스폰지 브러시가 웨이퍼 양면을 접촉 회전하며 입자를 물리적으로 제거합니다.
브러시 자체가 오염원이 될 수 있어 **브러시 세정·교체 관리**가 핵심입니다. [08장](08-cmp.md) 참조.

## 4. 세정 화학 사전

| 약칭 | 조성 | 온도(전형) | 제거 대상 | 주의 |
|------|------|-----------|-----------|------|
| **SC1** | NH₄OH : H₂O₂ : H₂O | 50 ~ 70 ℃ | 파티클, 유기물 | Si를 미세하게 식각(표면 거칠기↑) → 희석·시간 관리 |
| **SC2** | HCl : H₂O₂ : H₂O | 50 ~ 70 ℃ | 금속 이온 | — |
| **SPM (피라냐)** | H₂SO₄ : H₂O₂ | 100 ~ 130 ℃ | 레지스트·유기물 | 강산·발열. 금속 있으면 사용 불가(부식) |
| **DHF / BOE** | HF 희석 / NH₄F 버퍼 | 상온 | 자연산화막, 산화막 | **HF 취급 위험**([0-9장](00-9-operations-and-safety.md)), 하부 산화막 손실 |
| **APM/HPM** | SC1/SC2의 다른 표기 | — | — | — |
| **O₃/DIW** | 오존수 | 상온 | 유기물(SPM 대체) | 산화막 성장 |
| **희석 화학 (dilute)** | 고희석 + 물리 에너지 | — | 파티클 | 손상 저감·원가 절감 |
| **왕수/전용 케미컬** | — | — | 특정 금속 | 재료 호환성 확인 |
| **기상 HF / COR** | HF+NH₃ 증기, 후속 가열 승화 | — | 자연산화막 | **액체 없음 → 패턴 붕괴 없음** |
| **선택적 습식** | 예: SiGe 선택 제거 | — | 희생층 | 나노시트 릴리즈 |

> **Q-time 개념**: DHF로 자연산화막을 제거한 후 시간이 지나면 다시 산화막이 자랍니다(대기·수분).
> 그래서 세정 → 다음 공정 사이에 **최대 허용 대기 시간**이 규정됩니다. 장비 다운이 곧 품질 리스크가 되는 이유입니다.

## 5. 패턴 붕괴 — 세정의 최대 난제

```
   고종횡비 패턴(예: 폭 20 nm, 높이 200 nm) 사이에 물이 남아 있다가 마르면
   표면장력이 두 벽을 서로 당겨 패턴이 넘어진다(capillary collapse).

      ║  ║  ║        ║ ╲ ╱ ║
      ║  ║  ║   →    ║  ╳  ║   ← 붕괴
      물  물  물

   붕괴력 ∝ 표면장력 × (종횡비)  → 미세화될수록 급격히 위험

   대책 계보:
    ① IPA 치환 건조: 물보다 표면장력이 낮은 IPA로 바꿔 건조
    ② 마랑고니 건조: IPA 증기로 액면에 표면장력 구배를 만들어 물을 밀어냄
    ③ 계면활성제 린스: 표면장력 자체를 낮춤
    ④ ★ 초임계 CO₂ 건조: 초임계 상태는 기-액 계면이 없음 → **표면장력 0**
       → 붕괴 없이 완전 건조. 현재 최첨단 구조의 해법
    ⑤ 기상 세정(액체를 아예 쓰지 않음)
```

### 초임계 CO₂(scCO₂) 건조 장비

```
   원리: CO₂를 임계점(약 31 ℃, 7.4 MPa) 이상으로 만들면 기체와 액체의 구분이 사라진다
        → 패턴 사이의 IPA를 초임계 CO₂로 치환 → 압력을 낮춰 기체로 전환
        → 액-기 계면이 존재한 적이 없으므로 표면장력이 작용하지 않음

   장비 요구: 고압 챔버(수십~100 bar 이상), 압력 시퀀스 제어, 웨이퍼 반송(고압 도어),
             CO₂ 순환·정제, 안전(고압 인터락)
   대가: 처리량·비용·장비 복잡도 → 꼭 필요한 층에만 적용
```

## 6. 메가소닉 — 물리력의 양날의 검

```
   원리: 약 1 MHz 대 음파를 물에 가하면 미세 기포(캐비테이션)와 음향 흐름이 발생
        → 표면 입자를 떼어낸다

   문제: 그 에너지가 미세 패턴도 부러뜨린다
   대책:
    · 파워·주파수 정밀 제어(저파워 + 화학 보조)
    · 펄스 인가, 노즐 스캔으로 국부 에너지 균일화
    · 용존가스 제어(캐비테이션 강도 조절)
    · 손상 한계와 제거 효율의 "창"을 실험으로 찾아 고정 (패턴 세대마다 재설정)
```

> 실무 표현: "세정은 **제거 효율과 손상의 균형점**을 찾는 일"입니다. 파티클이 줄었다고 좋아하다가 패턴 붕괴로 수율을 잃는 일이 흔합니다.

## 7. 특수 세정 영역

| 영역 | 이유 | 장비/방법 |
|------|------|-----------|
| **웨이퍼 백사이드** | 노광 디포커스, 척킹 오염, 장비 간 교차 오염 | 전용 백사이드 노즐, 스크러버 |
| **베벨/엣지** | 엣지의 막 박리 → 파티클의 근원 | 베벨 세정/식각 전용 챔버 |
| **CMP 후** | 슬러리·금속 잔류 | 브러시 + 화학 + 메가소닉 |
| **애싱 후(레지스트 제거)** | 폴리머 잔류, 금속 부식 | 전용 리무버, 저손상 화학 |
| **본딩 전 표면 준비** | 하이브리드 본딩은 원자 수준 청정·활성화 필요 | 플라즈마 활성화 + 초순수 세정 + 극저 파티클 ([11장](11-packaging.md)) |
| **저유전막 세정** | 다공성 막은 화학이 침투해 손상 | 희석 화학, 기상, 저손상 |
| **금속 노출 구조** | 갈바닉 부식 위험(이종 금속 접촉) | pH·산화제 제어, 억제제 |

## 8. 장비 노브 ↔ 공정 결과

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| 케미컬 농도 ↑ | 반응 속도 | 제거 효율 ↑ | 하부 손상, 표면 거칠기, 원가 |
| 온도 ↑ | 반응 속도(지수) | 제거 ↑ | 손상, 케미컬 수명 ↓, 증기 |
| 시간 ↑ | 누적 반응 | 제거 ↑ | 손상, 처리량 ↓ |
| 회전수 ↑ | 액막 두께·물질 전달 | 균일도, 건조성 | 비산, 국부 건조 |
| 메가소닉 파워 ↑ | 캐비테이션 | 파티클 제거 ↑ | **패턴 붕괴** |
| 노즐 스캔 속도/위치 | 액 공급 분포 | 반경 균일도 | 링 패턴 |
| 린스 시간/유량 | 잔류 제거 | 결함 ↓ | 원가(초순수) |
| IPA/건조 조건 | 표면장력·증발 | 워터마크·붕괴 방지 | 원가, VOC |
| 희석 화학 + 물리 조합 | 균형 | 손상 ↓, 효율 유지 | 최적화 필요 |

## 9. 불량과 장비 원인

| 증상 | 의심 | 확인 |
|------|------|------|
| 파티클 제거 부족 | 화학 농도/온도, 메가소닉, 노즐 | 농도 분석, 파워 확인, 노즐 점검 |
| 패턴 붕괴 | 건조 방식, 메가소닉, 종횡비 | IPA/마랑고니/scCO₂ 검토, 파워 하향 |
| 워터마크 | 건조 불량, 잔류 수분, 용존산소 | 건조 시퀀스, IPA 농도, 회전 프로파일 |
| 링(ring) 형태 결함 | 노즐 스캔, 회전수, 액막 | 스캔 프로파일, rpm |
| 금속 오염 잔류 | SC2/케미컬 수명, 탱크 오염 | 케미컬 교체 이력, TXRF |
| 산화막 손실 과다 | DHF 농도/시간, 온도 | 식각량 측정, 조건 재설정 |
| 부식(금속 노출) | pH/산화제, 갈바닉 | 화학 선택, 억제제 |
| 저유전막 k값 상승 | 화학 침투 손상 | 기상/희석 전환 |
| 웨이퍼 파손/슬립 | 척킹, 회전 가속 | 척 상태, 레시피 |
| 배치 편차(웻 벤치) | 탱크 농도 구배, 침지 위치 | 순환·필터, 카세트 위치 실험 |
| 교차 오염 | 탱크 공유, 배기 혼입 | 공정 순서·전용 탱크 정책 |
