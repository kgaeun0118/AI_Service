# 08. CMP 장비 — 갈아내는 기술이 최첨단인 이유

> 선행 학습: [0-8 부품과 소모품](00-8-parts-and-consumables.md), [06 금속배선](06-metallization-pvd-ecp.md)

## 1. 공정이 장비에 요구하는 것 — 왜 CMP가 필수인가

CMP(Chemical Mechanical Planarization)는 **웨이퍼 표면을 화학+기계적으로 평탄하게 깎아내는** 공정입니다.
"갈아낸다"는 원시적인 동작인데, 왜 최첨단 팹의 필수 장비일까요? 이유는 3개입니다.

| 이유 | 설명 |
|------|------|
| **① 노광 초점심도(DOF)** | 층을 쌓을수록 표면 요철이 누적됩니다. 그런데 노광의 DOF는 수십 nm에 불과합니다([03장](03-photolithography.md)). 표면이 울면 패턴이 흐려집니다 → **매 층마다 평탄화가 필요** |
| **② Cu 다마신** | Cu는 식각할 수 없어 "채우고 깎아내는" 방식을 씁니다. 여분 Cu와 배리어를 제거하는 유일한 수단이 CMP입니다([06장](06-metallization-pvd-ecp.md)) |
| **③ 구조 형성 자체** | STI(소자 분리), W 플러그, 게이트(RMG), 하이브리드 본딩 표면 — 이제 CMP가 **구조를 만드는 공정**입니다 |

특히 ③이 중요합니다. **하이브리드 본딩**에서는 Cu 패드의 리세스(함몰)를 **nm 단위로 제어**해야 접합이 됩니다([11장](11-packaging.md)).
즉 CMP는 "정리하는 공정"에서 **"정밀 가공 공정"** 으로 위상이 바뀌었습니다.

## 2. 원리 — 화학과 기계의 협업

```
   [기본 식: Preston 식]

        MRR (제거율) = k · P · v

        P : 압력 (캐리어 헤드가 웨이퍼를 패드에 누르는 힘/면적)
        v : 상대 속도 (패드와 웨이퍼의 상대 회전 속도)
        k : Preston 계수 — 슬러리 화학, 패드, 재료가 결정

   → 기계적 변수(P, v)는 장비가, k는 소모품/화학이 지배한다.
```

```
   [화학+기계의 협업 메커니즘]

   ① 슬러리의 화학 성분이 표면을 "부드럽게" 만든다
      · 금속: 산화제(H₂O₂ 등)가 표면을 산화막으로 바꿈 (단단한 금속 → 무른 산화물)
      · 산화막: 알칼리(KOH/NH₄OH)가 Si–O 결합을 약화
   ② 슬러리 내 연마 입자(실리카/세리아/알루미나)가 그 약해진 층만 기계적으로 제거
   ③ 억제제(예: Cu용 BTA)가 깎이지 않아야 할 곳(오목부)을 보호막으로 덮어
      "튀어나온 부분만 깎이는" 선택성을 만든다  ← 평탄화의 핵심

   → 화학만으로는 등방성(평탄화 안 됨), 기계만으로는 스크래치.
      둘의 협업이 "돌출부만 제거"를 만든다.
```

## 3. 변천사

| 시기 | 기술 | 이유 |
|------|------|------|
| ~1980s | CMP 없음. **리플로우 평탄화**(BPSG를 녹여 흐르게), 에치백 | 열버짓·평탄도 한계, 국부 평탄화만 가능 |
| 1990년경 | **CMP 도입(IBM 등)** — 산화막 CMP | 다층 배선의 전역 평탄화(global planarization) 필요 |
| 1990s | STI CMP, W 플러그 CMP | 소자 분리·컨택 구조 |
| 1998 ~ | **Cu CMP** (다마신) | Cu 배선 도입 → CMP가 필수 설비로 |
| 2000s | 세리아 슬러리(STI 고선택비), 저압 CMP(저유전막 보호) | 재료 다양화, 취약한 막 대응 |
| 2000s ~ | 멀티 플래튼·인라인 계측·에디전류 종점, 포스트 CMP 세정 통합 | 처리량·수율 |
| 2010s ~ | **RMG(대체 게이트) CMP**, 폴리 CMP, 다양한 금속(Co/Ru/W) | FinFET 구조 형성 |
| 현재 | **하이브리드 본딩용 초정밀 CMP**(nm급 리세스/거칠기), 3D 적층 | 패키징과 전공정의 융합 |

> **관점**: CMP의 역사는 "표면을 정리하던 공정"이 **"구조를 만들고 접합면을 만드는 공정"** 으로 승격된 역사입니다.

### 4-1. 캐리어 헤드 — 웨이퍼 내 균일도를 만드는 심장

```
   [멀티존 캐리어 헤드 단면]

      ┌──────────────────────────────────────┐
      │   헤드 바디 (회전 + 상하 가압)          │
      │  ┌─── 에어백/멤브레인 (존 1~5+) ───┐   │ ← 각 존의 공압을 독립 제어
      │  │  ▒▒▒▒▒ 존1  존2  존3  존4 ▒▒▒▒▒ │   │   → 반경 방향 압력 프로파일 조형
      │  └──────────────────────────────────┘   │
      │     ███████ 웨이퍼 (아래로 향함) ███████  │
      │  ┌──────────────────────────────────┐   │
      │  │   리테이닝 링 (retaining ring)     │   │ ← 웨이퍼가 튀어나가지 않게 잡음
      │  └──────────────────────────────────┘   │   + 엣지 유동/압력에 큰 영향(소모품)
      └──────────────────────────────────────┘
      ╔════════════ 패드 ════════════╗
```

| 부품 | 역할 | 문제 시 |
|------|------|---------|
| **멤브레인(다존 에어백)** | 반경 방향 압력 프로파일 제어 → **웨이퍼 내 제거량 균일도** | 찢어짐 → 국부 압력 이상, 균일도 붕괴 |
| **리테이닝 링** | 웨이퍼 고정 + 엣지 압력/슬러리 유입 제어 | **마모 → 엣지 제거율 변화(엣지 롤오프)**. 대표적 소모품 |
| **헤드 회전/스윕 구동** | 상대속도·패드 마모 분산 | 편심·진동 → 스크래치 |
| **진공/로딩 기구** | 웨이퍼 장착 | 드랍, 파손 |
| **백사이드 세정** | 웨이퍼 뒷면 오염 방지 | 후속 노광 디포커스 |

### 4-2. 패드와 컨디셔너 — k를 지배하는 소모품

| 요소 | 내용 |
|------|------|
| **패드 재질** | 폴리우레탄. 다공성(기공이 슬러리를 담아 운반), 경질/연질 선택 |
| **그루브(groove) 패턴** | 동심원/방사형/XY. **슬러리 운반과 부산물 배출 경로**. 패턴이 균일도·스크래치에 영향 |
| **적층 구조** | 상부 경질(평탄화) + 하부 연질(웨이퍼 추종) 이중 패드가 흔함 |
| **패드 마모** | 사용할수록 두께·기공 구조가 변해 **MRR이 떨어짐** → R2R 보정 또는 교체 |
| **컨디셔닝(다이아몬드 디스크)** | 패드 표면의 막힘(glazing)을 긁어 새 기공을 노출 → **MRR 유지**. 스윕하며 균일하게 |
| **브레이크인(break-in)** | 새 패드는 길들이기 필요(수십 분) → 안 하면 초기 MRR/균일도 불안정 |
| **컨디셔너 디스크 마모** | 다이아몬드 탈락 → 스크래치 원인, 컨디셔닝 효과 저하 |

> **현장 감각**: CMP에서 결과가 흔들리면 **① 패드 수명 위치, ② 컨디셔너 상태, ③ 리테이닝 링 두께, ④ 슬러리 상태** 를 먼저 봅니다.
> 장비 본체보다 소모품이 결과를 지배하는 대표적인 공정입니다.

### 4-3. 슬러리 — 화학이 절반

| 대상 | 연마 입자 | 화학 | 포인트 |
|------|-----------|------|--------|
| **SiO₂ (산화막/ILD)** | 콜로이달 실리카, 퓸드 실리카 | 알칼리(KOH/NH₄OH) | 범용. 입자 응집 → 스크래치 |
| **STI (고선택비)** | **세리아(CeO₂)** | 계면활성제 + 억제제 | 산화막:질화막 선택비를 크게 → 질화막 스톱층에서 자동 정지 |
| **W** | 실리카/알루미나 | 산화제(H₂O₂/철염 등), 산성 | 부식·갈바닉 부식 주의 |
| **Cu** | 실리카/알루미나 | H₂O₂ + **BTA(억제제)** + 킬레이트제 | BTA가 Cu 표면에 보호막 → 디싱 억제 |
| **배리어(TaN/Ta)** | 실리카 | 선택비 조정 | Cu/배리어/유전막 3종 선택비 동시 관리 |
| **폴리/게이트** | — | — | RMG 구조에서 정밀 제어 |

**슬러리 공급 시스템의 요구**
- 입자 **응집 방지**: 응집체 하나가 스크래치 → 전용 필터, 무맥동(펄스 없는) 펌프, 배관 데드존 제거.
- **혼합 정확도**: 원액 + DIW + 산화제를 사용 직전에 혼합(산화제는 수명이 짧음).
- **온도 관리**: 화학 반응 속도가 온도 의존 → MRR 변동.
- **유량·토출 위치**: 패드 중앙 vs 웨이퍼 앞쪽. 슬러리 이용률이 원가에 직결(슬러리는 CMP 원가의 큰 부분).

## 5. 종점 검출 — 언제 멈추는가

| 방식 | 원리 | 적용 | 한계 |
|------|------|------|------|
| **모터 전류/토크** | 다른 재료가 노출되면 마찰계수가 변해 모터 부하가 변함 | 금속 CMP(Cu/W 제거 완료) | 패턴 밀도 낮으면 신호 약함 |
| **에디 전류(eddy current)** | 금속막 두께에 따라 유도 전류 변화 | **금속 잔량 실시간 측정** | 비금속에는 불가 |
| **광학(반사/간섭)** | 패드의 창(window)을 통해 반사 스펙트럼 측정 | 산화막 두께 실시간 | 패드 창 오염, 패턴 의존 |
| **마찰/음향** | 진동·음향 신호 | 보조 | 노이즈 |
| **인라인 계측(공정 후)** | 별도 스테이션에서 두께 측정 → R2R | 모든 공정 | 실시간 아님 |

## 6. CMP 고유 불량 — 디싱, 에로전, 스크래치

```
  [디싱 (dishing)]  : 넓은 금속 배선의 중앙이 오목하게 파임
      ▓▓▓▓▓▓▓▓▓▓▓▓  ← 원래 목표
      ▓▓╲________╱▓▓  ← 금속이 무르고 넓어서 패드가 눌려 들어감
   원인: 넓은 금속 영역, 압력 과다, 연질 패드, 오버폴리시
   결과: 배선 단면 감소 → 저항 증가, 층간 평탄도 악화

  [에로전 (erosion)]: 패턴 밀집 영역 전체가 주변보다 낮아짐
      ░░░░░▽▽▽▽▽░░░░░   (조밀 배선 영역이 통째로 침하)
   원인: 밀집 영역은 실효 경도가 낮아 더 빨리 깎임 (패턴 밀도 의존)
   결과: 층간 두께 편차, 후속 노광 DOF 악화
   대책: 더미 패턴(fill pattern) 삽입으로 밀도 균일화 ← 설계 규칙이 CMP 때문에 생긴 사례

  [스크래치]: 표면 긁힘 → 배선 단락/단선의 직접 원인
   원인: 슬러리 응집체, 컨디셔너 다이아몬드 탈락, 패드 이물, 세정 불량
   대책: 필터, 슬러리 관리, 패드/디스크 관리, 청정 유지

  [잔류(residue)]: 금속/배리어가 다 제거되지 않고 남음 → 단락
   원인: 균일도 부족, 오버폴리시 부족, 함몰부
```

> **디싱/에로전의 교훈**: CMP는 **설계(레이아웃)까지 바꿔 놓았습니다.**
> "더미 메탈을 넣어 패턴 밀도를 균일하게 하라"는 설계 규칙은 순수하게 CMP 장비의 물리에서 나온 요구입니다.
> **장비가 설계 규칙을 만든다** — 이 총서에서 반복되는 주제의 대표 사례입니다.

## 7. 포스트 CMP 세정 — CMP의 절반

CMP 직후 웨이퍼 표면에는 **슬러리 입자, 금속 이온, 반응 생성물**이 남아 있습니다. 이를 제거하지 않으면 그대로 결함이 됩니다.

| 단계 | 방법 | 목적 |
|------|------|------|
| 벌크 린스 | 고압 DIW | 슬러리 대량 제거 |
| **브러시 스크럽** | PVA 스폰지 브러시 양면 | 입자 물리 제거 |
| 화학 세정 | 희석 산/염기, 킬레이트제, 계면활성제 | 금속 이온·잔류물 제거 |
| 메가소닉 | 음향 캐비테이션 | 미세 입자 제거(단, 미세 패턴 손상 주의) |
| 부식 억제 | BTA 등 | Cu 표면 보호 |
| 건조 | 스핀 건조, IPA | 워터마크 방지 |

상세는 [09장 세정](09-cleaning.md).

## 8. 장비 노브 ↔ 공정 결과

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| **헤드 압력 ↑** | Preston의 P | MRR ↑ | 디싱·에로전 ↑, 스크래치 ↑, 저유전막 손상 |
| **존별 압력 프로파일** | 반경 방향 압력 | **웨이퍼 내 균일도 튜닝** | 과보정 시 엣지/센터 반전 |
| **플래튼/헤드 회전수 ↑** | 상대 속도 v | MRR ↑ | 슬러리 비산, 진동, 온도 상승 |
| **슬러리 유량 ↑** | 화학종·입자 공급, 열 제거 | MRR 안정, 스크래치 ↓ | 원가 ↑, 폐기물 ↑ |
| **슬러리 온도** | 반응 속도 | MRR | 변동 시 재현성 ↓ |
| **컨디셔닝 강도/시간** | 패드 표면 재생 | MRR 유지 | 패드 수명 ↓, 스크래치 |
| **리테이닝 링 압력** | 엣지 유동·압력 | 엣지 프로파일 | 링 마모 가속 |
| **오버폴리시 시간** | 잔류 제거 | 잔류 ↓ | **디싱·에로전 ↑** |
| **패드 종류(경/연질)** | 접촉 응력 분포 | 평탄화 능력 vs 균일도 | 상충 |
| **다단 플래튼 분배** | 벌크/배리어/버프 분리 | 선택적 제어 | 처리량 |

## 9. 불량과 장비 원인 (트러블슈팅)

| 증상 | 의심 | 확인 |
|------|------|------|
| MRR 점진 감소 | 패드 마모/글레이징, 컨디셔너 마모, 슬러리 열화 | 패드 사용 시간, 디스크 상태, 슬러리 농도/온도 |
| MRR 급변 | 슬러리 공급 이상(펌프/배관), 혼합비 | 유량·압력 로그, 혼합 시스템 |
| 엣지 제거율 이상 | **리테이닝 링 마모**, 링 압력, 멤브레인 | 링 두께 실측, 압력 설정 |
| 웨이퍼 내 균일도 악화 | 존 압력, 멤브레인 손상, 패드 프로파일 | 프로파일 측정, 헤드 점검 |
| 스크래치 증가 | 슬러리 응집, 디스크 다이아몬드 탈락, 이물 | 필터 교체, 디스크 교체, 배관 청소 |
| 잔류(금속/배리어) | 오버폴리시 부족, 균일도, 종점 오류 | 에디전류 신호, 시간 조정, 단면 확인 |
| 디싱/에로전 과다 | 압력·오버폴리시·패턴 밀도 | 압력 하향, 시간 단축, 더미 패턴 설계 확인 |
| 웨이퍼 파손/슬립 | 헤드 로딩, 링 상태, 진동 | 로딩 시퀀스, 링 교체 |
| 포스트 세정 결함 | 브러시 오염, 화학 농도, 건조 | 브러시 교체, 케미컬 점검 |
| 저유전막 손상/박리 | 압력 과다, 응력 | 저압 CMP 조건, 접착 개선 |
| 챔버(플래튼) 간 차이 | 패드 수명 위치, 링, 슬러리 분배 | 소모품 카운트 정렬, 매칭 절차 |

```
 일상: 패드 사용 시간·웨이퍼 수, 컨디셔너 디스크 상태, 리테이닝 링 두께,
       슬러리 유량/농도/온도, MRR 트렌드, 스크래치·파티클 모니터

 패드 교체 PM:
   ① 패드 제거 → 플래튼 표면 청소(접착 잔류 완전 제거: 남으면 국부 융기)
   ② 새 패드 부착(기포 없이 — 기포는 국부 압력 이상)
   ③ **브레이크인** (규정 시간/웨이퍼 수)
   ④ 더미 웨이퍼로 MRR·균일도 측정 → 목표와 비교
   ⑤ 필요 시 존 압력 재튜닝 → Qual(두께/균일도/스크래치/파티클) → 릴리즈

 정기 PM: 헤드 멤브레인 점검·교체, 리테이닝 링 교체, 슬러리 배관·필터,
          컨디셔너 디스크, 세정 브러시, 계측 센서(광학 창/에디 코일) 캘
```
