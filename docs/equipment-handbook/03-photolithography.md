# 03. 포토리소그래피 장비 — 빛으로 회로를 그리는 기계

> 선행 학습: [0-2 진공](00-2-vacuum.md), [0-5 온도와 척](00-5-thermal-and-chuck.md), [0-6 반송](00-6-wafer-handling.md)
> 다루는 장비: **트랙(코터/디벨로퍼)** · 얼라이너(컨택/프록시미티) · **스테퍼 → 스캐너** · ArF 이머전 · **EUV(NXE)** · **High-NA EUV(EXE)** · 마스크 제작/검사 장비
> 이 장은 이 총서에서 가장 깁니다. 포토가 모든 공정의 기준을 만들고, 장비 발전사가 가장 극적이기 때문입니다.

---

## 0. 먼저 용어 하나 정리 — "Deep-EUV"는 없다

현장/기사에서 혼용되지만, 정확한 계보는 이렇습니다.

```
   UV(자외선) ──▶ DUV (Deep Ultraviolet, 심자외선)  : 248 nm(KrF), 193 nm(ArF)
                        │
                        └──▶ EUV (Extreme Ultraviolet, 극자외선) : 13.5 nm
                                  │
                                  └──▶ High-NA EUV : 같은 13.5 nm, NA를 0.33 → 0.55로
```

- **DUV**가 **EUV보다 먼저** 나온 세대입니다("Deep"이 더 강한 것이 아닙니다).
- "Deep-EUV"라는 표기는 표준 용어가 아니며, 보통 **DUV(ArF/KrF)** 를 뜻하려던 것입니다.
- EUV의 다음 단계는 파장을 더 줄이는 것이 아니라 **NA를 키우는 것(High-NA)** 입니다. 이유는 아래 3절에서 설명합니다.

## 1. 공정이 장비에 요구하는 것 — 리소의 4대 스펙

| 스펙 | 정의 | 현재 수준 감각 | 무엇이 망가지면 이게 나빠지나 |
|------|------|----------------|------------------------------|
| **해상력 (Resolution)** | 분리해 그릴 수 있는 최소 피치/선폭 | EUV 0.33NA: 단일 노광 ~13 nm 하프피치급 / High-NA 0.55: ~8 nm급 | 파장, NA, 조명, 레지스트 |
| **오버레이 (Overlay)** | 이전 층과의 정합 정확도 | 수 nm(첨단 노드) | 스테이지, 얼라인, 웨이퍼 변형, 열, 레티클 |
| **CD 균일도 (CDU) / LWR** | 선폭 산포, 선폭 거칠기 | 수백 pm ~ 수 nm | 도즈·포커스 제어, 레지스트 확률효과, 마스크, 식각 |
| **처리량 (WPH)** | 시간당 웨이퍼 | ArF-i ~ 200 ~ 300, EUV ~ 150 ~ 220 (모델·도즈 의존) | 광원 파워, 스테이지 가속, 도즈 |

그리고 이 모든 것을 지배하는 두 식(레일리 식):

```
        해상력:  R  =  k₁ · λ / NA
        초점심도: DOF =  k₂ · λ / NA²

   λ  : 노광 파장
   NA : 투영 광학계의 개구수 (Numerical Aperture) = n·sinθ
   k₁ : 공정 상수(조명·레지스트·OPC로 개선, 단일 노광 한계 ≈ 0.25 근처)
   n  : 마지막 매질의 굴절률 (공기 1.0, 물 1.44)
```

이 두 식이 **리소 장비 역사 전체를 설명합니다.**

```
   해상력을 좋게 하려면 → λ↓ 또는 NA↑ 또는 k₁↓
   그런데 NA↑ 하면 DOF가 NA² 로 급감 → 웨이퍼가 조금만 울어도 초점이 안 맞음
   → 그래서 NA를 키울 때마다 "평탄화(CMP), 레벨 센서, 박막 레지스트, 하드마스크"가 같이 발전해야 했다
```

> **이것이 리소를 이해하는 가장 중요한 한 줄**:
> **해상력과 초점심도는 항상 맞바꾸는 관계**이고, 장비 발전의 절반은 이 대가를 감당할 주변 기술을 만드는 일이었습니다.

## 2. 변천사 — 무엇이 막혀서 무엇으로 갔는가

### 2-1. 전체 계보

| 세대 | 방식 | 파장 | NA(대표) | 해상력(대략) | 한계 → 다음으로 간 이유 |
|------|------|------|----------|--------------|------------------------|
| 1960s | **컨택 프린터** | 가시광~UV | — | µm | 마스크와 웨이퍼가 **직접 접촉** → 마스크 손상·파티클·수율 붕괴 |
| 1970s | **프록시미티** | UV | — | µm | 간격(수십 µm)만큼 회절로 흐려짐 → 해상력 한계 |
| 1970s 후 | **1:1 투영 스캐너** | g/h-line | 저 NA | ~2 µm | 1:1 마스크 제작 난이도, 전면 스캔의 해상력 한계 |
| 1980s | **스테퍼(step & repeat)**, 축소 투영 4 ~ 5× | **g-line 436 nm** | 0.3 ~ 0.4 | ~1 µm | 파장 한계 |
| 1980s 말 | 스테퍼 | **i-line 365 nm** (수은 램프) | 0.45 ~ 0.63 | 0.35 ~ 0.5 µm | 램프 광량·파장 한계 |
| 1990s | **엑시머 + 스텝&스캔 스캐너** | **KrF 248 nm** | 0.5 ~ 0.8 | 0.25 ~ 0.13 µm | 파장 한계 |
| 2000s | 스캐너 | **ArF 193 nm** | 0.75 ~ 0.93 | 90 ~ 65 nm | **공기 중 NA는 1 미만이 상한** |
| (실패) | F₂ | 157 nm | — | — | **소재(렌즈·펠리클·레지스트) 전멸** → 포기 |
| 2000s 중 | **ArF 이머전 (193i)** | 193 nm + **물(n=1.44)** | **1.20 ~ 1.35** | 40 nm 급 | 물보다 굴절률 높은 실용 액체 없음 → NA 한계 |
| 2007 ~ | **멀티 패터닝** (LELE, SADP, SAQP) | 193i | 1.35 | 20 nm 이하까지 | **공정 수·비용·오버레이 폭증** |
| 2019 ~ | **EUV (NXE, 0.33 NA)** | **13.5 nm** | 0.33 | ~13 nm 하프피치 | 광원 파워·확률효과·비용, 단일 노광 한계 도달 |
| 2024 ~ | **High-NA EUV (EXE, 0.55 NA)** | 13.5 nm | **0.55** | ~8 nm 급 | 하프 필드, 새 마스크/레지스트 생태계 필요 |

### 2-2. 세대 전환의 "진짜 이유" 정리

| 전환 | 겉으로 보이는 이유 | 실제 장비 관점의 이유 |
|------|-------------------|----------------------|
| 컨택 → 프록시미티 → 투영 | 해상력 | **마스크 수명과 결함**. 접촉은 마스크를 소모품으로 만들어 양산 불가 |
| 1:1 → 축소 투영(스테퍼) | 해상력 | 마스크에 웨이퍼 전체를 1:1로 그릴 수 없음. **4× 축소**하면 마스크 결함 요구도 4배 완화 |
| 스테퍼 → 스캐너 | 필드 크기 + 균일도 | 렌즈는 중심부만 수차가 좋음 → **좁은 슬릿만 쓰고 스캔**하면 큰 필드를 좋은 품질로 노광 가능 |
| 램프 → 엑시머 레이저 | 파장 | 램프는 짧은 파장에서 광량이 급감. 레이저는 **단색성·고출력** |
| ArF → 이머전 | NA 1 돌파 | 렌즈-웨이퍼 사이를 물로 채우면 NA = n·sinθ 에서 n=1.44 → **NA 1.35 가능** |
| 이머전 → 멀티 패터닝 | 더 미세한 피치 | 광학적으로 불가능한 피치를 **공정을 2~4번 나눠** 만듦 → 식각/증착 장비 부담 폭증 |
| 멀티패터닝 → EUV | 공정 수 절감 | 노광 1회로 해결 → 마스크 수·공정 단계·오버레이 스택 감소(비용 역전) |
| EUV → High-NA | 해상력 | 파장을 더 줄이는 건 소재·광원 모두 불가 → **NA를 0.55로**. 대가로 필드가 절반(아나모픽) |

> **멀티 패터닝이 장비에 준 충격**: 노광 1회를 못 하면 *증착 → 노광 → 식각 → 증착 → 식각…* 을 반복합니다.
> SAQP는 한 층을 만드는 데 수십 단계가 들어갑니다. 즉 **리소의 한계가 식각·증착 장비 수요를 폭증시켰습니다.** 반대로 EUV는 그 단계를 줄입니다.
> 이것이 "리소 장비 한 대가 팹 전체 구조를 바꾼다"는 말의 의미입니다.

## 3. 왜 파장을 더 줄이지 못하고 NA로 갔는가

```
   R = k₁λ/NA 이므로 λ를 줄이는 게 가장 효율적으로 보인다. 그런데:

   ① 13.5 nm 미만(예: 6.x nm) → 반사 다층막(Mo/Si) 설계 자체가 더 어렵고 반사율이 떨어진다
   ② 광원: 13.5 nm도 Sn 플라즈마로 겨우 수백 W를 만든다. 더 짧은 파장은 변환 효율이 더 나쁨
   ③ 모든 물질이 흡수 → 광학계 손실이 파장 감소와 함께 악화
   ④ 레지스트: 광자 에너지가 커질수록 광자 수가 줄어 확률적 요동(stochastics)이 심해짐

   → 그래서 파장은 13.5 nm에 고정하고, NA를 0.33 → 0.55로 올리는 길을 택했다.
      (NA 0.55 = 반사 광학 설계·거울 크기·입사각의 한계에 가까운 선택)
```

**아나모픽(anamorphic) 광학의 등장 이유**
```
   NA를 0.55로 키우면 거울에 오는 빛의 입사각이 커진다
   → 마스크(반사형)에서 다층막 반사율이 떨어지고 그림자(shadowing) 효과가 심해진다
   → 해결: 한 방향(스캔 방향)만 배율을 8×로, 다른 방향은 4×로 (아나모픽)
   → 대가: 노광 필드가 26 × 33 mm → 26 × 16.5 mm (절반, "하프 필드")
   → 큰 칩은 두 번 노광해 이어붙여야 함(stitching) → 설계·오버레이 부담
```

## 4. 리소 공정 흐름과 장비 배치

```
 ┌───────────────── 트랙 (Coater / Developer) ──────────────────┐   ┌──── 스캐너 ────┐
 │ ① 탈수 베이크 + HMDS 프라이밍 (밀착력)                        │   │                │
 │ ② 하부막 도포(BARC/SOC/SOG 등) + 베이크                       │   │                │
 │ ③ 레지스트 도포 (스핀 코팅) + EBR(엣지 비드 제거)               │   │                │
 │ ④ 소프트 베이크(PAB) → 냉각 플레이트                          │   │                │
 │ ⑤ (이머전용) 탑코트 도포                                      │──▶│  ⑥ 노광        │
 │ ⑦ 노광 후 베이크(PEB) → 냉각                                  │◀──│  (인터페이스로  │
 │ ⑧ 현상(develop) + 린스 + 스핀 건조                            │   │   직결)        │
 │ ⑨ 하드 베이크(옵션)                                          │   └───────────────┘
 └──────────────────────────────────────────────────────────────┘
                     │
                     ▼
              ⑩ 계측(CD, 오버레이) → [식각] 또는 [임플란트]
```

- 트랙과 스캐너는 **인터페이스 모듈로 직결**되어 하나의 라인처럼 동작합니다(트랙-스캐너 "링크").
- 이유: 레지스트는 도포 후 시간(Q-time)에 민감하고, PEB 타이밍이 CD를 직접 바꿉니다. **시간 지연 자체가 공정 변수**입니다.

## 5. 트랙(코터/디벨로퍼) — 사실 여기가 CD를 절반 결정한다

### 5-1. 구조

```
   [트랙 = 수십 개의 작은 모듈을 쌓아 올린 타워 + 반송 로봇]

   ┌──────────────────────────────────────────────────────┐
   │  상부: 열처리 모듈 스택                                │
   │   HP(Hot Plate) ×N   ·   CP(Chill Plate) ×N           │  ← 온도 ±0.1 ℃ 급 관리
   │   (PAB, PEB, 하드베이크 전용 플레이트 분리)              │
   ├──────────────────────────────────────────────────────┤
   │  중부: 습식 모듈 스택                                  │
   │   COT(코터 컵) ×N : 레지스트 스핀 도포 + EBR           │
   │   DEV(디벨로퍼 컵) ×N : 현상액 토출 + 린스             │
   │   BARC/SOC 코터, 어드히전(HMDS) 모듈                   │
   ├──────────────────────────────────────────────────────┤
   │  반송: 중앙 다관절 로봇(수직 이동) — 모듈 간 웨이퍼 이동  │
   ├──────────────────────────────────────────────────────┤
   │  하부/전면: FOUP 로드포트 ×4,  후면: 스캐너 인터페이스   │
   └──────────────────────────────────────────────────────┘
       유틸: 케미컬 캐비닛(레지스트/현상액/시너), 필터, 펌프, 배기
```

### 5-2. 모듈·부품 사전

| 모듈/부품 | 역할 | 문제 시 증상 | 관리 포인트 |
|-----------|------|--------------|-------------|
| **HMDS 프라이밍 챔버** | 표면을 소수성으로 → 레지스트 밀착 | 패턴 박리/리프팅, 언더컷 | 증기 농도·온도·시간, 탈수 베이크 선행 |
| **레지스트 디스펜스 노즐/펌프** | 정량 토출 | 도포 결함(스트릭, 코멧), 두께 편차 | 노즐 끝 건조 방지(대기 시 용매 분위기), 기포 제거, 필터 |
| **필터 (수 nm급)** | 겔·응집 입자 제거 | 결함, 브릿지 | 교체 주기, 압력 관리 |
| **스핀 척 + 모터** | 회전으로 균일 도포 | 두께 편차, 진동 무늬 | 회전 정확도, 척 청정(백사이드) |
| **코터 컵 + 배기** | 용매 증기 배출·비산 회수 | 재부착 결함, 두께 변동 | 배기 균일, 컵 세정 |
| **EBR 노즐 (Edge Bead Removal)** | 엣지에 뭉친 레지스트 제거 | 엣지 결함, 반송 오염, 파티클 | 토출 위치·폭 정밀 |
| **핫 플레이트 (HP)** | PAB/PEB 열처리 | **CD 직접 변화** | 온도 균일도 ±0.1 ℃, 근접핀 높이, 배기 |
| **칠 플레이트 (CP)** | 급속 냉각으로 반응 정지 | CD 산포 | 온도·타이밍 |
| **디벨로퍼 노즐** | 현상액 도포(슬릿/퍼들/스프레이) | 현상 불균일, 브릿지, 미현상 | 토출 균일, 퍼들 시간, 온도 |
| **린스/건조** | 현상액 제거 | 워터마크, 패턴 붕괴 | 린스 유량, 스핀 프로파일 |
| **온습도·케미컬 필터(AMC)** | 아민·산 오염 차단 | **T-top, footing**, CD 시프트 | 케미컬 필터 수명 관리 |

### 5-3. 스핀 코팅의 물리와 노브

```
   두께 t ≈ C · η^a / ω^b   (η: 점도, ω: 회전수)   → 대략 t ∝ 1/√ω

   ① 디스펜스: 웨이퍼 중앙에 레지스트 토출 (정지 or 저속)
   ② 스핀업: 급가속 → 원심력으로 방사 확산
   ③ 스핀오프: 일정 회전수 유지 → 여분 배출 + 용매 증발로 두께 고정
   ④ EBR + 백사이드 린스
```

| 노브 | 결과 | 부작용 |
|------|------|--------|
| 회전수 ↑ | 두께 ↓ | 엣지 결함, 재료 손실 |
| 가속도 ↑ | 균일도 개선(방사 무늬 억제) | 진동/비산 |
| 토출량 ↑ | 커버 안정 | 재료비(레지스트는 매우 비쌈) |
| 배기 유량 | 용매 증발 속도 → 두께·균일도 | 과도 시 건조 무늬 |
| 온습도 | 용매 증발·현상 반응 | CD 시프트 |
| 베이크 온도/시간 | 용매 잔량, 산 확산(PEB) | **CD와 프로파일 직접 변화** |

> **PEB가 특별한 이유**: 화학증폭형 레지스트(CAR)는 노광으로 생성된 산(acid)이 PEB 중 확산·반응하며 패턴을 완성합니다.
> 그래서 **PEB 온도 0.1 ℃가 CD 수십 pm ~ nm를 움직입니다.** 트랙의 핫플레이트 온도 균일도가 곧 CDU입니다.
> 반대로 말하면, "스캐너만 좋아도 안 된다"는 뜻입니다.

### 5-4. 레지스트 관련 결함 사전

| 결함 | 형태 | 원인 |
|------|------|------|
| **T-top** | 패턴 상단이 T자 | 공기 중 아민(염기)이 표면 산을 중화 → AMC 관리 실패 |
| **Footing** | 하단이 넓어짐 | 하부막(질화막 등)의 염기성 표면, BARC 부적합 |
| **Standing wave** | 측벽 물결무늬 | 하부 반사 간섭 → **BARC(반사방지막)** 로 해결 |
| **Pattern collapse** | 패턴 넘어짐 | 현상·린스 중 표면장력(높은 종횡비) → 계면활성제 린스, IPA, 초임계 CO₂ |
| **Bridging / Missing contact** | 붙음/사라짐 | 도즈·포커스, **확률효과(stochastics)**, 결함 |
| **Comet / Streak** | 꼬리 모양 도포 결함 | 파티클, 노즐 기포, 필터 |
| **Bubble defect (이머전)** | 원형 결함 | 물 속 기포 |
| **Watermark** | 물자국 | 이머전 물 잔류, 건조 불량 |
| **Scum** | 현상 잔류물 | 현상 부족, 노광 부족 |

### 6-3. 왜 "스텝 & 스캔"인가

```
   [스테퍼: step & repeat]              [스캐너: step & scan]
   필드 전체를 한 번에 정지 노광          좁은 슬릿만 쓰고 마스크·웨이퍼를 동기 이동

   ┌───────────┐                        ┌───────────┐
   │███████████│  ← 렌즈 전 영역 사용     │   ▓▓▓     │  ← 슬릿(고품질 영역)만 사용
   │███████████│    (주변부 수차 나쁨)    │   ▓▓▓     │     스캔하며 필드를 채움
   └───────────┘                        └───────────┘
                                         ↑ 스캔 방향

   장점: ① 렌즈의 가장 좋은 부분만 쓴다 → 수차·균일도 유리
         ② 렌즈 직경을 키우지 않고 큰 필드(26×33 mm) 노광
         ③ 슬릿 내 조명 균일화가 쉬움, 스캔 중 도즈 평균화 효과
   대가: 마스크 스테이지와 웨이퍼 스테이지를 4:1 배율로 정확히 동기 구동해야 함
         (동기 오차가 곧 오버레이·CD 오차)
```

### 6-4. 듀얼 스테이지 — 처리량의 비밀

```
   웨이퍼 A: 노광 중         |  웨이퍼 B: 동시에 얼라인·레벨 측정 중
   → 측정 시간을 노광 시간에 숨긴다(hide)
   → 교대(스왑) → 처리량 대폭 향상

   이것이 없으면 "측정 + 노광"이 직렬로 붙어 WPH가 크게 떨어진다.
```

## 7. 이머전(ArF-i) — 물을 넣는다는 결정

```
   NA = n · sinθ
   공기(n=1): 이론상 NA < 1
   물(n=1.44 @193 nm): NA 1.35까지 실현

   [이머전 후드 구조]
        렌즈 최종면
     ══════════════════
       ┌── 물 공급 ──┐  ← 탈기(degassed) 초순수, 온도 정밀 제어
       │ ░░░░물░░░░ │  ← 수 mm 두께의 물 층, 스캔 중에도 유지
       └── 물 회수 ──┘  ← 에어 시일/기류로 물 가둠
     ▓▓▓▓▓ 웨이퍼 ▓▓▓▓▓  ← 최대 수백 mm/s 로 스캔
```

| 이머전이 만든 새로운 문제 | 대책 |
|--------------------------|------|
| **기포(bubble)** → 결함 | 물 탈기(degas), 유동 설계, 스캔 속도 제한 |
| **워터마크** (물 잔류 후 건조) | 후드 회수 성능, 소수성 탑코트, 건조 |
| **레지스트 성분 용출(leaching)** → 렌즈 오염 | **탑코트(topcoat)** 도포, 저용출 레지스트 |
| **물 온도 변화** → 굴절률·수차 | 물 온도 정밀 제어(±mK 급) |
| **스캔 속도 상한** | 물이 끌려가지 않는 한계 → 처리량 제약 |
| **엣지 필드에서 물 유실** | 엣지 노광 전략, 엣지 링/커버 |

> **왜 물이었나**: 193 nm에서 투명하고, 굴절률이 높고(1.44), 안전하고, 초순수 인프라가 이미 팹에 있었기 때문입니다.
> "더 높은 굴절률 액체(n≈1.65)" 연구가 있었으나 흡수·오염 문제로 양산에 못 갔습니다. → **NA 1.35가 DUV의 끝**이 되었습니다.

## 8. EUV — 왜 전부 다시 만들어야 했나

### 8-1. EUV가 강제한 4가지 근본 변화

| 변화 | 이유 |
|------|------|
| **① 렌즈 → 거울(반사 광학)** | 13.5 nm는 모든 물질에 강하게 흡수됨. 투과 렌즈 불가 |
| **② 진공 필수** | 기체도 13.5 nm를 흡수. 공기 중에서는 수 mm ~ cm에서 광량이 사라짐 |
| **③ 마스크도 반사형** | 투과 마스크 불가 → 다층막 미러 위에 흡수체 패턴 |
| **④ 광원이 플라즈마** | 13.5 nm를 내는 레이저가 없음 → Sn 플라즈마 발광(LPP)을 이용 |

### 8-2. EUV 스캐너 전체 구조

### 8-3. EUV 광원(LPP)의 동작 — 단계별

```
 ① Sn(주석) 액적 발생기가 수십 µm 액적을 초당 약 5만 개 사출
 ② 프리펄스(pre-pulse) 레이저가 액적을 때려 넓게 퍼진 "팬케이크" 형태로 만든다
    → 이렇게 해야 메인펄스의 에너지를 효율적으로 흡수한다 (변환효율 향상의 핵심 아이디어)
 ③ 메인펄스(고출력 CO₂ 레이저)가 이를 플라즈마로 만듦 → Sn 이온이 13.5 nm 를 방출
 ④ 타원 컬렉터 미러가 사방으로 나가는 EUV를 모아 중간초점(IF)으로 보냄
 ⑤ 조명계 → 마스크 → 투영 광학 → 웨이퍼

 변환효율(CE, 레이저 에너지 → 13.5 nm 대역 에너지)은 수 % 수준
 → 웨이퍼에 수십 W를 주려면 CO₂ 레이저는 수십 kW급이 필요
 → 그래서 EUV 장비는 전력 소모가 매우 크고, 광원 가동률이 장비 가동률을 지배한다
```

| 광원 부품 | 역할 | 문제/관리 |
|-----------|------|-----------|
| **Sn 액적 발생기** | 정확한 크기·주기로 액적 공급 | 노즐 막힘, 액적 궤적 지터 → 광량 요동 |
| **CO₂ 레이저(드라이버)** | 프리펄스 + 메인펄스 | 출력 안정성, 광학 오염, 냉각 |
| **빔 전송/집속 광학** | 레이저를 액적 위치에 정확히 | 정렬 드리프트 |
| **컬렉터 미러** | EUV 집광 (핵심 소모성 광학) | **Sn 퇴적 + 이온 충격 → 반사율 저하**. 수명이 광원 비용을 지배 → H₂ 세정, 자기장/기류 기반 debris 완화 |
| **H₂ 계통** | 광학 보호·Sn 세정·열 제거 | 대량 H₂ 사용 → 안전 및 회수·재순환 설비 |
| **DGL(Dynamic Gas Lock)** | 모듈 간 오염 확산 차단(가스 흐름 장벽) | 압력 밸런스 |
| **Sn 트랩/포일 트랩** | 파편(debris) 포집 | 막힘, 교체 |

### 8-4. EUV가 진공을 요구하는 이유 (상세)

```
  ① 흡수: 13.5 nm 광자는 기체 분자의 전자 전이와 강하게 상호작용해 흡수된다.
     대기압 공기에서는 수 mm 진행에 광량이 크게 감소한다. 광로는 수 m → 절대 불가.
  ② 오염: 남아 있는 탄화수소(오일, 아웃개싱)는 EUV 조사로 분해되어
     거울 표면에 탄소막을 형성 → 반사율 영구 저하. 거울 1장 손실이 곧 수 % 광량 손실.
  ③ 파편(debris) 관리: Sn 플라즈마에서 나오는 이온·중성 원자·미세 액적을
     기체 흐름(H₂)과 트랩으로 제어해야 한다.
  ④ 열: 진공에서는 복사·전도로만 열을 빼야 하므로 미러 냉각 설계가 중요.

  그런데 왜 완전 진공이 아니라 수 Pa 의 H₂ 를 넣는가?
  · H₂는 EUV 흡수가 상대적으로 작다 (완전 무손실은 아니고 "감당 가능한" 수준)
  · EUV가 H₂를 해리시켜 만든 수소 라디칼이
      Sn + H → SnH₄ (휘발성) 로 Sn 오염을 제거한다  ← 거울 수명 연장의 핵심
  · 탄소 오염도 환원시켜 제거한다
  · 미세하게나마 열 전달 매체가 된다
  부작용: 수소가 소재로 침투해 펠리클·다층막·레지스트에 블리스터(수소 취화)를 유발
          → 소재 개발의 큰 과제
```

### 8-5. 반사형 마스크와 펠리클

| 요소 | 내용 | 관리 포인트 |
|------|------|-------------|
| **기판** | LTEM(초저열팽창 유리) | 열변형이 오버레이 직결 |
| **다층막** | Mo/Si 약 40 ~ 50 주기, 반사율 약 70 % | 결함 하나가 패턴 결함. 다층막 결함은 수리 불가에 가까움 |
| **캡핑층** | Ru 등 | 산화·손상 방지 |
| **흡수체** | TaBN 등, 두께 수십 nm | 두께 때문에 **그림자 효과(shadowing)** 발생 |
| **백사이드 도전막** | 정전척킹용 | 척킹 안정 |
| **펠리클** | 초박막(CNT/다결정 Si계). 파티클이 마스크면에 앉는 것을 방지 | EUV 투과율 손실(수 %), 열·수소 내성, 파손 시 치명적 |
| **입사각 ~6°** | 반사형이므로 수직 입사 불가 | 방향에 따른 **그림자·CD 비대칭** → 마스크 설계(OPC)에서 보정 |

**EUV 마스크 결함 검사의 어려움**: 13.5 nm로 검사해야 실제 노광 조건과 같습니다(**actinic** 검사).
DUV 광학 검사로는 다층막 내부 위상 결함을 놓칠 수 있어, actinic 패턴/블랭크 검사 장비가 별도로 발전했습니다.

### 8-6. 확률 효과(Stochastics) — EUV의 고유 난제

```
   EUV 광자 1개의 에너지는 92 eV (193 nm는 6.4 eV)
   → 같은 노광 에너지(mJ/cm²)를 주더라도 광자 "개수"가 훨씬 적다
   → 작은 영역(수 nm²)에 도달하는 광자 수의 통계적 요동이 커진다
   → 결과: 라인 거칠기(LER/LWR), 확률적 결함(micro-bridge, missing hole)

   대책:
    · 도즈 ↑ (광자 수 ↑) → 하지만 처리량 ↓ (직접적인 비용 증가)
    · 고감도·고해상 레지스트 개발 (메탈 옥사이드 레지스트, 드라이 레지스트)
    · 광원 파워 ↑ (도즈를 올려도 처리량을 지키기 위해)
    · 패턴 설계(정규화된 레이아웃), 계측·검사 강화(e-beam 다중빔 검사)
```

> **여기서 "장비가 공정에 어떤 영향을 주는가"가 가장 선명하게 보입니다.**
> 확률 결함을 줄이려면 도즈를 올려야 하고, 도즈를 올리면 처리량이 떨어져 원가가 오릅니다.
> 그래서 **광원 파워 향상 = 수율과 원가를 동시에 해결하는 유일한 길**이 됩니다. EUV 개발의 절반이 광원에 쏟아진 이유입니다.

### 8-7. High-NA(EXE) — 무엇이 달라지나

| 항목 | NXE (0.33 NA) | EXE (0.55 NA, High-NA) |
|------|---------------|------------------------|
| 해상력 | ~13 nm 하프피치급 | ~8 nm 급 |
| 배율 | 4× (양방향) | **아나모픽**: 스캔 방향 8×, 다른 방향 4× |
| 노광 필드 | 26 × 33 mm | **26 × 16.5 mm (하프 필드)** |
| DOF | 상대적으로 큼 | NA²로 감소 → **더 얇은 레지스트, 더 정밀한 레벨링** |
| 미러 | 상대적으로 작음 | 훨씬 크고 무거운 미러(제작 난이도 급증) |
| 스테이지 | — | 더 빠른 가속(필드가 작아 스텝 수 증가) |
| 마스크 | 표준 | 아나모픽 대응 데이터·검사 인프라 필요 |
| 큰 칩 | 1필드 | **스티칭(두 필드 이어붙임)** 필요 |

> **트레이드오프의 정석**: 해상력을 얻는 대가로 ① 필드 절반, ② DOF 감소, ③ 마스크/설계 인프라 재구축을 지불합니다.
> 그럼에도 가는 이유는, 그 대안(EUV 더블 패터닝)이 더 비싸기 때문입니다. **장비 선택은 결국 원가 비교입니다.**

## 9. 오버레이와 얼라인먼트 — 층을 겹치는 기술

### 9-1. 원리

```
 ① 웨이퍼에 미리 만들어 둔 얼라인 마크(회절 격자)를 센서가 읽는다
 ② 여러 마크(웨이퍼 전체에 분포)를 읽어 "웨이퍼 그리드"를 계산
    → 이동(shift), 회전(rotation), 배율(magnification), 직교성, 고차 변형까지 모델링
 ③ 모델에 따라 각 필드의 노광 위치·배율·회전을 보정하며 노광
 ④ 노광 후 오버레이 계측 → 다음 로트 보정에 반영 (R2R, [0-7장](00-7-sensors-and-control.md))
```

### 9-2. 오버레이 오차의 원인 분해

| 원인 범주 | 구체 예 | 대응 |
|-----------|---------|------|
| **장비(스캐너)** | 스테이지 동기 오차, 렌즈 수차/왜곡, 레티클 스테이지, 열 드리프트 | 캘리브레이션, 매칭(MMO: matched machine overlay) |
| **웨이퍼** | 웨이퍼 변형(막 응력), 척킹 상태, 백사이드 파티클, 휨 | 척 청정, 응력 관리, 고차 보정 |
| **프로세스** | CMP에 의한 마크 변형, 식각으로 마크 손상, 막 적층으로 마크 신호 저하 | 마크 설계, 파장 다양화(멀티 파장 얼라인) |
| **마스크** | 레티클 열변형, 마스크 자체 배치 오차, 척킹 | 레티클 가열 보정, 마스크 규격 |
| **계측** | 오버레이 측정 자체의 오차/편향 | DBO/IBO 비교, 타깃 설계 |
| **툴 간 차이** | 서로 다른 스캐너에서 층을 노광 | MMO 관리, 전용 툴 지정(dedication) |

> **실무 감각**: 오버레이 예산(overlay budget)은 여러 원인의 제곱합으로 관리됩니다.
> 그래서 한 항목만 개선해도 전체가 크게 나아지지 않고, **모든 항목을 균형 있게 줄여야** 합니다.
> "스캐너가 좋아도 CMP가 마크를 망가뜨리면 끝"이라는 말이 여기서 나옵니다.

### 9-3. 레벨 센서와 초점 제어

```
   DOF가 수십 nm → 웨이퍼 표면 높이가 그만큼 흔들리면 패턴이 흐려진다

   레벨 센서: 노광 직전(또는 다른 스테이지에서 미리) 표면 높이를 맵으로 측정
             → 스캔 중 웨이퍼 척(Z/틸트)을 실시간 보정

   초점을 망치는 실제 원인:
    · 웨이퍼 뒷면 파티클 (국부적으로 웨이퍼를 들어올림) ← 가장 흔하고 치명적
    · 척 표면 오염
    · 웨이퍼 휨(응력 막)
    · 막 두께 급변(패턴 밀도 차) → 프로세스 기인
```

> 그래서 **노광 장비의 최대 오염 이슈는 "웨이퍼 백사이드"** 입니다([0-6장](00-6-wafer-handling.md)).
> 앞면만 깨끗해도 뒷면 파티클 하나가 그 영역 전체를 디포커스로 날립니다.

## 10. 해상력을 더 뽑아내는 기술 (k₁ 줄이기)

| 기술 | 원리 | 장비/공정에서의 구현 |
|------|------|---------------------|
| **OPC (광학 근접 보정)** | 회절로 왜곡될 것을 예상해 마스크 패턴을 미리 변형 | 마스크 데이터 처리(대규모 계산), 마스크 라이터 |
| **PSM (위상 시프트 마스크)** | 위상 180° 차이로 간섭 대비 향상 | 마스크 제작 |
| **오프액시스 조명 (OAI)** | 환형/다이폴/쿼드러폴 등 특정 각도만 조명 → 특정 피치의 대비 향상 | 일루미네이터 퓨필 형상 |
| **SMO (Source-Mask Optimization)** | 조명 형상과 마스크를 동시 최적화 | FlexRay형 자유 퓨필 + 계산 리소 |
| **편광 제어** | 고 NA에서 TE/TM 대비 차이 보정 | 조명계 편광 소자 |
| **이머전** | n↑ → NA↑ | 후드/물 계통 |
| **멀티 패터닝** | 한 층을 여러 번 나눠 노광·식각 | 식각/증착 장비 부담 ↑ |
| **레지스트/하부막 최적화** | 콘트라스트·확산 제어, 반사 억제 | BARC/SOC, 탑코트, 트랙 조건 |
| **컴퓨테이셔널 리소** | 전산 모델로 전체 최적화 | 대규모 컴퓨팅 인프라 |

### 멀티 패터닝 방식 비교

| 방식 | 절차 | 장점 | 단점 |
|------|------|------|------|
| **LELE (Litho-Etch-Litho-Etch)** | 노광·식각을 2회 | 자유로운 레이아웃 | **오버레이 오차가 CD 오차로 직결**, 공정 수 2배 |
| **SADP (Self-Aligned Double Patterning)** | 코어 패턴 → 스페이서 증착 → 코어 제거 → 스페이서를 마스크로 | 피치가 **스페이서 두께로 결정** → 오버레이 무관, 균일도 우수 | 레이아웃 제약, 컷 마스크 필요 |
| **SAQP** | SADP를 2번 반복 | 4배 밀도 | 공정 수 대폭 증가, CD 제어 난이도 |

> **여기서 장비 간 연결이 보입니다**: SADP의 피치 정확도는 **ALD 스페이서 두께 균일도**로 결정됩니다([05장](05-deposition-cvd-ald.md)).
> 즉 리소의 한계를 증착 장비가 메우는 구조입니다. "장비는 따로가 아니라 사슬"이라는 것이 여기서 드러납니다.

## 11. 마스크(레티클) 제작·관리 장비

| 장비 | 역할 | 특징 |
|------|------|------|
| **마스크 라이터 (전자빔, 특히 멀티빔 MBMW)** | 마스크 패턴 직접 묘화 | 단일빔은 너무 느려 곡선형(curvilinear) OPC 시대에 멀티빔이 필수화 |
| **마스크 식각/증착 장비** | 흡수체 패턴 형성 | 전용 소형 장비 |
| **마스크 검사기 (DUV/전자빔/actinic)** | 결함 검출 | EUV는 **actinic(13.5 nm) 검사**가 중요 |
| **마스크 수리기 (e-beam/AFM 기반)** | 결함 제거·보강 | 다층막 결함은 수리 난이도 매우 높음 |
| **마스크 세정기** | 파티클/오염 제거 | 세정마다 막질 손상 위험 |
| **펠리클 마운터/검사** | 펠리클 장착·상태 확인 | EUV 펠리클은 취급 난이도 높음 |
| **레티클 보관/반송 (RSP, 포드)** | 오염 차단 | EUV는 진공/청정 요구가 극단적 |

> **마스크 헤이즈(haze)**: DUV 시대에 마스크 표면에 황산암모늄 결정이 자라 패턴을 흐리게 만드는 현상이 큰 문제였습니다.
> 원인은 잔류 이온 + 광화학 반응. 대책은 세정·보관 환경·펠리클 관리였습니다. **"광학 장비는 오염으로 죽는다"** 는 교훈입니다.

## 12. 장비 노브 ↔ 공정 결과

| 노브 | 물리 | 결과 | 부작용 |
|------|------|------|--------|
| **도즈(Dose, mJ/cm²) ↑** | 노광 에너지 ↑ | CD 변화(포지티브면 선폭 ↓), 확률 결함 ↓ | **처리량 ↓**, 레지스트 손상, 열 |
| **포커스(Focus) 이동** | 상면 위치 | CD·프로파일 변화, 최적점에서 벗어나면 급격히 악화 | 공정 윈도우 축소 |
| **조명 형상(퓨필)** | 회절광 수집 방식 | 특정 피치 해상력·DOF 개선 | 다른 피치 악화(패턴 의존) |
| **NA** | 해상력·DOF | 해상력 ↑ | DOF ↓, 편광 효과 |
| **스캔 속도** | 노광 시간·도즈 | 처리량 | 도즈 정확도, (이머전) 물 안정성 |
| **레티클 배율/회전 보정** | 결상 왜곡 | 오버레이 개선 | 과보정 위험 |
| **레벨링(Z/틸트)** | 초점면 정합 | CDU 개선 | 측정 오류 시 악화 |
| **PEB 온도(트랙)** | 산 확산량 | **CD 직접 변화** | 프로파일, LWR |
| **BARC 두께** | 반사율 | 스탠딩 웨이브·CD 변동 억제 | 식각 부담 |

### FEM(Focus-Exposure Matrix) — 리소 엔지니어의 기본 도구

```
   도즈를 가로축, 포커스를 세로축으로 바꿔가며 노광한 웨이퍼를 만들고
   각 조건의 CD를 측정 → "Bossung 곡선"과 공정 윈도우(process window)를 구한다

   CD
    │   ╭──╮        각 곡선 = 특정 도즈
    │  ╱    ╲       평평한 구간이 넓을수록 DOF 여유가 큼
    │ ╱      ╲
    └──────────── 포커스
   → 여기서 "DOF와 EL(Exposure Latitude)"을 동시에 만족하는 영역을 공정 조건으로 채택
```

## 13. 트러블슈팅

| 증상 | 의심 | 확인 순서 |
|------|------|-----------|
| 특정 위치만 CD 이상/흐림 | **웨이퍼 백사이드 파티클**, 척 오염 | 백사이드 검사, 척 청소, 동일 위치 반복성 |
| 웨이퍼 전체 CD 시프트 | 도즈 드리프트(광원), PEB 온도, 레지스트 로트 | 도즈 센서 캘, 핫플레이트 온도 맵, 레지스트 이력 |
| CD 산포(랜덤) 증가 | 확률 효과, 레지스트/현상, 필터 | 도즈 상향 테스트, 레지스트/필터 교체, LWR 측정 |
| 오버레이 갑작스런 악화 | 척킹/백사이드, 웨이퍼 변형, 스캐너 캘 | 오버레이 지문(fingerprint) 맵으로 원인 분류, 툴 매칭 확인 |
| 오버레이 서서히 악화 | 렌즈 가열, 레티클 가열, 스테이지 드리프트 | 로트 내 순서 의존성 확인, 보정 모델 |
| 이머전 결함(원형/물자국) | 기포, 후드 회수, 탑코트 | 탈기 상태, 후드 점검, 스캔 속도 |
| T-top / footing | AMC(아민), 하부막 | 케미컬 필터 교체 이력, BARC 조건 |
| 패턴 붕괴 | 종횡비·표면장력·린스 | 린스 계면활성제, 레지스트 두께, 건조 조건 |
| 처리량 저하 | 광원 파워, 스테이지, 도즈 상향, 얼라인 재시도 | 광원 출력 트렌드, 로그의 시간 분해 |
| EUV 광량 저하 | 컬렉터 반사율(Sn 오염), 광원 파라미터 | 컬렉터 수명 지표, 액적/레이저 정렬 |
| 레티클 기인 반복 결함 | 마스크 오염/손상, 펠리클 | 동일 필드 내 동일 좌표 반복성 확인 → 마스크 검사 |

> **"동일 좌표 반복"은 마스크, "웨이퍼 좌표 랜덤"은 프로세스/장비** — 결함 원인 분류의 첫 번째 규칙입니다.

## 14. 최근 동향과 앞으로

| 동향 | 내용 |
|------|------|
| **High-NA 도입** | 0.55 NA 장비의 초기 도입 단계. 하프 필드·스티칭·새 마스크 인프라가 과제 |
| **EUV 광원 파워 향상** | 처리량과 확률 결함을 동시에 개선하는 가장 직접적 수단 |
| **드라이 레지스트 / 메탈옥사이드 레지스트** | 감도·해상력·LWR 동시 개선 시도. 증착·식각 장비와 결합(레지스트를 "증착"한다) |
| **커빌리니어(곡선형) 마스크** | SMO/ILT 결과를 그대로 구현 → 멀티빔 마스크 라이터 필수 |
| **계산 리소 확대** | 디지털 트윈 수준의 시뮬레이션으로 조건 탐색 |
| **오버레이 극한 관리** | 하이브리드 본딩·3D 적층에서 오버레이 요구가 더 커짐 ([11장](11-packaging.md)) |
| **e-beam 다중빔 검사** | 확률 결함을 잡기 위한 대면적 전자빔 검사 |
| **DUV의 지속적 역할** | 모든 층을 EUV로 하지 않음. 비임계층은 ArF-i/KrF/i-line이 계속 담당(오히려 물량은 여기가 큼) |
